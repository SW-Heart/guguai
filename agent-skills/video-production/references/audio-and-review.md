# 声音与成片检查

## 声音设计

为每个需要声音的时段写出来源和作用：人物对白传递信息，环境声建立空间，关键音效标记动作，音乐控制情绪与连续性。对白写准确文字、说话人、语言和语气；画内人物说话时把口型和发声放在同一镜头描述。无声片也可以成立，不因工具支持声音就强加配音或音乐。

现有 Agent 能转录语音、检测音轨与静音、提取视频混合原声，并把用户提供的独立音频放入成片。它不能从混合原声中单独分离人声和音乐，也没有通用的独立配音、音乐或音效生成工具。台词、音效和环境声优先写进视频描述，由视频模型同次生成。用户对人物说话的音色、口音或配音有特殊要求时，先查当前可用模型中是否有配音/语音模型，有则先生成配音，再用支持音频参考的视频模型以该配音为参考生成；没有时说明并请用户提供录音，不声称已经制作。配音/翻译时保存原声、说话人、原文、目标语言、时长和背景声意图；替换配音不自动替换整条声轨。

## 跨镜头角色声音一致

固定音色描述是所有说话角色的基础设定，不以用户提出特殊配音要求或提供音频为前提。先读已有角色与声音设定，保留已确认内容；新创作时为每个角色确定一段简短、具体、可重复使用的描述，例如“宁舟：成年男性中低音，温润厚实，略有颗粒感，中文普通话，无明显地方口音”。按角色保存到当前人物设定或制作文档，后续写镜头前读取并复用原文，不逐段重新设计。

每一段包含该角色发声的分镜、画面描述和独立生成请求，必须完整写出角色名与固定音色描述，包括画外对白、旁白和续拍。不能仅在总方案中写一次，也不能用“同上一段”“原有音色”或角色名代替具体内容。多人发声时分别写入各自描述，不让同一音色隐式指代多人；没有发声的角色无需在该段添加声音描述。

固定声线、音域、质感、语言与口音和当段表演分开写。角色可以轻声、喊叫、哭泣或改变语速，但情绪变化不重新分配声线；用户明确要求变声、成长或切换语言时，记录对应版本与适用镜头，不覆盖其他镜头的原设定。精简画面描述时保留每个说话角色的音色内容。

连续两段的示例：

```text
第一段：宁舟声音为成年男性中低音，温润厚实，略有颗粒感，中文普通话，无明显地方口音。宁舟台词（克制、轻声）：“我一直在等。”
第二段：宁舟声音为成年男性中低音，温润厚实，略有颗粒感，中文普通话，无明显地方口音。宁舟台词（惊喜、语速稍快）：“你终于回来了。”
```

没有可用参考音频时仍逐段带入固定描述；有已确认的真实音频且模型支持时，同一角色持续复用同一份声音参考，并同时写音色描述与真实素材标签。音频编号随本次素材顺序变化，角色与实际音频的对应不变。固定描述和参考提高一致性，不能据此宣称已锁定实际成品声音；跨镜头音色是否漂移仍需实际听审。

## 合成与核对

拼接前读取各片段真实时长与画幅。用实际片段和独立音轨建立成片时间线；音乐跨镜头时优先保持一条连续声轨，不让每段重复起乐。字幕不由视频模型生成，只在用户需要时于成片后加入，依据最终混音后的语音时间制作；专名、数字、断句和卡点要核对。

交付前按实际文件检查：能否播放、总时长和画幅、镜头接缝、画面/身份连续性、对白与口型、音量和静音、音乐与音效、字幕准确性。`video_probe`、`video_frames`、`video_audio_check` 和 `audio_transcribe` 只能证明各自观测到的事实；不能证明未观看的画面或未听审的声音正确。发现问题时定位时间段并局部修正，保留原版供比较。
