# 声音与成片检查

## 声音设计

为每个需要声音的时段写出来源和作用：人物对白传递信息，环境声建立空间，关键音效标记动作，音乐控制情绪与连续性。对白写准确文字、说话人、语言和语气；画内人物说话时把口型和发声放在同一镜头描述。无声片也可以成立，不因工具支持声音就强加配音或音乐。

现有 Agent 能转录语音、检测音轨与静音、提取视频混合原声，并把用户提供的独立音频放入成片。它不能从混合原声中单独分离人声和音乐，也没有通用的独立配音、音乐或音效生成工具。需要新声音时先看是否已有合适音频，缺少能力就明确说明，不声称已经制作。配音/翻译时保存原声、说话人、原文、目标语言、时长和背景声意图；替换配音不自动替换整条声轨。

## 合成与核对

拼接前读取各片段真实时长与画幅。用实际片段和独立音轨建立成片时间线；音乐跨镜头时优先保持一条连续声轨，不让每段重复起乐。字幕只在用户需要时加入，依据最终混音后的语音时间制作；专名、数字、断句和卡点要核对。

交付前按实际文件检查：能否播放、总时长和画幅、镜头接缝、画面/身份连续性、对白与口型、音量和静音、音乐与音效、字幕准确性。`video_probe`、`video_frames`、`video_audio_check` 和 `audio_transcribe` 只能证明各自观测到的事实；不能证明未观看的画面或未听审的声音正确。发现问题时定位时间段并局部修正，保留原版供比较。
