# 连续制作与续拍

## 先判断是否需要分段

先读取当前剧本、真实素材、用户选择的模型与交付要求。模型能在一次生成中完成的同场景连贯动作与对白优先保持完整；小幅摄影、表情、反应和换人说话不机械拆分。确实超过单次能力、发生场景变化或用户指定分段时，再规划必要的最少段数。

长故事先定最终结果与有序事件，区分已完成、当前片段要做和留到后面的动作。后段描述保留可修改余地，不把整个故事重复放进每条描述。分镜是观看与摄影安排，不自动等于生成请求数量。

## 以实际成片结尾继续

续拍先取得已接受的上一段成片或真实尾部画面。用 `video_probe` 查看实际时长，按需要用 `video_frames` 取接近末尾的有效画面；静态帧无法判断运动方向、速度、摄影阶段与声音时，再取附近画面或结合用户报告。无法查看的类别明确未核实，不编造已看见或听见的结果。

记录人物位置和朝向、持物、衣着、场景、机位、正在进行的动作及声音状态。例：计划走到车门，实际停在两步外，下一段先走完两步；实际提前打开箱子，则后段取消再次开箱。计划和实际结尾分别保留；被拒绝或未接受的失败片段不成为续拍依据。

## 不同衔接方式

- 同场景同动作续拍：继承实际画面、正在进行的运动和必要声音；没有相关证据不承诺无缝。
- 切到下一镜：保持故事与身份，允许明确的机位变化，精确首尾画面可以不同。
- 桥接已知状态：起点与终点都明确，并在所选模型支持时使用真实首尾帧。
- 修复结尾：先修受影响的尾段，再决定后段从哪一版继续。
- 外观或空间漂移：回到原始身份与场景参考，必要时通过明确切镜重新建立画面。

连续用生成结果作为下一次参考会积累偏差。按实际表现和场景切换安排重新使用原始参考，不把上游默认续接次数当作模型硬限制。成片原声与持续音乐分别考虑，跨生成音乐连续性必要时在后期处理。

## 参考职责与保存

原始角色图控制稳定身份，已接受片段或尾帧控制当前状态，动作参考仅控制动作，场景参考控制空间。明确每一维度以哪份素材为准和不继承哪些内容；不要让动作视频覆盖人物外貌或服装。实际标签、顺序和素材 ID 与当前工具输入保持一致。

GuGu 的 `video_frames` 返回供观察的画面，不会创建可提交的图片素材。模型支持视频参考时，可用 `video_compose` 的单段 `clips`（`assetId`、`startSeconds`、`endSeconds`）将已接受成片末尾的必要范围保存为真实视频素材，再与原始身份图一起引用；先检查素材数量与时长限制。仅支持图片或首尾帧时，缺少真实尾帧图片就明确缺项，不能把帧时间、原视频 ID 或观察图片当作首帧素材。镜头切换可用实际结尾状态与原始人物、场景图描述新机位，不机械复制尾帧构图。

逐镜保留简短接点记录：上一镜接受版本、实际结束状态、本镜起点、需要继续的动作和允许的变化。没有生成结果时标为计划接点；新结果与计划不同时，先修正下一镜起点，不重复已完成动作。例：上一镜计划把钥匙递出，实际钥匙已到对方左手，下一镜从左手持钥匙开始，不能再演一次递交。

身份、造型与当前状态使用不同素材名称，例如“阿宁”“阿宁雨衣”“上一镜结尾”。查看并明确对应后用 `references_bind` 保存，后续主动在描述中写 `@阿宁`、`@上一镜结尾`，只带入本镜需要的素材。单次使用通过 `media_prepare.assetMentions` 命名；平台自动按有序真实素材列表转换编号，反复出现同一名称仍引用同一份素材。不要要求用户逐镜重复输入，也不要把“同上一镜”作为独立模型请求唯一的衔接信息。

制作需要持续保存时用当前文档或项目记录：已接受片段、实际结尾、当前任务、已完成动作、后段动作、原始参考、允许变化与未核实项。修改先读最新 revision，保留历史计划和已成功素材；描述中的编号不能代替真实生成任务或素材 ID。

仅请求方案或描述时交付文字；实际生成继续走 `models_describe`、`media_prepare`、`media_submit` 和 `jobs_wait`。修订建议不自动授权付费重试。完整成片再检查接缝、时长、声音与观看结果。

方法参考上游 `seedance-sequence`、`seedance-continuation`、`reference-transfer-contract.md` 与 `retake-protocol.md`；来源见 [来源记录](seedance-source.md)。
