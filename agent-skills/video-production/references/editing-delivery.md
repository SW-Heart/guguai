# 剪辑与成片交付

用于真实素材剪辑、生成片段成片和已做视频的局部修改。这里的时间来自实际文件；方案预计秒数只用于指导选择。

## 确认素材可用范围

先 `video_probe` 获取每段时长和画幅，再用 `video_frames` 看候选入点、关键动作、出点及相邻镜头。每次最多 6 帧，先判断这一批再继续；抽帧不能证明两个时刻之间的运动或整段表演没有问题。

对每个保留区间记录：真实素材、源片入点、源片出点、保留理由、前后如何连接。出点必须大于入点且在素材内；片段顺序、动作完成和台词完整优先于卡整齐秒数。对白是否被剪断需要声音证据，不能只看嘴部静帧。

## 源片秒数与成片秒数

`video_compose` 的 clips 使用各自源片时间；audioTracks 的 atSeconds 使用新成片时间。纯顺序拼接的目标片长为各段保留时长之和。例：A 保留 1–4 秒、B 保留 2–7 秒，成片共 8 秒，B 从成片第 3 秒开始。要在 B 开始时放入音效，atSeconds 应为 3，不是 2。

调换片段或改入出点后，重新核对独立音轨、文字出现、字幕和揭示位置。不要沿用旧成片时间表。当前片段数、片长、音轨与画幅限制以工具定义为准，超出时按有意义段落规划，不能悄悄截断交付。

## 声音与图文分工

现有原声含对白和背景声时，关闭原声会一并关闭它们。只想换背景音乐而没有分离能力时不能声称保留了干净对白；需要可用分轨或另定方案。叠加视频不会自动带入其声音，独立声音需在混音中安排。

需要文字、补充图片、画中画或分屏时，用 `skills_read` 读取 `video-replication` 的 `references/video-editing.md`，依照实际 `video_edit` 工具执行。精确标题与数据优先使用可编辑文字层，生成镜头负责表演与场景。不存在相应能力时交付制作说明，不虚构已完成效果。

只改已有标题时先 `video_edit_read` 读取原底片和方案，改对应层后从原底片重做。不要在已经烧入旧标题的视频上叠新标题。换底片或更换台词时，按新底片真实转录重新定位词句；原片时间不能直接当作新片触发点。

字幕按用户选择制作。顺序通常是确定镜序与声音，转录最终有声成片，核对文字，再 `video_caption_burn`。修正专名和数字时用真实字幕区间；不要拿剧本预计时间冒充识别时间。改剪辑后重建受影响字幕。

## 检查交付文件

| 问题 | 证据 | 可作的结论 |
| --- | --- | --- |
| 时长、画幅是否正确 | 最终素材的 video_probe | 技术规格；不证明审美或播放全程无异常 |
| 接点、标题、产品是否合理 | 最终素材关键点的 video_frames | 已查看时刻的画面情况 |
| 音轨是否存在、是否静音 | video_audio_check | 音轨和音量情况；不证明配乐合适 |
| 台词与字幕内容是否对应 | 完整转录及 source_transcript_read | 识别文本和时间；可疑字、口型及音色待核对 |

抽查包括开头、关键揭示、每个改动接点前后与结尾；问题集中处追加证据。检查应针对最终交付素材，不只检查各个输入镜头。实际无法连续看听时明确这一限制，不给“全部通过”的结论。

## 交付与最小返工

实际成片请求交付工具返回的可读取视频，不以分镜表、单段素材集合或渲染任务 ID 代替。简短说明完成的内容及仍需人工核对的关键处；用户未要求时不创建多种比例、无水印版或额外宣传切片。

画面遮挡只改相应图层；空等过长只改入出点；单镜动作缺失只修该镜头；声音缺失先查原声设置和音轨位置。修改后复核本处及相邻接点，并保留未改动的成功素材与上一版成片。
