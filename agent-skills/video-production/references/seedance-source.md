# 制作方法来源

来源：Emily2040/seedance-2.0，https://github.com/Emily2040/seedance-2.0 ，固定提交 `4668457e560eee06e95d7fcfdf441c8c0bba802e`，声明版本 6.7.0。调研日期 2026-09-30。

本次参考导演分析、空间分镜、续拍、素材职责、拒绝表达与修订判断方法，并为 GuGu 工具改编。未引入其安装器、外部生成脚本、平台价格、素材上限、敏感词表或固定续接次数。上游逻辑检查与样例不是实拍生成质量证明。本记录适用于本次加入视频创作、提示词优化和 Seedance 创作圣经的相关方法。
