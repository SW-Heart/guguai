# 运镜与场面调度

用于设计、改写或诊断单镜头。先在内部回答：观众先看什么；观众站在哪里（景别、高度、角度）；观看关系怎样变化。已有信息足够就直接设计，不把这三个问题变成必问用户的表单。

## 先让行动成立

写出人物起始位置、行动动机、移动路线、朝向、停下或转身的触发事件，以及摄影机相对位置。人物为什么动、摄影机为什么动、移动揭示什么？如果固定机位同样能完成任务，优先考虑固定。强表演、重要对白或复杂场面尤其需要稳定参照；用户明确指定的运动风格仍应保留。

一段短镜头通常保留一个主要摄影动作。复杂动作不是禁用项，但需要足够时长、清晰路线与模型支持；容纳不下就拆镜，不把推近、环绕、升空和拉远堆成一条指令。先用单一主体、主要动作和主运镜验证，再按实际需要增加复杂度；不擅自启动额外付费试镜。

## 按叙事任务选择

| 观看关系 | 常用选择 | 判断依据 |
| --- | --- | --- |
| 观察表演 | 固定 | 画面内部动作已经传递变化 |
| 靠近内心或压力 | 推近 | 终点表情或细节比起点更重要 |
| 拉开、重新理解处境 | 拉远 | 新露出的环境改变人物意义 |
| 揭示画外信息 | 摇摄、俯仰、横移、升降 | 新信息位于哪边，是否需要越过遮挡 |
| 转移画内注意力 | 移焦 | 两个对象处于不同距离平面 |
| 陪伴穿越空间 | 跟拍、横移 | 保持人物路线与观看方向清楚 |
| 展示立体或人物关系 | 环绕 | 更换背景或角度有明确目的 |
| 强调局部 | 变焦 | 希望改变取景范围而非进入空间 |

运动没有固定情绪：推近既可亲密也可压迫，拉远既可孤独也可释然。动作、光线、声音、速度和落点共同决定效果。

## 十二种动作的执行边界

| 动作 | 实际变化 | 必须说明与易错处 |
| --- | --- | --- |
| 固定 | 位置、朝向和构图稳定 | 人物和环境可动；三脚架仍可摇摄，不等于锁定镜头；焦点是否跟随另行说明 |
| 摇摄 | 机位不动，水平旋转 | 左右方向、起始对象、结束对象；不写成横向位移 |
| 甩镜 | 极快的水平旋转 | 从谁到谁，短暂运动模糊，抵达后停稳；不等于随机抖动 |
| 俯仰 | 机位不动，垂直旋转 | 从脚到脸或从脸到手中物；不等于摄影机升降 |
| 变焦 | 位置不变，焦距改变 | 起止取景范围、速度；不要求位移视差，不混同数字裁切 |
| 移焦 | 清晰距离平面改变 | 起始清晰对象与结束清晰对象必须有前后距离；不等于变焦 |
| 推近 | 摄影机向主体靠近 | 起止景别、停止事件；固定焦距时主体通常变大，空间视差变化 |
| 拉远 | 摄影机远离主体 | 拉到多远、露出什么、终点构图；主体通常变小 |
| 横移 | 摄影机左右平移 | 方向、与人物速度关系；近景与远景有不同位移，不是原地转头 |
| 升降 | 摄影机垂直移动 | 起止高度、揭示对象；若保持水平朝向，不再要求同时抬头 |
| 跟拍 | 随主体穿过空间 | 前方后退、后方跟随或侧面并行；距离、人物位置、转弯与停下条件 |
| 环绕 | 沿弧线围绕主体位移 | 中心、从上方看顺/逆时针、弧度、距离、高度、起止背景；四分之一圈通常比整圈容易控制 |

焦段数值只在能说明取景意图时使用；没有画幅或传感器条件时，不把某个毫米数当成必然对应某种景别。景别还取决于距离。浅景深不是所有镜头的默认要求，背景承载信息时要让它可读。

## 从意图到画面描述

按需要补齐六层，不机械输出标签：

1. 观看任务：观众先看到什么，结束时多知道什么。
2. 拍摄位置：景别、角度/高度，必要的焦段或景深。
3. 场面调度：主体起点、动作、路线、朝向、触发与停点。
4. 摄影动作：名称、方向、速度、跟随或围绕的对象。
5. 起止画面：起始构图、信息出现顺序、结束构图与停止事件。
6. 保持项：稳定方式、身份、空间，以及确实能同时成立的距离、焦距、焦点等限制。

不要把叙事解释、检查清单和所有术语都塞进生成描述。交付清晰的自然语言；用户只要提示词时直接给可用文本。

**保持人物大小的跟拍**：平视中景。护士沿走廊朝手术室快步走去，手中始终握着病历。摄影机在她前方沿走廊平稳后退，速度与步速一致，保持约三米距离和胸部以上构图。焦距与高度不变，背景自然掠过；她在门口停下时摄影机一同停住。

**揭示而不乱跑**：平视全景。男人坐在窗边保持不动。摄影机从空门口开始向右缓慢摇摄，依次经过墙上的钟和桌角，最后停在男人身上，保留短暂停留。摄影机位置不变，只水平旋转。具体停留时长按本镜可用时长安排。

**同场景不同目的**：一个人进屋坐下。冷静观察可用固定全景，让他走入中央；紧张可在坐下后从中景推至近景，在门外响声时停住；孤立可从近景拉远露出空椅子；异常可固定构图，从前景人物移焦到后方闪烁的录音机。最后一种必须先安排两个可区分的距离平面。

## 提交前消除矛盾

- 推近又要求人物大小不变：若人物静止且焦距不变，不能同时满足。根据观看目标保留推近并允许变大，或改为保持距离跟拍。只有明确要滑动变焦时才设计反向变焦补偿，仍不承诺背景完全不变。
- 人物迎面跑、摄影机也向前：说明是主动接近还是后退保持距离；不能同时要求距离恒定。
- 移焦又要求所有对象一直清晰：改成先后清晰，或选择深景深固定镜头。
- 横移/环绕又锁死背景：保留真实视差与背景变化，身份和建筑结构保持一致不等于背景像素不动。
- 只写向右或缓慢：补上起点、终点、主体和停下事件，避免无尽漂移。
- 指定近景却要求完整全身与大范围环境：按关键信息调整景别，必要时拆镜。

## 失败后的最小修订

人物随镜头乱跑时，先固定人物路线与停点，并写清摄影机相对位置；无动机前漂时，改为锁定或指定结束事件；运镜过载时，保留叙事必需的一项；身份漂移时缩短遮挡或环绕幅度，核对参考图职责；空间不清时先用全景建立关系。只改能解释失败的变量，保留成功素材。不宣称文字精确就能保证模型一次成功。
