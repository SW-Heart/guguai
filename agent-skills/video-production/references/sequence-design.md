# 段落设计与连续性

## 让每镜承担任务

从观看终点倒推必要信息：观众最后要理解、相信或感到什么，之前需要看见哪些证据。开场可用行动、问题、冲突或清楚的利益点，不默认尖叫、快切和夸张承诺。中段改变信息、关系或风险；结尾兑现开场承诺。只有用户确需转化时才安排行动号召。

广告把卖点落到可观察的使用动作、细节或结果；不能虚构效果、数据和对比结论。解说让画面展示关系、变化或例子，避免把旁白逐句变成不相关风景。情绪片允许停顿与重复，但要说明重复中发生的变化。

分镜记录可按任务简化：镜号、时长、叙事任务、起点、人物行动、摄影动作、终点、声音、衔接条件。不要要求用户填写完整表格。按动作完成、信息读懂、对白表演与必要停顿估时，总和对齐目标片长；不把长台词塞进几秒，也不把模型支持的生成时长当成最终必须保留的剪辑时长。

## 连续性清单

先建立空间：人物谁在左谁在右、视线朝向、入口出口、主要道具位置。连续镜头保持运动方向和对话轴线；要越轴可用可见的连续移动或重新交代空间，不把有意跳切一律纠正。

接点比较前镜结束和后镜开始的姿势、动作阶段、持物手、服装损伤、光线与地点。动作衔接在同一行动上接续；视线切换要让被看对象位置合理。反应镜头应由具体信息触发，插入镜头必须提供信息或支持接缝，不能只为凑数量。

声音可以提前引出下个空间或延续情绪，但在工具仅支持片段顺序拼接时，不假称已完成复杂声音剪辑。先核对实际工具参数；无法执行的效果留作明确制作建议。

## 从方案到生成

先检查已有素材能覆盖哪些任务，缺少哪个关键动作才补哪个镜头。为复用角色、道具和场景规定稳定项，为当前镜头规定可变状态。首帧适合作为可执行动作的起点：人物比例清楚、肢体有活动空间、运动方向留有余地；不要把已完成动作的摆拍当成动作起点。

生成失败时区分身份问题、动作问题、机位问题和剪辑接点问题。改一个主要变量，核对结果后再决定下一步；文字方案修改不自动授权付费重试。已有片段可通过裁剪解决时先评估可用范围，但不得剪掉关键因果来掩盖缺失。
