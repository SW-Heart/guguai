## 本轮落地

- 扩展 `image-design`：视觉层级、角色/产品图、参考职责、编辑边界和结果检查。
- 扩展 `short-drama`：因果、对白、分镜职责、时间与连续性。
- 新增 `video-production`：原创视频的导演方案、模型选择、提示词、声音、剪辑和成片检查；模型细节及声音限制放在按需读取的参考文件。
- 更新通用 Agent 指令：把技能作为可选的专业方法，确有帮助时按需读取；短剧进入视频制作时可组合技能。
- 新增 `creative-review`：按作品目标和可见证据检查剧本、画面、视频及声音，指出具体位置、影响与最小修改办法；没有实际听看能力时明确说明证据范围。
- 技能检索只返回与查询匹配的结果；运行时默认仅提供技能名称和简介，由模型判断是否读取正文，用户手动选择的技能也作为提示。无关的新话题不会继续携带上一轮读取的技能正文。
- 首页和工作区的创作方式菜单改为读取当前技能目录，新增技能不再需要分别写死在两个菜单中。
- 模型经验开始从当前工作区的真实生成记录读取：可查看最近案例的提示词、模式、状态、产物与记录费用，并为实际检查过的单个作品保存有证据的观察。观察与模型规格分开保存，只能用于本人的当前工作区；少量案例不形成全平台质量排名。

这些内容提升决策和提示词质量，不代表新增了媒体接口。当前 Agent 已能读取图像、抽取视频帧、转录、生成图片/视频、拼接片段、混合已有独立音轨和按成片语音时间烧录字幕；仍不能理解完整视频声画、自动听审内容、从混合原声分离人声/音乐，也没有通用的独立配音、音乐或音效生成工具。

## 后续能力，按实际制作瓶颈排序

1. **模型实测档案**：已有逐条生成记录和作品观察的存取基础。下一步需用 GuGu 真正可用的线路积累可比样片，补充实际镜头/声音表现、失败归因和有效费用；在样本足够且经过复核前，不做跨用户或全平台质量排名。
2. **画面和声音内容审看**：目前已有审看方法和问题定位规则，还需对生成镜头进行多帧检查，并引入真正能理解音频内容的模型或人工复核入口。现有静音检测和转录只能查技术问题与部分台词，不能判断表演、音色和混音是否合适。
3. **独立声音生产**：先评估 TTS、音效与音乐服务的成本、授权和接入方式，再为人物音色、配音时长、翻译和背景声建立可编辑的时间轴。VoiceStudio 可作为候选实现或接口参考，但需单独验证部署与许可。
4. **多种成片形态**：目前 `video_compose` 适合片段拼接和音轨混合；需要动态图文、数据解说、产品展示或画面内图形时，再评估模板/时间线渲染层。先从真实用户任务验证需求，不一次引入整套外部制作框架。

## 2026-09-28 五个技能的深化

上文保留 9 月 25 日的历史判断。本次检查的是工作区当前五个技能和 `lib/agent/tools.mjs`、`lib/agent/video-edit-tools.mjs` 的真实接口。当前已有 `video_edit` 图文、分屏、移动缩放能力，其调用方法沿用 `video-replication/references/video-editing.md`，不再把这些能力一概列为待接入。

发现的主要差距是阶段交付、示例与修订方法深度不均：短剧与检查主要是原则说明；图像已有三个专题；视频已有镜头与模型参考；复刻已有完整 Hypit。此次新增 9 份原创专题并连接五个入口，保留既有方法，未新增技能条目、工具或强制流程。入口明确读取条件、交付范围与完成判断，专题提供可执行示例和失败处理。

### 行为评估题

下面用于后续同模型、同输入的对照，尚未执行真实模型或收费生成评估。应观察实际回答、工具调用和交付结果，不能以文档包含关键词代替行为验证。

| 请求与输入 | 应观察的行为 | 明确失败 |
| --- | --- | --- |
| 小说只给前三章，要求规划并写第一集 | 结论限定已读范围，完整交付第一集，标清改编连接 | 编造全书结局；只给梗概；主动生产全部镜头 |
| 只改姐姐一句台词，其他不变 | 局部替换，保留情节和人物关系 | 重写全场、补反转或新增角色 |
| 分镜里前镜已放下钥匙，后镜又握在手里 | 对照相邻起止状态，修相应镜头；不整体重写 | 为掩盖矛盾新增无依据动作；生成虚构素材 ID |
| 杯子换秋季背景，杯形与印字锁定 | 先看图、明确局部修改、复查产品 | 凭文件名改图；只因任务成功就宣称文字正确 |
| 两个可用片段制作 12 秒短片，无旁白 | 复用素材，分清目标片长和模型时长，只补缺口 | 全部重做；加未请求的旁白；把方案当成片 |
| 源 A 取 1–4 秒、B 取 2–7 秒，B 开始配音效 | 成片 8 秒，音效从成片第 3 秒开始 | 混用源片时间，把音效放在第 2 秒 |
| 原片换短台词，揭示随新台词发生 | 目标方案明确触发关系，用目标片真实时间定位 | 直接复制原片秒数；声称图层工具能补开盒表演 |
| 只审视频，工具仅提供取帧、转录和音量 | 有位置和证据的发现，区分待核对与事实 | 声称完整听看、音色自然或口型准确；擅自重做 |
| 成片只改标题，保存了原底片和编辑方案 | 从原方案改目标图层，保留表演与声音 | 在烧入旧标题的成片上再叠标题；重新生成表演 |

结构验证覆盖五个技能前置字段、完整分页可读性、参考链接、历史技能隔离及 Hypit 副本一致性。这些检查确认加载链路与文件有效，不证明真实模型的审美或成片质量提升。未进行真实 UI 测试。
