# GuGu 读取补充：多人身份与取帧

原版完整阅读方法通过 `skills_read` 读取 `references/hypit/references/creation/reference-video.md`。本页仅保留 GuGu 在多人身份与取帧工具上的补充，不替代原文。

## 多人对话与移动镜头

全片不同角色数来自跨时间核对后的角色清单，不是单帧人数、各帧人数相加或单帧人数的最大值。先用 A、B、C 等临时编号标记可区分的人物，再记录每个取景中有哪些编号。画面左、中、右只是当时的位置，不是身份；出画不等于退出故事，再次入画也不等于新增角色。

先取得覆盖开头、中间各段和结尾的概览帧，保留各次取景中人物清楚的画面。看到组合、朝向或背景变化，再回看变化前后；快速甩镜中的模糊帧适合定位变化，不适合单独辨认人物。`video_boundaries` 只提供画面变化候选：未检测到切点不代表人物组合没变，检测到切点也不证明发生了剪辑。平移、推近、遮挡与人物从边缘进出都可能需要补看。不要把“每秒一帧”或固定张数当作看全的证明。

为影响改编的角色保留简短记录：`编号｜可区分的外观组合｜证据时间点｜同框角色｜身份疑点`。结合脸部可见特征、发型、服装结构、配饰和前后运动连续性判断；颜色相近不能直接合并，服装或站位改变也不能直接判成新人。只见局部或侧脸时保留候选关系，找到清晰参照再核对。不要从外貌推断国籍；目标国家、语言和口音属于用户要求或目标方案。

当前 `video_frames` 每次最多返回 6 帧，新一批会替换当前提供给模型的上一批图片；已读取的时间点仍会记录，但不代表旧图片仍在眼前。比较身份时，把早、晚两处及必要的中间画面放进同一次调用，看到返回图片后再判断，避免连续取多批却没有逐批核对。需要跨批分析时先保存观察，再重新调取关键对照帧。当前取帧保留完整画面并缩放，不自动裁边；人物在原画面边缘不完整、运动模糊和细节不足应分别描述，不编造工具裁剪原因。

例如，早段为 A、B，中段为 C、D、E，尾段为 D、E、A；只有完成身份对照后，才能归纳为五位角色，尾段的 A 是再次入画。同样是粉色服装的 A 和 C 可能是不同人，尾段换了位置的 A 也可能仍是开头那位。例子是核对方法，不是对其他视频人数的预设。

把这些判断写入现有 `source_observation_write` 的概览和带时间证据的视觉事件，区分明确人物、疑似对应和待核对部分；证据时间是实际观察点，不能据此捏造精确的首次入画、离开时刻或声称逐帧看完。转录中的说话人标签、画面字幕或谁站在中央都不能单独证明谁在说话。对会影响改编的台词归属，用相邻画面中的口型与动作、转录时间和上下文交叉核对，仍不能确定则保留待核对。

当开头、各段与结尾的出镜组合已有依据，影响改编的身份疑点已解决，就进入方案，无需无目的地逐帧扫描。仍有疑点时只补看相关区间，并表述为“目前确认至少 N 位，另有一位待比对”等实际状态。发现先前误判后，同步修正已保存的观察和受影响的方案，再继续制作；不要只在回复里改口，或继续沿用错误的角色数。用户只需看到角色、出镜安排和必要的不确定处，不需要内部编号与工具流程说明。

目标复刻保留关系，而不机械复制表面：切换画面的原因、某个词触发的揭示、商品信息出现的时机、声音与情绪的对应。目标台词或节奏改变后，相关事件要随意义重新定位。最终用真实成片播放和检查来验证这些关系。
