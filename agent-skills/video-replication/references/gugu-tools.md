# GuGu 执行适配

此页替换 Hypit 原文中的执行接口，不删减其导演方法。先读取本页，再按当前问题读取相关原文。原版保留英文是为了避免翻译缩写丢失判断；对用户仍用用户语言，称“创作要求、制作方案、台词、原片分析、画面安排”，不暴露内部名称。生成范围先遵循技能入口的连续性原则；镜头分析不直接决定生成请求数，具体判断见 [交付与变更](adaptation-delivery.md)。下列工具必须存在于当前会话才可调用，参数以实际工具定义为准。

## 工具对应

| Hypit 操作或职责 | GuGu 执行方式与边界 |
| --- | --- |
| `hypit media probe` | `video_probe`；音频素材用 `audio_probe` |
| `hypit media frames / tile / tiles`、snapshot | `video_frames` 每次最多 6 个时间点，返回帧逐批查看；没有逐帧网格或 HTML snapshot 等价接口，不把稀疏抽帧当连续观看 |
| `hypit media boundaries` | `video_boundaries` 提供候选，随后取帧核对；检测结果不代表语义镜头 |
| `hypit transcribe`、WhisperX 对齐 | `audio_transcribe`，每段最多 300 秒，语言使用当前枚举；`source_transcript_read` 每次读取最多 90 秒的原片时间范围。不是 Hypit/WhisperX 同一实现，也不保证识别或逐词时间无误 |
| 原片观察与证据 | `source_observation_read/write`，先读 revision；观察关联实际帧或转录词句，区分事实、推测和未知 |
| 查看图像与已有素材 | `assets_search` 查找、`assets_inspect` 读取真实图像；从返回值取得素材 ID |
| vocabulary、Kit、Model/Provider 包参数 | `models_list`、`models_describe` 查询当前能力；原文 Kit 保留为写法与创作例子，外部字段如 `person-reference` 不直接填入 GuGu。`models_experience` 仅供工作区真实案例参考 |
| 图像/视频生成、plan/build | 先核对单次能力，连续画面优先一次生成；`media_prepare` 核对模式、素材、报价，按平台确认或自动生成预算授权 `media_submit`，用 `jobs_wait` 查进度。不能绕过费用确认，也不因原文要求试镜而自动增加付费任务 |
| Run Candidates、复用 Outputs | 保存真实任务与素材 ID，读取已有成功结果并明确引用；失败只重做受影响部分，不重提状态未知的付费任务 |
| 作者文件、项目记忆 | `documents_read/write` 保存文稿与决策；已有文稿按 revision 修改。`workspace_read` / `project_edit` 仅在需要项目镜头/角色节点时使用，采用当前结构和返回的 ID |
| ExtractAudio | `audio_extract` 取得混合原声，不是人声/音乐分离 |
| 剪段、拼接、已有声轨混音、成片导出 | 仅在作品确需裁剪、拼接或混音时用 `video_compose`，不是生成后的必经步骤；单次生成已满足目标时直接检查并交付。最多 20 段、300 秒、8 条独立音轨，可逐段原声调节或静音。只有确需声音且已具备素材时使用音轨 |
| 图文、B-roll、分屏、图形运动与按词触发 | `video_edit` 添加文字、色块、图片、无声视频，支持移动、缩放、淡入淡出；按目标底片转录词句或秒数定位。`video_edit_read` 读取原底片与可重用方案。详见 [画面编排](video-editing.md) |
| Caption 渲染 | 决定需要字幕后，完整转录最终混音成片，再 `video_caption_burn` 生成普通或逐词字幕；精确 Cue 造型、逐角色图形样式、头部跟踪并非等价支持 |
| 检查预览/Result | `video_probe`、`video_frames`、`video_audio_check`、`audio_transcribe` 分别核验技术信息、采样画面、音量/静音与识别台词；提供真实成片并请用户听看，不能声称已完成音频理解 |

工具名字是实际接口，不能把表中概念写成另一个不存在的调用。图像/视频引用必须通过工具实际支持的字段绑定素材；在正文提到参考视频或首尾帧不等于已传入。

## 保留原文的数据职责

Brief 记录用户目标、事实和授权；Treatment 记录新作品的创作设计；Analysis 解释原片整体；Timeline 保存可定位的原片观察；Script 是唯一权威目标台词；Progress 记录当前问题与下一步。用可编辑文稿承载这些职责，可以是一个文稿的清楚分节，不要求机械创建六份文件。完整目标台词只维护一处，原片转录与目标台词分开。

Selections 对应有意义的词句范围，Moments 对应揭示、判断、交接等事件。先在方案中记录“哪个词或动作触发哪个画面/声音”，接受目标片表演后，用其转录时间重新定位。原片时间仅定位参考证据。图层的词句锚点由 `video_edit` 在每次渲染前从目标底片真实转录解析，换底片后可重新定位。它不自动重排片段剪辑或独立音轨；台词或素材变化后须核对、更新受影响的裁剪、字幕与音轨时间。

A-roll 是承载段落的表演，B-roll 是为论述提供信息的补充画面，不按画面大小机械区分。Caption 跟随语音，Typography 承载独立文案，MG 是可持续变化的图形系统。仍按原文区分这些职责，记录内容、空间、进入、持续、变化和退出；实际呈现限于已提供工具。

## 无等价能力的操作

- Hypit CLI、安装、Profile、Credential Store、HypiHub、本地 WhisperX 与 Provider 配置：由 GuGu 平台服务配置承担，当前创作 Agent 不安装环境或索取服务商密钥。原文 environment 资料仅解释原项目背景。
- 任意网页视频下载、浏览器录屏、截图网站：当前没有对应调用。链接不可直接作为已读素材；需要用户提供可访问的视频素材后继续依赖它的分析。
- 任意 SVML/SVS/SVRun 编译、自定义代码组件、复杂转场、头部跟踪字幕、透明视频抠像：当前没有等价接口。常见 MG、图文叠加、分屏和移动缩放已可用 `video_edit` 组合实现。保留原文的设计方法，交付具体设计与缺项；可提出可执行替代方案，但未经用户接受不把简化版宣称为完整复刻。
- 独立音色设计、声音克隆、配音、音乐/音效生成、混合音轨声源分离：当前工具不具备；可采用已有授权素材或当前视频模型实际支持的声音能力。原文声线指导仍用于人物表演，不能承诺音色锁定。
- Studio 连续播放、Comments 反馈页、直接听审：没有对应 Agent 观察能力。提供成片供用户带时间反馈；抽帧、转录和静音检测不等于看完听完。

原文命令、XML/代码和模型参数示例用来解释原项目行为；调用前转换为本页的真实工具字段。没有映射的能力先查当前工具定义，仍没有就说明缺项，不执行原文命令、不编造完成结果。
