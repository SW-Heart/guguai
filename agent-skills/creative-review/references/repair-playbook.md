# 从发现到最小修订

用于用户要求直接改稿、修图建议、修成片或复查已有修订。先读取当前版本和相关要求，区分“建议修改”和“实际已修改”。

## 问题归属决定改哪里

| 已有证据 | 优先改动处 | 保留内容 | 修后核对 |
| --- | --- | --- | --- |
| 剧本未给人物行动理由 | 相关场景的因果连接 | 已定人物、结局、无关台词 | 修改后人物选择是否有依据 |
| 剧本动作明确但分镜漏掉 | 对应镜头覆盖 | 剧本及其余分镜 | 信息是否进入画面/声音 |
| 描述同时要求相互矛盾的运动 | 镜头描述或起止构图 | 人物与叙事任务 | 运动在空间上是否成立 |
| 描述清楚但生成片段没有完成动作 | 参考职责、动作容量或该片段 | 已成功镜头 | 实际动作及相邻接点 |
| 片段完成动作但拼接剪掉关键部分 | 源片入出点或镜序 | 原始生成片段 | 修改后完整动作、片长与对白 |
| 字幕遮脸或文字层出现过早 | 对应图层版位或时间 | 底片、声音与其他层 | 出入场、阅读时间和人脸位置 |
| 有声源但成片无声 | 静音开关、音量、音轨位置 | 素材与台词 | 最终成片音轨和待听审范围 |

按证据选择，不因为“效果差”就整体重写。后期缩放不能补出素材里从未发生的动作；替换配乐不能修复台词归属错误。

## 原创示例：对白挤在过短镜头

镜头安排要求人物先从屋外进来、锁门，再说完两句较长台词，整个镜头只有很短时长。此时只能先指出计划容量风险，不能说已发生吞字。修法按锁定内容选择：保留台词则拆动作与对白，片长不能增加则压缩未锁定的重复内容。用户两项都锁定时提出明确取舍，不擅自删句。

复查对象是新分镜中的发声空间、停顿和片长之和；若已有生成视频，再检查真实转录与动作证据。预估合理不证明成片一定讲完。

## 原创示例：图像“看起来不专业”

观察到主标题、产品和折扣贴纸占据近似视觉重量，且贴纸遮住产品标签。必要修正是露出用户要求保留的标签；标题或产品谁做第一焦点由用途决定。可给具体局部方案：“将贴纸移至右上空白处并缩小，保留原文；产品轮廓、标签和背景不变。”

不可从这条观察推出必须换色、换字体、换构图；修改后需要同时检查标签露出和文字是否仍清楚。模型若改坏产品轮廓，不能因为贴纸修好就宣布完成。

## 原创示例：标题叠了两次

先读取 `video_edit_read` 看是否存在原底片与图层方案。若旧文字已在底片里，而本次又叠新文字，仅移动新文字仍会留下旧内容。使用保存的原底片修改原图层并重新渲染；没有干净底片时说明局限，不承诺无痕恢复。保留声音、其他图层和正确的时间关系。

## 改动的传播范围

台词变化会影响预计时长、镜头表演、真实转录、字幕和按词触发的图文；角色造型变化会影响引用该参考的镜头；剪辑入出点变化会影响其后的成片时间。检查这些相关处，不顺带重做无依赖的内容。

文字改稿用 `documents_read/write`，修改项目用最新 `workspace_read` 和 `project_edit`；冲突时重读再改。媒体修订先查已有任务与结果，再决定具体需要的生成；预算允许不代表需要重复生成。

## 复查到哪里就结束

用原问题的证据标准复查修改处，并查看前后相邻部分与保留项。记录已修复、仍存在、当前无法验证的内容，不把“已改提示词”写成“画面已修复”。目标满足后停止；同一问题仍存在时重新定位原因，不无限循环同一修法。
