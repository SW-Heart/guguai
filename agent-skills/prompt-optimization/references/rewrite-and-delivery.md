# 改写与交付

先确定原稿最重要的结果与锁定内容，保留它们，再定位导致不清楚的具体句子。改写不是增加更多形容词：每一项补充都应解决人物、空间、动作、声音、文字或输出要求的实际缺口。

## 把抽象要求落到作品

“高级的香水广告”仍可以保留其风格意图；若用户让你具体化，可补成“磨砂玻璃香水瓶放在浅色石台，侧面柔光显出瓶身纹理，标签朝向镜头，背景简洁”。不要自动虚构品牌、售价或香型。

“女孩很纠结”可以在用户允许设计表演时变成“她拿起信封，手指停在封口，随后把信放回桌面”。这是创作选择，不能声称原稿已有这项动作。原稿指定大笑、舞蹈或直接演示时保留，不硬加隐藏情绪或戏剧冲突。

“镜头推近，同时绕人物旋转、拉远、升空”先判断动作是否在同一时段；存在冲突时说明并提出一个主动作或连贯先后，不悄悄丢弃用户的硬性要求。深入拍法用 `video-production` 的运镜资料。

## 素材与短稿

人物照片提供外貌、视频提供动作、场景图提供空间时分别说清。素材标签按当前接口和真实输入保留，包括空格、大小写、文字与顺序。描述中的示例序号不代表已绑定素材；没有素材时交付标明缺项的模板。

压缩时优先保留身份、真实素材职责、动作与终点、精确台词和必须保持的内容。风格不是默认的删除对象，镜头和声音也不是每条短稿必须补齐的固定栏位。

## 比较与核对

交付一份完整可复制改稿，而不是只有修改建议；用户要多个方向时才给对应版本。简短说明有实质影响的变化，例如“保留原对白，把同时发生的两个动作改成明确先后”。生成结果失败时引用实际位置、报错或用户报告；若同时改了多项，标为组合修订，不把结果归因于某个词。
