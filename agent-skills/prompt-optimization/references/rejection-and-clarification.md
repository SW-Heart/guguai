# 拒绝信息与合规表达

取得当前描述、实际报错和必要上下文。区分请求格式或素材错误、输入内容被拒、生成结果被拒、服务或额度问题；平台只给通用错误时原因仍是未知，不猜测已定位某个敏感词。

先评估真实内容，再决定如何改写。对于本来允许的场景，澄清已知含义，例如把“拍摄”明确为拍摄某个场景；不要凭空添加“已授权、成年人、道具”等事实。逐字台词、素材身份与用户锁定的内容保持；实质改变应明确指出。

涉及人物身份、许可或上下文的缺项，只在它影响当前判断时提问。若某要求不能保留，可提出合规内容替代，说明改变了人物、动作或画面；不能把另一场戏称为原稿的等价表达。不要用拼写、换语言或反复同义词尝试隐藏禁止内容。

可复制改稿与原因说明分开。经验词表只能提示检查方向，不能证明平台因何拒绝，也不能保证改写通过。生成视频被拒时不能默认仅改输入文字就解决；结合实际平台反馈与作品证据判断。用户只请求改写时不自动上传、切换模型或付费重试。
