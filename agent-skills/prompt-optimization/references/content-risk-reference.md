# 内容风险与候选表达参考

核对日期：2026-10-06。用于图像、视频提示词报错后的内容诊断与最小范围澄清，不是供应商完整禁词库。以下候选表达为 GuGu 根据公开类别整理的检查线索；出现词语不等于违规，未出现词语也不等于安全。不得声称已定位上游禁词或保证通过。

## 先确认反馈指向什么

- 只有“上游拒绝生成，请修改提示词后重试”：可以开始优化检查，但原因未知。先看原文是否有真实歧义，不凭报错臆造敏感词。
- 火山方舟公开错误码区分输入文字和输出媒体：`InputTextSensitiveContentDetected` 指向输入文字；其 `.PolicyViolation` 可能涉及版权；`InputTextRiskDetection` 可带 Label/SubLabel。`OutputImageSensitiveContentDetected`、`OutputVideoSensitiveContentDetected` 指向生成结果，不能证明某个输入词被禁止。输入图片问题也不能仅凭改词解决。[官方错误码](https://docs.volcengine.com/docs/82379/1299023)
- Google Gemini 公开安全类别包括骚扰、仇恨、性露骨内容和危险行为，并对儿童安全设置额外保护。存在类别反馈时优先据此检查上下文。[官方安全说明](https://ai.google.dev/gemini-api/docs/safety-settings)
- Imagen 的输入、输出分别审核；安全属性与过滤器并非一一对应。健康、政治、宗教等属性出现不代表一定被禁止。只在确定模型和错误来源时使用它的 support code，不将它套到 Seedance 或其他供应商。[Imagen 官方说明](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/image/responsible-ai-imagen?hl=zh-cn)
- Veo 的反馈还可能涉及儿童、名人、第三方内容等限制；要区分内容问题与人物生成设置、功能许可问题，不虚构授权来处理。[Veo 官方说明](https://docs.cloud.google.com/vertex-ai/generative-ai/docs/video/responsible-ai-and-usage-guidelines)

## 候选词句与上下文检查

下面是编写者整理的候选项，不是官方禁词。必须同时阅读人物、动作、对象、目的、镜头及前后句，判断实际要求；不得执行机械替换。

| 检查方向 | 候选词句或组合 | 必须判断的上下文与处理边界 |
| --- | --- | --- |
| 性露骨、性化表达 | 裸露、脱衣、性行为、私密部位特写、挑逗 | 区分普通服装、艺术、医学语境与实际性化要求。允许内容只澄清原文已有含义；不得把明确性行为换成暗语继续表达。 |
| 儿童安全 | 儿童、学生、少女与性化动作或身体特写的组合 | 儿童、学生本身不是禁词。涉及性化或剥削时不做同义改写；不能自动把年龄改成成人或删掉年龄伪装原意。 |
| 暴力、伤害、血腥 | 杀死、砍断、流血、伤口、尸体、虐待、爆炸 | 区分非血腥剧情、体育动作与真实残酷伤害。不能未经授权删除核心动作或把真实武器、伤害改成道具、表演。 |
| 仇恨、骚扰、粗俗 | 针对身份群体的侮辱、灭绝主张、羞辱、脏话 | 判断是否在鼓励攻击，还是引用、批判、教育。锁定对白不能擅改；不把攻击对象隐藏后保留原有伤害意图。 |
| 危险、违法活动 | 武器制作、犯罪步骤、毒品交易、恐怖行为、自伤方法 | 判断是否提供实施帮助。中性的影视、新闻或安全教育描述不机械删除；实质危险要求不能通过模糊表达保留。 |
| 真人、名人、隐私 | 真人姓名、名人肖像、身份证号、住址、银行卡、模仿真实身份 | 看实际模型限制、肖像与隐私上下文；不能补造许可、认证、虚构身份。参考图被拒时不自动改人物身份。 |
| 第三方内容、版权 | 逐帧复刻、原片片段、指定受保护角色、原版音乐 | 看反馈是否明确指向第三方内容。不能用暗示性外形描述隐藏同一复制要求；需要改成原创内容时交由用户决定。 |
| 语义歧义、否定句、引用 | 英文 shoot、成人礼、“不要出现血腥”、否定句里的高风险词 | shoot 可能是摄影也可能是射击，必须按对象判断；成人礼不能按“成人内容”理解。否定句或引用并非自动违规，只有存在可靠等价表达且不改变约束时才澄清。 |

## 风险词表与扫描

系统维护一份分级风险词表 `references/prompt-risk-lexicon.json`，用户提交生成前的检查与自动优化共用。Agent 调用 `prompt_risk_scan` 得到命中，不要整份读取词表。每个命中带有：

- `level`：`banned` 大概率被国内上游拒绝（露骨色情、国家领导人、敏感政治事件、暴恐、血腥残忍、侮辱用语）；`suspect` 取决于上下文；`off` 只是需要细读的线索。
- `risk`：对应国家标准 GB/T 45654-2025《生成式人工智能服务安全基本要求》附录 A 的风险编号，例如 A.1.6 暴力与淫秽色情、A.3.1 知识产权、A.4.2 肖像权。
- `combo`：组合规则命中，例如未成年人与性暗示出现在同一句，此时单独看都正常的词也会标为 `banned`。
- `review`：该类词的核对要点，按上表的上下文边界判断。
- 级别已按模型调整：GuGu 线上记录中，同一段脱衣与身体特写的描述 Seedance 2.0 多次拒绝、MiniMax 通过；GPT Image 按语义判断，否定句里的敏感词通常不受影响。因此同一个词在不同模型下级别可能不同，扫描时传入目标模型。
- Seedance 的 710082022（“疑似包含侵权/违规内容”）在 GuGu 线上基本由提示词触发，但也出现过原文不变重试即通过的情况；改写前先确认原文确有风险命中。
- 自动写进描述的“不生成色情、露骨、挑逗内容”这类安全声明，会按字面触发 Seedance 等模型的审核。不要为了合规添加这类声明，已有的建议直接删除。

banned 命中不能靠同义词、谐音、拆字或换语言改写后继续保留原意；只能如实告诉用户哪句很可能导致失败，由用户决定是否改变内容。suspect 与 off 命中按上下文判断，正常场景保留原词。扫描结果为空不代表安全。

## 自动优化如何使用

先在内部区分“反馈明确指出”“原文可能有歧义”“无法判断”。通用报错下只能提出有上下文依据的候选问题；原稿本身清晰、反馈指向素材/输出/参数，或不存在可靠等价表达时返回空 replacements。

可以做的局部澄清示例（GuGu 编写，非平台通过案例）：原文已有“摄影师拍摄街头”的含义时，将歧义英文 `shoot` 明确为 `photograph`；不能将“向人开枪”的 `shoot` 改成摄影。不要把中文“拍摄”本身列为违禁词。

第二轮读取第一次的原句、替换结果与新报错。相同通用报错不代表上一轮锁定了真正原因；重新检查其他有依据的歧义，不重复替换、倒换或升级为整体重写。不能保留原意时停止自动改写。任何谐音、拆字、换语言、编码或隐喻式规避都不是合规优化。

本参考只放在 agent 资料中；页面无需展示审核类别、候选词或内部诊断规则。来源更新或某供应商新增明确规则时，按模型范围更新词表对应分组并重新核对来源，许可与署名见 `references/prompt-risk-lexicon-NOTICE.md`。
