# 角色设定与参考图

## 可复用设定

设定从作品需要出发，包含人物在故事中的作用、行为方式、重要关系、外貌轮廓、服装与配色、必要道具，以及允许改变的状态。只要求视觉角色时减少背景传记；只要求人物小传时不强制多视图或付费出图。

示例：用户邀请设计一位原创成年飞行信使，可以选择短发、浅色飞行夹克、深色长裤、斜挎邮包作为识别锚点。夹克色块、邮包肩带方向和固定发夹在各视图保持；信封、表情和姿态可随场景改变。这些是新创作选择，不能声称来自未读取的照片。

## 参考职责

面部图控制外貌，服装图控制衣着与材质，姿态图只控制动作，风格图只控制画法或光色。参考存在冲突时说明每个维度以哪份为准；不会自动把姿态图的人脸和场景也复制。用户给定真实人物参考时根据真实授权和平台能力处理，不凭措辞杜撰许可。

## 视图与表情

正面、侧面、背面与三分之四视图按用途选择，不把“多视图”一律解释为必须九宫格。全身图要能辨认体态和服装结构，面部参考留足脸部信息，重要饰物在看得到的视角保持位置。各视图数量、同图布局和独立文件按用户需求与实际生成能力决定。

表情设计写情绪与一个可见动作，避免罗列互相冲突的面部肌肉。角色本来要求热烈、喜剧或夸张时保留其能量，不强制克制微表情。人物运动和摄影不在设定表里堆参数，实际拍摄用 `video-production`。

## 结果偏差

以真实图片定位面部、发型、服装、道具或画法哪个维度漂移。保留成功版本，优先修改对应参考职责或局部图片。背景不同不等于身份失败，服装不一致也不能只用“更像同一个人”修复。出图参数、序号和素材 ID 来自工具真实结果，不能从模板猜测。
