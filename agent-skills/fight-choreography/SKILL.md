# 打戏创作

先把动作搞对，再把打斗连起来，最后才让镜头好看。发生冲突时严格遵守：**剧情事实 > 武器力学 > 攻防因果 > 空间连续 > 人物设定 > 可生成性 > 镜头特效**。不得为了炫技、迎合人设或方便生成而破坏武器结构、攻击距离与重心逻辑。若锁定剧情与物理规则无法同时成立，指出矛盾并给出最小调整建议，不悄悄改写事实。

读取当前剧本、人物、兵器和前后镜头，保留已确认内容；局部修改只改受影响的回合及其衔接。只为影响结果的关键缺项提问，其余作为明确的创作假设。只请求编排或改稿时交付文字，不自动生成媒体。实际拍法、声音、生成与剪辑按需读取 `video-production`；指定视频模型时结合对应模型技能，不让模型写法覆盖动作约束。

## 1. 初始化战局

编动作前锁定双方能力、体型、武器、目的、初始位置、距离、朝向、障碍、伤势、体力、优势方和总时长。能力包括已建立的特殊能力及限制，不得临时补能力解围。武器说明长度、握持方式、持械手和数量；投掷物逐次扣除，掉落、拾取、转交均须有动作。

第一回合建立地标、双方站位、相对朝向、距离与动作轴线。用地标和人物相对位置记录空间，不把画面左右作为唯一坐标。

逐镜维护起手状态（Start State）与收招状态（End State）：位置、高度、朝向、持械手、武器位置与姿态、支撑脚、重心、伤势、体力、剩余物件和优势方。**上一镜收招状态必须无缝接成下一镜起手状态**。机位变化不代表人物换位，伤势、疲劳和物件损耗不能在切镜后重置。

## 2. 按武器选择动作

| 类型 | 动作库与约束 |
| --- | --- |
| 枪矛 | 刺、戳、点、挑、拨、架、压、扫杆；区分枪尖与杆身路径，绝不能当大刀狂劈 |
| 刀 | 劈、砍、斩、削、撩、格、拖切；明确刃线、接触方向与回收路径 |
| 剑 | 刺、削、点、撩、格、压剑；剑尖、刃线与对手反应对应 |
| 棍 | 扫、砸、戳、挑、架、拨；表现杆身轨迹、惯性和持握空间 |
| 锤 | 砸、抡、撞、压；重击之后必须恢复，不能无停顿连续重击 |
| 匕首 | 刺、割、挑、贴身控制；接触距离须成立，不能隔空命中 |
| 软兵器 | 甩、抽、缠、套、拉；写出惯性、张弛、运行空间和回收过程 |
| 拳脚肘膝 | 距离正确、支撑脚稳定、腰胯发力顺畅、重心转移可见；腿法后交代落地与重新支撑 |

动作库由实际结构与已建立能力限定，不为丰富招式赋予武器不存在的功能。

## 3. 编排完整攻防回合

按因果推进：**起手 → 意图 → 攻击 → 对手反应 → 空档 → 反击 → 位移 → 收招 → 结尾**。说明上一动作怎样造成下一动作的条件，不能堆叠互不相干的招式。反击被封住或主动脱离时，交代原因与后果，不强迫双方机械轮流命中。

每个动作都有战术目的：抢距离、封路线、逼退、制造空档或脱离。反应由看得见的来势、遮挡、失衡或判断触发。结尾交代回合怎样改变位置、优势、伤势或人物目标，不只写漂亮定格。

## 4. 检查距离、空间与打击恢复

远距离考虑长枪、投射；中距离考虑刀剑棍、拳腿；近距离考虑短刀、肘膝、控制。按实际兵器长度、步幅和接触点校准，不把分类当作隔空命中的许可。长兵器被贴近时须表现调整距离或握法的过程。

进退、绕行、转身、跃起、落地、换手、换位都交代起点、移动过程和终点；障碍实际限制路线。禁止瞬移、突然换手、状态重置和无过程穿越障碍。

命中或落空都沿工具逻辑处理：刀剑看刃线、接触与避让；枪矛看枪尖路径和偏转；棍锤看惯性与身体位移；拳脚看头躯偏转、支撑变化与失衡。不用光效、震屏或音效代替实际接触和身体反应。

**攻击之后必须有收招**：按动作安排回收、落地、换脚、回架、恢复重心或重新建立距离。被打断时表现失衡、受阻与补救，不直接跳到下一次完整攻击；重武器和软兵器尤其不能省去恢复与回收。

## 5. 动作成立后再设计镜头

动作与摄影分开写。每镜明确景别、机位、运镜、方向、速度、跟焦主体；固定机位也明确写出。摄影服务于看清攻防、距离与结果，不替人物完成位移。

- 一镜到底用于空间换位、连续兵器轨迹、环境互动；路径须容纳人物和兵器。
- 快切用于近身爆发、打击反馈、高密度交换；切点依附接触、格挡、落地、回架等真实动作节点，接点保留同一动作阶段。
- 跨轴通过可见机位移动或重新交代空间建立方向，不能让观众误认双方互换位置。
- 为可生成性做减法时减少并行动作、拆分回合或简化运镜，保留完整因果、移动与收招。总时长容不下时减少招式，不压掉恢复时间。

## 6. 输出与交付检查

完整编排默认按以下模板输出，按真实动作及恢复时间分段，时段总和对应总时长；局部改稿或检查只展开相关内容。用户可见内容用中文，不把内部状态字段名当作台词或画面描述。

```text
【战局设定】双方能力、体型、武器与数量、目的、位置、距离、朝向、障碍、伤势、体力、优势方、总时长；必要假设。
【武器力学】本场动作库、结构与距离限制、惯性及恢复要求。
【时间线推进】
第 N 段｜起止时间
目的：本回合的战术目标及剧情作用。
镜头：景别、机位、运镜、方向、速度、跟焦主体。
起手：双方位置、高度、朝向、持械手、武器姿态、支撑与重心。
意图：想迫使对手做出什么选择。
动作：攻击路径、步法、接触距离与先后关系。
反应：对手如何应对，由此产生什么空档与反击。
打击：接触或落空、偏转、位移与失衡结果。
收招：回收、落地、换脚、回架、恢复重心与距离。
结尾：回合结果和下一段可直接承接的双方状态。
连续性：核对上一段收招与本段起手、本段结尾与下段起手。
硬性锁定：本段不可改变的剧情、兵器、持械手、物件数量和空间事实。
```

交付前逐项排除：武器功能错配、枪矛乱挥砍、软兵器无惯性、拳脚无重心、腿法无支撑、投掷物数量突变、重武器连发无恢复、人物瞬移、孤立招式堆砌、无过程换手换位。发现问题先修动作，再核对衔接，最后调整镜头。未实际生成或观看成片时，只说明文字编排已检查，不宣称画面已验证。
