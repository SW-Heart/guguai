# Seedance 2.0/2.5 创作圣经

将用户的故事、分镜或原提示词改写为目标版本能理解的拍摄指令，保留题材、人物、逐字台词和创作意图。依据用户提供的两份指南整理；文档能力与 GuGu 当前可执行能力分开判断。

## 先判断版本和任务

从用户指定模型或当前模型目录确认 2.0 / 2.0 Fast / 2.5。版本不明且会影响时序、素材或模式时先澄清；仍可先整理角色和故事。先读 [版本差异与任务选择](references/version-and-task.md)。不要把 2.5 的时间戳、多视图或素材上限套到 2.0。

区分全新生成的参考任务、原片增删改的编辑任务、向前/向后的延长、严格首尾帧、关键帧参考及多宫格故事板。参考只提取指定维度；编辑列明修改范围和保留内容；延长说明方向、衔接状态与新增剧情。组合任务明确哪份是待编辑原片，哪份只提供参考。

## 提示词调优方法

先把真实素材按上传顺序绑定到角色与职责：外貌、妆造、场景、动作、运镜、音色、音乐分别说明。角色标签持续一致，多人按首次出场顺序准备素材；不要只依赖图片里的姓名或直接把素材 ID 写进提示词。未提供素材时可交付明确的模板占位符；可执行正文只能指向已存在的素材。

以“一句话概述 + 必要素材绑定 + 情节与镜头 + 全程要求”组织正文，结构随任务调整。2.0 用镜头顺序和少量连贯动作；2.5 可用连续整数秒时间轴，动作先概括，只细写关键动作。对白、环境音、音效、音乐和画面文字分别决定；按用户语言回答，台词保留原语言或用户指定目标语言。

每镜只设计一种主要运镜；特殊运镜写明效果与触发点。用可见动作表达情绪，保证动作承接、空间关系和机位合理。精简重复形容词、冲突指令、冗余剧本与无关负向词；精确动作参考已经足够时，不额外复述出矛盾轨迹。

## 交付与检查

提示词请求交付可直接复制的正文、必要素材清单和与原稿相比的关键调整。技术参数单独列出，只有用户需要调用接口时展示字段。模板中的序号必须与实际输入一致；2.5 时间轴连续、覆盖目标时长，留足对白与动作时间。多宫格只提供剧情参考，独立关键帧与接口绑定的首尾帧需要明确区分。

实际生成先查 `models_describe` 与 `media_prepare`；未暴露的编辑、延长、音频或 MOV 参数不可伪造。用户只要优化提示词时交付正文，不提交生成。排查时先改能解释现象的一项因素，保留成功部分；复杂任务必要时拆成参考生成、局部编辑和后期剪辑。提示词约束提高成功概率，不能保证无字幕、身份绝对一致或口型逐字准确；未看听产物时，不宣称已经验证效果。
