# 版本差异与任务选择

本表依据用户提供的 Seedance 2.0 系列和 Seedance 2.5 指南，是写作参考。具体平台能否使用某项能力，须以本次模型与工具返回为准。

| 决策点 | Seedance 2.0 系列 | Seedance 2.5 |
| --- | --- | --- |
| 情节时序 | 镜头1、镜头2、镜头3；精确时间支持不稳定，不依赖时间戳 | 支持整数秒时间段、时间点、相对时间；时间轴连续 |
| 动作密度 | 优先低缓、连续的小动作，写身体部位及速度力度 | 动作先概括，少数关键动作详细写；避免重复动作堆砌 |
| 人物多视图 | 优先独立大头照加全身照，不建议人物三视图/多视图拼图 | 可使用多视图；超过5主体时单视图更稳，不同视角建议分图上传 |
| 参考素材数量 | 通常4–5份足够；指南中的轨道补齐最多3段输入视频、总长不超过15秒 | 总计最多50份：图片30张、视频10段、音频10段；视频合计≤30秒、音频合计≤30秒 |
| 视频长度 | 本指南未提供统一输出上限，查当前模型 | 文档支持单段最长30秒；不等于当前线路均开放 |
| 画幅 | 文档称固定6档，不据此猜每档具体数值 | 文档称可借输入素材控制0.4–2.5之间的任意比例；锁定任务必须顺应输入 |
| 编辑/延长格式 | 不套用2.5的MOV结论 | 输入、输出MOV更利于颜色、亮度和声画衔接 |
| 美学 | 2.0 的风格偏好 | 相同提示词可能不同；续写2.0原片并输出MOV可尝试保留风格 |

## 按创作意图分任务

- **全模态参考**：提取图片的人物/场景、视频的动作/镜头/特效、音频的音色/音乐，创作新视频。写“参考视频1的运镜”，明确参考维度，避免意外复制整个视频。
- **视频编辑**：在原片上增加、删除、替换画面或声音。写“严格编辑视频1，将原特征改为新特征，其余保持一致”。明确时间段、位置、对象和保留项。
- **延长**：延续原片前后剧情，保持人物、叙事和声画风格。直接写“向后延长视频1”，给定衔接状态与新增内容。
- **组合**：参考一份素材，编辑另一份。写“参考图片1的服装，严格编辑视频1，将女主服装替换……”。
- **首尾帧**：需要严格绑定端点时，使用真实首帧/尾帧模式；提示词写“图片1为首帧”本身不能代替接口角色绑定。
- **关键帧**（2.5）：分镜拆成独立图片，按顺序传入，开头写明“以图片1至图片N的顺序作为关键帧”；画面相对严格对齐，仍需检查产物。
- **多宫格故事板**：一张图包含多个分镜，主要提供剧情和镜头结构，不能承诺每格细节严格一致。
- **转场补齐**：写清视频1末态、间隙中发生的变化、视频2起态，以及需要保留的原片内容。

2.0 的编辑/延长对象不要写成“参考视频1”，否则可能被解释为新视频参考任务。2.5 也要清楚区分待处理原片与只提供参考的素材，并按其关键词和角色参数触发正确任务。

连续单场文戏、长对话和单路径运动可考虑延长；复杂追逐、打斗、场景转折可分段生成并剪辑。这里是创作选择，不要求每个任务拆分，也不自动扩展用户的交付范围。
