# Seedance 2.5：提示词与素材

## 基础结构

1. **素材绑定**：按真实上传顺序明确图片、视频、音频编号与职责；多人逐项列清。
2. **一句话概述**：主体、地点、事件、题材/风格及核心拍法。
3. **具体情节**：镜头序号或整数秒时间轴，写画面、动作、运镜、台词与声音。
4. **贯穿要求**：身份、光影、机位、音轨、字幕或风格的一致性。

优先正向描述。参考足够准确时只指定参考维度，例如“严格参考视频1的动作和运镜，顺序一致”，不要又写出不同动作轨迹。白模渲染和粗线稿故事板仍需补齐外貌、场景、美术及缺失动作。

文档说明原生支持10余种语言，但未在本次资料中给出完整语种清单。台词明确目标语言，不据此猜某个小语种必然可用；实际生成先核对线路，并检查发音和口型。

## 素材映射

“图片1、图片2共同对应阿岚；阿岚使用音频1的音色。图片3对应宁舟，使用音频2。视频1只参考施法动作，视频2只参考环绕运镜。”

图片上的姓名不能代替文本绑定。局部参考明确哪一部分；角色在剧情中的首次出场顺序与素材顺序尽量一致。多人时同一标签绑定脸、服装和声音，不临时交换编号。

## 时间控制

以整数秒为单位支持以下三种方式：

- 连续区间：“0–3秒……3–7秒……7–15秒……”；不留下未说明的时间空档，不交叉重叠，覆盖目标时长。
- 时间点：“第5秒快速向左横移转场”，写明触发点、方向和转场方式。
- 相对时间：“按下快门后定格1秒”，动作前后可合理衔接。

时间段过空会增加自由发挥，过密会过度剪切或遗漏。留足完成动作、台词与停顿的时间。不用时间戳控制频率，如“一秒摇头3次”。镜头序号仍可使用，不要求所有提示词加时间轴。

## 运镜与表演

基础景别、推拉摇移跟、低角度/俯视/第一人称可直接写。热门拍法如一镜到底、希区柯克变焦、FPV、子弹时间也可直接写，但要与场景和动作合理匹配。小众术语写“名词 + 效果说明”，例如移焦：前景树木由清晰变模糊，背景人物逐渐清晰。

一个镜头以一种主要运镜为主。转场写清触发点和方式；一镜到底不能同时要求不连续跳切。

动作优先概括，如“双方展开近身搏斗”，只对记忆点动作细写。不将2.0的小动作偏好变成2.5所有任务的限制，也不反复堆砌相同动作。表情用直接描述，如“满足地微笑，大口吃饭”，少用抽象成语。真实人物强烈情绪用肩背、呼吸、嘴角表达，避免把眼神描述成发光特效。

## 素材配置：上限与建议分开

文档支持总计50份：图片最多30张、每张4K以内；视频最多10段、总时长≤30秒；音频最多10段、总时长≤30秒。这是文档上限，实际输入先查模型目录，不能作为推荐用满数量。

| 情境 | 文档的稳定性建议 |
| --- | --- |
| 主体音视频参考 | 1–5主体、每段5–10秒较好；6–10主体或更长可尝试，但稳定性下降 |
| 主体图片参考 | 1–8主体较好；9–12主体稳定性下降 |
| 多视图 | 1–5主体单/多视图均可；超过5主体优先单视图，多视角拆成不同图片 |
| 多宫格 | 少于15分镜，优先简洁火柴人或线稿，避免过多文字、杂乱和过度锐化 |
| 视频编辑 | 20秒以内效果较好，更长稳定性下降 |
| 视频参考图编辑 | 1–5张较好，6–8张稳定性下降 |
| 延长 | 输入、输出均采用MOV有利声画衔接 |

超过稳定性建议不等于违反接口上限。不得自动减少用户明确要求的人数；可建议分任务或分段完成。

## 白模、故事板与关键帧

白模先指定参考什么：运镜、运动、动线、镜头节奏，是否还参考光影。参考图绑定到具体模型对象，例如“图片1的阿岚对应视频1的红色模型”。生成内容描述与白模时序一致。

粗粒度白模优先简单几何体，文档建议仅保留躯体；若含四肢或翅膀，要提供完整动作以免僵化。细粒度白模用于重渲染，移除轨迹线、坐标轴、相机锥等辅助标注，避免泄露到成片。

多宫格是剧情参考，不严格对齐每格细节；线稿不应把目标成片引向素描风，需补充目标风格。逐镜补齐故事板缺少的运镜、动作、声音。概念分镜可简写“按分镜顺序构建故事，运镜连贯”。

更需要画面对齐时，拆成独立图片按顺序作关键帧，第一句说明“以图片1至图片N的顺序作为关键帧”。关键帧参考不自动锁定比例；严格首尾帧另看任务参数。
