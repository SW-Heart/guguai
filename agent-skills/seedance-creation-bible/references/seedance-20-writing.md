# Seedance 2.0 系列：提示词与素材

## 基础句式

| 任务 | 写法 |
| --- | --- |
| 图片参考 | 参考图片N中的主体，生成…… |
| 视频参考 | 参考视频N中的动作/运镜/风格/音效，生成…… |
| 音色参考 | 参考音频N的音色，角色说…… |
| 增加元素 | 在视频N的某位置、某时机加入具有指定特征的元素 |
| 修改元素 | 严格编辑视频N，将原特征修改为新特征 |
| 删除元素 | 从视频N删除指定对象，明确保留的对象、镜头和声音 |
| 延长 | 向前/向后延长视频N，生成…… |
| 轨道补齐 | 视频1 + 过渡画面 + 接视频2 + 过渡画面 + 接视频3 |

编辑与延长直接指代“视频N”，不把待处理原片写为“参考视频N”。未提及部分默认不变；重要保留项可再次明确。

## 进阶结构

精准主体 + 动作细节 + 场景环境 + 光影色调 + 镜头运镜 + 视觉风格 + 画质 + 约束条件。

从“谁做什么”开始，补充地点和氛围，再决定怎么拍。不是必须填满的八项表格；参考素材已清楚表达的信息不必反复复述。

### 主体定义与一致性

- 用2–3个稳定的静态特征唯一识别对象，例如“图片1中穿红裙、戴草帽的女子定义为小禾”。主体也可为道具或场景。
- 多素材同角色统一绑定：“图片1的面部、图片2的服装与体型共同定义为小禾”。
- 多角色分别定义，后续持续用同一标签，少用“他/另一个人”等模糊指代。
- 未提前定义的简单场景，每次用“小禾@图片1”强调绑定；已定义后不必反复写完整外貌。
- 使用素材库时也写“图片N/视频N”，素材ID只用于工具输入，不能替代模型指代。
- 复杂空间优先通过场景图表达，文字补充必要方位、身高关系和视线。

### 镜头顺序

按“镜头1、镜头2……”排序，每镜包含运镜/切换、主体动作与表情、位置变化、声音。优先让模型自然分配剧情节奏，不用0–3秒等精确时间戳控制2.0。

例如：镜头1侧面中景，小禾缓慢走到窗边；镜头2固定近景，小禾停步，手指轻握窗沿；镜头3切至室外全景，灯光照出小禾的剪影。每镜提供新的动作或信息，不只重复“电影感”。

### 动作与情绪

动作明确到手、腿、头、肩背，补充幅度、速度、力度，如“微微低头”“缓慢抬手”“用力蹬地”。优先低缓、轻柔、连贯的动作，复杂爆发动作可借参考视频并减少单次负担；不是禁止武打题材。

前后动作写明承接，例如“借转身惯性顺势抬手”。情绪用可见细节：悲伤可低头、肩膀微颤；紧张可敲手指、急促呼吸；愤怒可握拳、下颌紧绷；释然可呼气、放松肩膀。避免情绪描述与身体行为矛盾。

### 运镜、风格与约束

直接使用全景、中景、特写、固定机位、缓慢推近、平稳横移等标准术语。一个镜头尽量一种主要运镜，不同时要求推拉摇移；需要另一运动时分镜或写清先后转换。

统一风格、色调、光线和材质，如冷蓝低饱和的3D国漫、暖色电影纪实、复古胶片。画质词帮助描述目标，不替代分辨率设置。约束按需要写“保持无字幕”“不要生成Logo”“不要生成水印”；品牌展示任务应保留用户明确要求的Logo，不能套统一排除词。

## 素材准备

通常4–5份：角色图1–2张（大头照/全身照）、场景图1张、运镜视频1段、音频1段。不要为了用满上限而加入冲突参考。最重要的精准参考优先放在提示词前部，并保持真实编号。

人物身份优先独立、清楚、表情中性的人脸特写；全身照控制妆造。人物多视图拼图容易被误认为多个角色。商品多角度参考与人物多视图不是同一问题，商品可明确绑定同一物件。

## 文字与声音符号

对白尽量统一语言（专有名词除外）；非中英文台词明确语种。音乐用（背景音乐描述），音效用<音效描述>，台词用{逐字台词}，画面字幕用【字幕内容】。这是文档推荐的表达约定，不是接口字段。

需要文字时使用常用字，写“内容 + 出现时机 + 位置 + 出现方式 + 颜色/字体风格”。无文字任务不要加入字幕括号或广告文字要求。严谨拼写可用文字图片参考或后期叠字。
