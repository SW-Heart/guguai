# Seedance 2.5：可复制模板

## 双人短剧：连续整数秒时间轴

素材顺序：图片1小禾，图片2宁舟，图片3书店；音频1小禾音色，音频2宁舟音色。无音频参考时删除音色引用，改写声音特征。

```text
图片1中的小禾是首先出场的角色，使用音频1温柔清亮的女性音色；图片2中的宁舟使用音频2低沉平和的男性音色。图片3只参考书店布局、光线和材质。
生成15秒写实情感短片：傍晚书店，小禾把一封迟到的信交给宁舟，暖色电影光影，表演克制。
0–4秒：固定双人中景，小禾站在柜台左侧，宁舟在右侧。小禾伸手递出信封；宁舟停止整理书本，抬手接信。小禾台词（轻柔）：“这封信，是留给你的。”宁舟闭口。
4–9秒：切至宁舟近景，缓慢推近。宁舟低头看信封，手指收紧后渐渐放松，抬头望向小禾。宁舟台词（释然）：“我一直在等。”小禾闭口。
9–15秒：固定双人中景。小禾轻轻点头，宁舟把信握在胸前，两人安静对视。让动作自然结束，保留短暂停顿，无新增台词。
全程保持两人身份、服装、方位和书店环境一致。正常人眼，瞳孔不发光。仅对白、翻书声和轻微衣料声，无背景音乐，不额外加入对白字幕，无水印，无额外Logo。
```

音色与语气风格需和参考一致；不要在台词后再逐句复述内容并追加情绪，这可能诱发字幕。

## 局部编辑：A到B

```text
严格编辑视频1，仅修改4–6秒画面右侧宁舟手中的红色杯子，将其替换为图片1中的白色陶瓷杯。杯子跟随原手部动作，维持透视、遮挡与接触阴影。其他时段、人物身份与服装、表演、背景、机位、镜头顺序、灯光和声音保持一致。
```

供应商参数条件：reference_*角色；ratio=adaptive；duration=-1；建议output_format=mov。GuGu未暴露这些字段时只交付方案与正文，不伪造调用。

## 音频编辑与多语言翻译

```text
编辑视频1，将所有可辨识人声翻译为中文普通话，包括两位角色及背景中的对白、低语、感叹词。按原片角色、说话顺序、情绪、停顿和音量重新配音，保持各角色声线对应，依据中文发音调整口型。
目标台词：
0–4秒，小禾台词（轻柔）：“这封信，是留给你的。”
4–9秒，宁舟台词（释然）：“我一直在等。”
9–15秒，无对白。
不保留原语言人声，不添加任何字幕。除人声语言与相应口型外，保持人物、动作、服装、场景、镜头、环境音和音效一致。
```

先用实际原片对白填写完整译文与时间轴，不能用示范台词替换用户原对白。目标是全片无原语残留、声线不串位、口型同步；没有实际看听就不宣称已达标。

## 向后延长5秒

```text
向后延长视频1，新增5秒，承接末尾小禾与宁舟在柜台前对视的状态。
0–3秒：固定双人中景，宁舟缓慢把信放入外套口袋，小禾微微侧身让出门口方向，动作顺势衔接。
3–5秒：镜头平稳后拉，两人走向门口，暖色窗光照出背影，结束在门口双人中景。
保持原片角色、服装、场景、光影、色温与音色，仅原有环境声和动作音，无新增台词，无背景音乐，无字幕。
```

这里0–5秒指新增片段的相对时间。文档建议输入与输出MOV；确认工具支持后选择。先查输出是否仅新增段再拼接，检查接缝与音量。

## 严格首尾帧与关键帧

严格首尾帧正文：“从图片1的小禾站在门口开始，小禾缓慢走向柜台并递信，最终到达图片2的双人接信构图。保持人物外貌、服装、书店布局和暖色光线连续。”接口必须将两图分别设为first_frame、last_frame，ratio=adaptive，时长按实际允许值设置，图片画幅一致。

普通语义参考可写“图片1为首帧参考，图片2为尾帧参考”，角色是reference_image，不保证严格匹配或锁定比例。

关键帧：“以图片1至图片4的顺序作为关键帧，依次呈现小禾进门、递信、宁舟读信、双人对视，动作与运镜连贯，统一写实暖色电影风格。”各帧独立上传；需要时补连续时间轴。

## 白模渲染与故事板

白模：“视频1只参考运镜、镜头顺序和人物运动轨迹；图片1的小禾对应视频1的红色模型，图片2的宁舟对应蓝色模型，图片3参考书店环境。生成暖色写实电影短片，按白模顺序走向柜台、递信、接信和对视。保持原调度，不展示轨迹线、坐标轴或相机辅助元素。仅环境音和动作音。”如白模包含需保留的光照变化，单独说明。

故事板：“图片1为六格线稿故事板，按从左到右、从上到下顺序参考剧情；图片2对应小禾，图片3对应宁舟。生成写实电影画面。”随后按镜头补足每格动作、机位和声音；多宫格不保证严格画面匹配，需更强对齐时改独立关键帧。

## 成片与无缝转场

一键成片：“使用图片1至图片4，按该顺序生成咖啡店日常短片，每图仅做轻微自然动作，保持外观一致，手绘涂鸦风，指定轻快纯音乐，无对白。”说明图片顺序、风格、运动幅度、音轨和是否要文字。

转场：“在视频1末尾与视频2开头之间补充过渡，镜头从桌上的纸飞机平稳向前跟随，纸飞机经过窗边时场景自然转为视频2的室外天空。保持两个原片的内容与顺序，接缝处运动方向、亮度和声音自然衔接。”这是声画目标，交付检查实际保留情况。
