# 画面与素材排查

按现象选择最小修改，不把整张排查表变成每条提示词的约束。以下措施来自用户提供指南，能改善概率，不能保证消除问题。

## 人脸不准 / 中途换脸（2.0重点）

先检查人脸是否太小、是否与服装/背景/多视图拼在同图。额外准备仅头部、表情中性、低干扰的大头照；明确“角色面部参考图片1，妆造体型参考图片2”，把重要绑定放前面。2.0避免人物多视图拼图；2.5可使用多视图，超过5主体优先单视图或不同视角分图。不要因为2.0限制而禁止2.5单人物多视图。

## 重复人物 / 多人少人

明确每位角色与参考素材一一对应，持续用同一名字；多人参考按首次出场顺序准备、同步更新图片/音频编号，不能只改文字编号而不改输入。

无需分身时可加“同一画面中每名指定角色仅出现一次，不生成同款分身”。真实双胞胎题材不能套此约束。2.0优先单人独立图；超过4个参考角色时文档建议先按每组≤4人生成分组图，再作视频参考，仍可能不稳定。

2.5主体图1–8人、音视频1–5人效果较好，更多人稳定性下降。这是经验建议，不是硬上限。保留用户要求的人数，必要时建议分镜或分组，不擅自删角色。

## 风格漂移 / 2.0与2.5风格不连贯

写明确目标如“2D日漫”“3D国漫CG”，将写实参考先调整到目标风格可提高一致性。同一提示词在2.0和2.5下美学可能不同；2.5延长2.0原片并输出MOV可尝试保留原风格，不承诺完全相同。

## 情绪使眼睛发光（2.5）

真实人眼任务把“正常人眼、瞳孔不发光”放优先位置，环境光只勾勒面部轮廓。将狂热、极度震惊等词改为惊叹，并配呼吸、肩背、嘴角变化；题材本来要求发光眼时遵从用户。

## 文字拼写 / Logo / 水印 / 特效错位

- 文字写明内容、时机、位置、方式、颜色和字体风格，优先常用字。2.5英文可拆成独立字母按序出现；精准中文/品牌文字可做成图片参考或后期叠加。生成不保证准确拼写。
- 无额外标记时加“不要生成水印/额外Logo”；用户指定品牌Logo则使用真实图片绑定，不同时排除。
- 数字滚动、倒计时、翅膀生长等特效逻辑不准时，优先用正确效果视频参考并明确“只参考特效形态与运动”，少用抽象文字反复加码。

## 延长接缝跳变 / 画质劣化

2.0指南给出的剪辑修补起点：前片末尾减6帧、后片开头减1帧，检查每个拼接点。这是经验修补，不能在未知帧率/内容下机械套用，也不要直接删除必要动作和台词。可在切镜转场处结束续写，下一段从新场景开始。

多次续写会累积劣化，减少连续续写次数并优先高清角色图。2.0文档提出先转白模再续写的缓解办法：人物纯白3D、无色彩纹理阴影、纯白背景、结构与运动稳定。该法会改变画面外观；需恢复原风格时还要绑定角色/场景进行渲染，不能当成无损续写默认步骤。

2.5优先输入、输出MOV并检查颜色、亮度、声画与音量。技术格式有利一致性，仍需看听接缝。

## 编辑时长 / 宽高比不一致（2.5）

编辑可能比输入短约0.3秒，FAQ约0.33秒。若严格保留原片，文档建议将输入帧数调整为8n+1（n正整数），例如161帧，再比较输出。先检查真实帧数和帧率；这不是“8n+1秒”，也不默认补帧/删帧破坏内容。2.5自产输入的编辑文档称无此差异。

需自定义时长或新画幅时，可改参考生成并补充具体剧情、逐镜顺序、动作轨迹与原视野完整性；它允许重生成偏差，不能称严格编辑。严格编辑、延长与首尾帧遵守锁定比率，参数条件见2.5任务资料。

## 输入解码失败 / 密集纹理异常（2.5）

特殊JPG可能使用非常规色度采样，转PNG或标准JPEG再传；在有本地执行工具且确需修复时可用：

```bash
ffmpeg -i input.jpg -pix_fmt yuvj420p fixed.jpg
```

不要仅凭扩展名判断损坏或格式。GuGu创作工具未提供命令执行时，交付转换建议，不假称运行成功。

草叶出现指纹/鞋印状纹理时，指南建议将高分辨率AI参考图降到不超过输出视频分辨率；1080p比720p出现概率更低。仅有此现象时调整，不与常规清晰人脸素材建议混淆。

## 多要求互相干扰

先拆“轨迹动作参考生成”与“原片局部编辑”：例如先生成帽子按轨迹飞行的参考视频，再编辑原片，参考该帽子的形态与轨迹。轨迹线、坐标轴、相机辅助元素最好从输入移除。拆分会增加任务与费用，实际生成按用户授权与报价执行，不自动无限重抽。
