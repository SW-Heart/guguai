# Seedance 2.0 系列：可复制模板

方括号表示待替换内容，交付可执行正文时全部替换；编号须与实际上传顺序相同。以下例子为根据指南重新编写的示范，不是已生成验收的成片。无需某种参考时删除相应绑定，不虚构文件。

## 全模态参考通用模板

```text
将图片1中[2–3个稳定外貌特征]的角色定义为[角色名]；[角色名]的面部参考图片1，妆造与体型参考图片2。场景参考图片3。参考视频1的[动作/运镜/节奏]，参考音频1的[音色/音乐氛围]。
生成[角色名]在[场所]完成[事件]的视频，整体为[唯一目标风格]。
镜头1：[景别、机位与一种运镜]。[角色名]从[起始状态]缓慢[动作]，[位置和身体细节]。[声音]。
镜头2：[切换方式与一种运镜]。[角色名]顺势[后续动作]，[表情具体变化]。[说话人]说{逐字台词}。[音效]。
镜头3：[景别和一种运镜]。[角色名]完成[终点动作]，画面落在[结尾构图]。[声音收尾]。
全程[光线/色调/材质]一致，角色面部与服装保持稳定，动作自然衔接。[按需无字幕、无水印、无额外Logo]。
```

2.0 使用镜头序号，不给每镜强制整数秒时长。角色已定义后持续用名字，参考职责不清时不直接写“参考全部素材”。

## 双人文戏：递信

素材：图片1为小禾独立大头照，图片2为小禾全身照，图片3为宁舟单人照，图片4为书店场景；不需要额外视频和音频。

```text
将图片1的短发女子定义为小禾，小禾的脸参考图片1、服装和体型参考图片2；将图片3中穿深蓝外套的男子定义为宁舟。书店环境参考图片4。
傍晚，小禾在旧书店把一封信递给宁舟，写实电影风格，暖色窗光，情绪克制。
镜头1：固定双人中景。小禾站在柜台左侧，宁舟站在柜台右侧。小禾轻握信封边缘，抬眼看向宁舟；宁舟停止整理书本，看向信封。<轻微翻书声、衣料摩擦声>
镜头2：切至小禾侧面近景，缓慢推近。小禾将信封平稳递向宁舟，手臂停在柜台上方。小禾用轻柔普通话说{这封信，是留给你的。}宁舟保持闭口。
镜头3：固定宁舟近景。宁舟接住信封，手指短暂收紧，随后放松肩膀，轻轻点头。宁舟低声说{我一直在等。}小禾保持闭口。画面停留在宁舟的淡淡微笑上。
保持两名角色的脸、服装、位置和视线连续，接信动作前后衔接；仅对白、书店环境声和动作音，无背景音乐，无字幕，无水印，无额外Logo。
```

## 编辑 / 参考加编辑

```text
严格编辑视频1，将台面中央的红色玻璃杯替换为图片1中的白色陶瓷杯。新杯子保持原杯子的摆放位置、透视、接触阴影和随手部移动的轨迹。人物、动作、机位、镜头顺序、背景、原声音和其他物件保持一致。
```

增加：“在视频1中，人物坐下后，在桌面左侧加入一束浅黄色鲜花，花瓶稳定放置，其余内容保持一致。”

删除：“从视频1中删除桌面右侧的钥匙串，保留杯子、书本、人物动作和镜头不变，补齐原桌面纹理。”

## 延长 / 补齐

```text
向后延长视频1。承接原片末尾宁舟已接住信封的状态，宁舟缓慢展开信纸，阅读后微微抬头看向小禾。固定双人中景，保持原角色、书店布局、暖色光线和原有音色。宁舟说{谢谢你还记得。}小禾轻轻点头，画面在两人安静对视时结束。无字幕，无新增背景音乐。
```

向前延长替换为“向前延长视频1”，写能自然到达原首帧的前置事件。

补齐：“视频1，承接落叶刚触地的状态，微风卷起细小金色粒子，镜头随粒子平稳横移到窗边，接视频2。”文档中的轨道补齐最多3段输入视频、总长≤15秒，实际先查线路。

## 商品与文字

“图片1、图片2、图片3中的相机是同一商品，分别参考正面、侧面、背面。白色桌面背景，固定特写，相机缓慢转动展示结构。”商品多角度不套人物多视图禁忌。

需广告语时：“结尾背景逐渐虚化，画面中央淡入文字【此刻，慢下来】，白色简洁字体。”需要品牌Logo时绑定真实Logo图片并明确出现时机；不同时加“不要Logo”。
