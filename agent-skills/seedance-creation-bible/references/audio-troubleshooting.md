# 声音与字幕排查

区分人声、背景音乐、环境声、动作音效和画面文字，约束只针对用户不要的部分。不默认静音，也不把“不要字幕”解释为不要对白。指南中的措施提高成功概率，仍需实际看听产物。

## 生成了不需要的字幕

两版本均可写“保持无字幕/不要字幕”，但无法保证完全避免。先检查参考图/视频是否自带字幕或文字；非必要文字先去除或换无字幕素材，不能以提示词保证去除参考中的文字。

2.0指南还建议业务允许时优先横屏，再裁竖屏；必须保持用户画幅要求，只有内容可裁时才建议此替代，不直接改输出画幅。

2.5避免在对白后逐句复述台词，再追加语气/表情/动作，此写法可能诱发字幕。改成：

```text
周女士台词（难以置信）：“像……”
周女士台词（声音发颤）：“太像了。”
周女士台词（惊喜）：“终于等到你了。”
```

情绪写在台词前；动作描述单独写，不复述台词词组。需要字幕时明确文字和时序，不与“无任何文字”约束并存。

## 台词读错 / 音色偏离

2.0多音字、生僻字可在**仅发声文本**中使用常用同音字，例如“螭龙山”发声可写“吃龙山”。这是发音优化，不把用户剧本、正式文案或屏幕文字永久改为错字。显示文本保留正确写法，必要时分开管理发声稿与画面文字。

音色不准时加具体特征，如“音频1低厚、温润、略有颗粒感的中年男声”；台词语气与参考音频风格接近。每人单独绑定音色；不要用同一音频同时隐式指代多人。没有可用音频输入时可写音色描述，但不能声称已绑定音频。

## 没有背景音乐仍生成配乐（2.5）

先写准确音频目标：“仅对白、轻微环境声与动作音，无背景音乐”。仍失败且确需严格约束时，在正文开头与结尾各强调一次排除音乐、BGM、配乐、器乐、旋律、合成器音效、氛围铺底等音乐类声源。

只有用户明确只要人声时才改“音频仅保留角色人声声源，不产出任何音乐类音轨”，不要顺带删除需要的风声或动作声。排除合成器音效时也要检查用户是否需要科幻/魔法音效。

后期分离人声可移除非人声部分，但可能同时移除音效、环境声。先说明结果取舍，保留源片；仅凭文件处理成功不宣称声音无损。

## 翻译残留原语言 / 声线串位 / 口型不准（2.5）

列全片所有可辨识人声：男女角色、背景对白、低语、感叹词与语气词。按角色给完整目标语言台词和实际起止时刻，明确原语言不保留为背景音；要求说话顺序、情绪、停顿、音量和每人声线对应，口型按目标语言逐字调整。

指定除人声语言与口型外，人物、动作、服装、场景、镜头、原音乐、环境声和音效保持一致。原片时间轴不完整时先补充或说明缺口，不杜撰听到的台词。无字幕任务明确不得添加源/目标语言字幕。

验收目标：无可辨识原语言残留、无角色串声、目标语言口型同步、其他音画未误改。这是需要实际看听的标准，不是让生成模型“输出前自检”就已完成验收。

## 片尾咔哒 / 截断噪音

2.0含旁白的视频片尾可能有截断杂音。可重新生成或在后期用音量包络线将末尾平滑降到0；淡出从台词结束之后或合适停顿开始，不截断最后字。若声音本就延续到下一段，优先检查拼接与音轨连续性，不随意淡出。

## 水泡 / 回音 / 微弱啸叫（2.5）

指南建议移除与水、波浪、回音有关的描述可降低异常噪声概率。仅删不必要的声效词；真实剧情需要水面或海浪时保留视觉事实，改为明确、克制的声音要求，必要时后期处理。不能为了消噪改掉用户题材。

## 声音交付检查

检查台词漏词/重复、语言、说话人、音色、口型、音乐与音效职责、声音开头结尾、续写接缝的响度。2.5续写音量可能轻微变化，MOV和自产视频输入较利衔接。不能用抽帧证明口型准确，不能用时长探测证明听感正确；未具备看听条件时把这些列为待用户核对项。
