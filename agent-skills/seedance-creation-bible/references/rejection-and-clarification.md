# 生成被拒与表达调整

先看实际返回信息，区分输入文字被拒、参考素材问题、生成结果被拒、参数不支持、额度或服务故障。只有通用失败提示时保留未知，不能给出确定的敏感词归因，也不能把所有问题都用改词解决。

必须读取 [审核词句排查](moderation-vocabulary.md)，并用 `prompt_risk_scan` 扫描原文，结合原文检查武器、伤害、犯罪、未成年人组合、机构文书、烟酒、恐怖及身份符号等候选项。候选命中不等于违规；普通法律、医院、合同场景不能机械删除。2.0 即梦社区记录不代表 2.5 或 GuGu 渠道的接受结果。

结合完整场景和用户要求判断。允许的内容表达含糊时，澄清已经知道的含义，保留逐字台词、真实素材标签、镜头和声音要求。不要虚构“已授权”“成年人”“只是道具”等事实。人物或声音许可等关键上下文缺失时只询问必要信息。

如果需要删除或替换内容，说明这是内容变化，给出明确的合规替代；用户已允许此类修改时直接在其范围内改写。不能用隐藏词、改拼写、换语言或反复同义词试探来掩盖禁止内容。正常法律、医疗等题材不因某个词单独出现就被判为禁止。

交付可复制的新版描述，另说明平台已知原因、尚未确定的可能原因和重要改动。没有提交的草稿不能称审核通过，也不能保证改写后接受。生成视频被拒时可能涉及输出内容；结合具体反馈判断，不默认只是输入文本的问题。

用户只请求改写时不自动上传、生成、切换模型或增加费用。真实重试先核对既有任务状态、当前模型能力、报价与剩余授权；未知超时不能盲目重复提交。具体表演与画面替代设计统一读 `video-production`，通用改写方法可读 `prompt-optimization`。
