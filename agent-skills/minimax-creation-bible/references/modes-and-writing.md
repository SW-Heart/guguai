# 模式与写法选择

## 模式由素材用途决定

| 模式 | 输入职责 | 正文重点 |
| --- | --- | --- |
| T2VA | 无关键帧，从文字生成视频与声音 | 建立起始画面、动作、镜头和声场 |
| I2VA | 一张图真正绑定开头 | 从图中已有状态向前发展 |
| FL2VA | 两张图真正绑定首尾 | 描述两种状态之间可见、连贯的变化 |
| L2VA | 一张图真正绑定结尾 | 构造合理前态，逐步收束到目标图 |
| Ref2VA | 素材提供人物、环境、动作、声音等参考 | 定义参考职责，再逐镜说明如何生效 |

FL2VA 官方倾向一个连续镜头；用户指定多镜头时才按其意图安排。I2VA 不能先生成一个与图片无关的开场；L2VA 不把尾图当作首图。普通角色参考没有自动变成关键帧。

Ref2VA 可以描述参考生成、具体画面补全、原片编辑或续拍等不同关系，但有视频参考不等于要编辑该视频。只借鉴原片运镜属于参考生成；改原片本身才是编辑；从原片终点发展新内容才是续拍。接口是否开放这些任务另查。

## 选输出写法

1. 用户指定官方 H3 结构，或目标接口明确接收该结构：基础模式使用三字段，全参考使用六字段，保留字段顺序与专用标签。
2. 用户在海螺/Hub 写普通创作描述，或第三方工作流未验证官方结构：用自然语言描述同一套主体、时间线、动作、声音和参考职责，不猜标记映射。
3. 用户只问创意：交付导演方案，无需强制转成英文结构。

同一条结构化描述作为完整 prompt 提交。基础字段与 Ref2VA 字段不要拼成九段，也不要把每个字段变成一次独立生成。官方结构适合精确改写，不说明当前服务已经执行官方的上下文处理。

## 时间和语言

官方公开规格为 4～15 秒；GuGu 当前工作流有自己的时长范围，详见平台资料。多镜头正文第一镜 `[Shot 1]` 不带切点，后续采用 `[Shot 2] At 00:04.000, ...`。切点用 `MM:SS.mmm`，是目标片时间，不是参考视频时间。关键帧对齐行终点用两位小数秒，如 `10.00-second`。最后动作在总时长结束前落定，不能留待下一镜完成。

官方结构的叙述部分用英文；台词、歌词与可见文字不翻译。用户明确要翻译作品内容时才改对应字句。只有音色参考时，不把参考录音中的旧台词带入新片；源音频听不清的部分标记 `[unclear]`，不猜词。

## 细节写到哪里

把“高级、电影感”改成可见的光源、材质、景别与运动；把“紧张”改成停顿、握紧物品、视线转移或呼吸。每镜描述主体现状、变化和后果；避免重复身份长句，但关键参考首次出现要足够明确。全参考官方建议主体描述通常约 350～500 英文词，这是参考密度建议，不是 API 字数上限；对白时间与用户要求优先，不为了凑字制造动作。
