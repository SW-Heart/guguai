# 问题与局部修订

先辨别输入/模式错误、描述矛盾和结果偏差。输入被拒与生成后画面不好不是同一个问题。下表是诊断建议，不是经大量 H3 样本验证的成功率结论。

| 现象 | 先检查 | 最小修订 |
| --- | --- | --- |
| 人脸、服装、产品颜色漂移 | 实际素材、各图职责、冲突风格词、是否多个款式混用 | 固定同一身份/产品来源，明确要保留的可见特征，删除冲突改色要求 |
| 图片背景跑进目标场景 | 是否把身份参考写成完整场景/首帧 | 明说只保留外貌，单独描述目标场景；已绑定首帧时不能又要求完全不同开场 |
| 两个人物串位或串音 | Subject 定义、画面左右、实际发声顺序、Audio 绑定 | 固定空间位置和全片 speaker ID，引用音色时明确对应人物 |
| 旁白人物也张嘴 | 旁白是否误写成画内对白 | 使用画外旁白说明，画面对应人物嘴唇闭合 |
| 台词复读、缺字、跨镜断开 | 原稿、台词时间、重复粘贴、跨切点表达 | 一处完整安排该句；跨切点才用相应标签，留足时间，不擅自缩写 |
| 有无意音乐或字幕 | 是否“有声音”误带入配乐，是否把台词当字幕 | 明确配乐与字幕分别需要什么；只不要配乐时仍保留必要对白与环境声 |
| 参考音色带进旧台词 | 是否把声音复制与音色参考混写 | 指定只参考音色，使用新台词；删除源对白引用 |
| 参考音频节拍不准 | 是否指望模型逐样本复制音乐，源/目标时间是否混用 | 保留原音乐作为连续后期音轨，按真实入出点对齐，检查人声起止 |
| 镜头乱切、人物与相机同时乱动 | 切点密度、相机路线、主体路线是否冲突 | 精简到服务观看目标的切点，分别写人物路线与相机路线 |
| 首尾不匹配 | 接口是否真绑定帧、两图是否同角色/空间、动作是否可完成 | 无绑定时改成目标状态参考；有绑定时补全合理路径或修订冲突两帧 |
| 图中宫格、编号进入成片 | 是否上传分镜板/角色卡并要求完整保留 | 独立提取实际参考画面，明确分镜板只提供顺序；不复制版式标注 |
| 画面文字或 Logo 错 | 同屏文字量、阅读时间、模型实际表现 | 精简并留出停留；需精确文字时考虑后期图层，保留用户文字原稿 |
| 某参考完全没作用 | 实际参数是否传入、编号是否对应、正文是否写生效位置 | 核对真实素材引用，补充在哪镜、哪个对象上生效，不凭标签假定已传入 |
| 请求不支持视频、首尾帧或 2K | 当前目录和预检，而不是源码里旧配置 | 使用当前支持模式；明确具体缺口，其他线路需另查，不能暗切模型 |

修改提示词前读已有正文和真实结果，保留成功的人物、动作、镜头与声音。无法观察结果时给检查项和候选修订，不声称已诊断某个画面。生成被拒时依据实际报错澄清意图与素材，必要时读取 `prompt-optimization` 的拒绝澄清资料，不宣称换词即可绕过审核。

需要返工先缩到受影响镜头/声轨，再预检真实输入与报价；不要无限自动重试付费生成，也不要为一次失败引入全片通用负向词墙。
