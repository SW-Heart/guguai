# MiniMax 创作圣经

把故事、素材或已有描述整理成 MiniMax H3 的声画拍摄指令。依据 MiniMax-AI/MiniMax-H3 官方提示词指南与八种制作技能独立整理；保留用户的题材、语言、台词、风格和交付范围。只要提示词就交付提示词，要求成片才进入生成与剪辑。

## 先确定任务和可用模式

区分文生视频、首帧发展、首尾帧补全、尾帧收束、全参考生成，以及基于原片的编辑或续拍。用户泛称 MiniMax 或海螺时，结合视频语境判断是否指 H3；不能把 H3 语法套给旧版海螺或 MiniMax 文本/语音模型。

开始写法选择前读 [模式与写法选择](references/modes-and-writing.md)。官方模式、官方输入上限和 GuGu 当前线路分开判断。准备实际生成时读 [平台能力与来源](references/platform-and-sources.md)，并以本次模型目录与预检结果为准。没有首尾帧绑定参数时，写“最后到达某姿态”只是创作目标，不能承诺锁定尾帧。

## 写作与交付

先核对真实素材和职责：哪份决定外貌、哪份决定场景、哪份只参考音色或节奏。编号以各类实际输入顺序建立，素材 ID 留在调用参数里。没提供素材时可交付明确标注的模板，实际提交前替换并核对全部引用。

官方结构正文用英文，逐字台词、歌词和画面文字保留用户指定语言；解释和反馈用用户语言。用户要求中文正文或当前线路未验证官方方言时，提供清晰的中文自然语言版本，不擅自英文化广告词。结构是一整条提示词，不是多次生成，也不是新增 API 字段。

按真实播放顺序写主体、位置、动作变化、摄影机路线、声音与终点。镜头切点严格递增且在总时长内；短片给动作和台词留出实际时间，不把故事梗概冒充逐镜描述。单镜连续动作不强行拆段，多段制作保持角色、空间、画幅与主音轨的连续性。

交付可复制正文、必要输入与参数，简要说明关键改动。不能执行的官方模式说明具体缺口并给当前可行方案。实际制作沿用平台报价与授权，继续到真实文件可读取；验收区分技术检查与实际听看，返工受影响部分，不把指南建议、模型名称或一次生成当成效果保证。
