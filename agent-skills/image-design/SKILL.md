# 图像设计

先确定图片的用途、观看位置、主体、目标观众、画幅、视觉风格、必须出现的文字，以及用户明确锁定的元素。只有用户要一个想法或提示词时交付文字；用户要求实际出图时才进入生成。资料足够就直接提出可执行方案，不为了填表而询问。

## 把需求变成设计决定

- 分清新设计、已有作品优化和系列延展。改一处就保留其他已确认内容；有品牌规范或参考图时先读取，不自行改成偏好的风格。没有参考时可以提出原创方向，但不要声称看过竞品或做过用户研究。
- 内部建立简短设计约束：谁在什么尺寸与场景看、第一眼应理解什么、希望产生什么行动或情绪、必须出现/不能改变什么。缺少会改变主题或成品规格的信息才提问；可逆的次要选择采用合理假设。不得虚构品牌故事、价格、活动时间、产品功效或用户证言来填画面。
- 对开放的新设计，先比较少量真正不同的表达，例如产品证据、使用场景、叙事隐喻，按目标选择；换颜色不算不同创意。用户要一个结果就收敛到一个，不为探索擅自生成多张付费图。
- 将方向具体化为视觉焦点、构图关系、字体角色、颜色职责和有主题依据的识别特征。优先把一个特征做好，不把渐变、玻璃、金属、颗粒、发光全部堆上去；这些手法可按需求使用，不固定禁用某种颜色或风格。

## 设计画面

- 先定视觉层级：观众第一眼看什么、第二眼看到什么、文字放在哪里。主体与背景要有清晰的明暗、色彩或空间分离；给标题和按钮等后续排版留真实留白。
- 用可观察的内容描述主体、动作、构图、景别、镜头角度、光线、色彩、材质和背景。风格词只用于补充，不用“高级、电影感、精美”等词代替画面决定。
- 海报和产品图先说明传播目标与卖点，再确定主视觉、道具关系和文字区。角色设定图要区分稳定身份特征与本次服装、表情、动作等可变状态；供后续视频使用的参考图优先清晰、无遮挡、易辨识。
- 系列图先形成简短视觉锚点：角色外貌、服装状态、场景空间、主色和光线。每张只改变用户允许变化的部分。参考图按“身份、造型、场景、构图、风格”分配职责，不让一张图无意控制全部内容。
- 需要精确文字、品牌标识或界面时，检查模型对文字的实际表现。若结果文字不准，应说明并建议在后期排版；不得声称模型已经正确写出未核对的字。
- 先锁定成品里真正要出现的文案，区分主标题、必要信息和注释；不要把上述设计约束、配色说明、画面描述或内部步骤变成作品里的文字。不用无意义的英文小标题、虚构编号和装饰箭头制造设计感。

## 为视频准备参考画面

为后续动作设计画面时，区分身份参考、场景参考和镜头起始构图。身份图要能辨认脸部、体态与稳定服饰；场景图交代出入口、遮挡与人物尺度；起始构图给行走方向、手部操作与道具留出空间，不用极端裁切或复杂遮挡阻断动作。需要走位与运镜时按需读取 `video-production` 的 `references/camera-and-blocking.md`。

首尾画面要在时间与空间上可达：持物手、身体方向、场景结构和光线相容，中间变化能在计划时长完成。只有起点图时不宣称已经控制终点；只有文字设定时不宣称身份一致性已经验证。系列修改优先保留已成功的身份与构图，只修本次失败部分。

## 写提示词与出图

提示词可按“主体与身份 → 当前状态和动作 → 构图与空间 → 光色和材质 → 背景与留白 → 必须保留/排除”组织，但不强求固定模板。编辑现有图时明确保留什么、只改什么，并先用 `assets_inspect` 读取真实参考图；不要凭文件名推断图片内容。

实际生成前用 `models_list`、`models_describe` 核对可用图像模型、尺寸、质量和参考图用法；比较实际表现时用 `models_experience` 查看当前工作区的案例，不根据少量案例给模型排位。提示词写画面，模型参数填工具字段，不把未经核对的供应商语法写进正文。用 `media_prepare` 得到准确报价，再按当前授权 `media_submit`。生成后查看真实结果：主体是否清楚、身份与参考是否一致、文字是否准确、构图是否适合用途、是否出现多余肢体或物件。需要积累经验时用 `model_experience_note` 保存已看过的单张作品观察。只修失败的变量，保留可用版本和素材 ID。

结果可读取后用 `assets_inspect` 查看，不把任务成功等同于设计合格。按原目标检查，返工仍遵守现有内容授权和费用确认，不为追求完美无限重试。字体、标志、精确图表、透明背景或文件格式未核实时说明实际交付状态；当前工具不能制作的可编辑文件或成品工艺，给出明确的后续制作说明，不假称已完成。
