# 按作品类型设计

只读当前类型，按用户目标调整；这些是判断依据，不是必须照搬的版式。

## 海报、封面与社交图

先决定观众应记住的一句话或一个形象，再排列必要信息。活动海报保留准确的名称、时间、地点与行动入口；资料没有提供就询问或在方案中标为待定，不捏造填满。封面要在缩略图里仍能辨别题材与主体。留出对应投放位置的裁切空间；平台遮挡区没有实测资料时不要声称绝对安全。

示例：用户要社区夜市海报，重点可能是烟火气与时间地点。可以用摊位灯光聚拢主视觉，标题和日期形成清晰入口；没有必要加奢侈品式英文副标题、虚构销量或大面积无关金属装饰。

## 品牌、标志与包装

先提炼品牌要传达的识别特征与使用环境。标志同时考虑轮廓、负形、字标关系、小尺寸辨识和单色适配，不靠复杂背景才能成立。品牌延展保留同一套比例、字形气质与颜色职责，而不是把标志贴在许多随机物件上。

包装区分正面主识别、品类/规格和必要说明，形状、材料、印刷区域要与真实包装一致。效果图用于沟通外观；刀模、出血、专色、色彩配置和工艺文件需要供应商规格与制作工具，不能把高分辨率图片当成可生产文件。生成标志只是概念方案，不承诺商标可注册或自动成为可编辑矢量。

## 产品图与商业摄影

以实物参考锁定轮廓、配件数量、接口、标签和材料，不为了美观改造产品。主图重识别，细节图重可见证据，场景图重使用关系。道具和环境服务卖点，不能遮住关键部位；不凭空加认证、折扣、性能数字或使用效果。

玻璃与金属看反射是否合理，悬浮产品看是否符合既定表达，食物看份量、温度与质感是否可信。白底、电商尺寸、文件大小等要求以用户提供的平台规范为准，没有资料就不假称符合某平台全部规则。

## 角色、插画与场景

角色明确剪影、比例、面部特征、服装结构和少量可辨识细节；多视图保持同一身份。故事画面通过姿态、视线、距离和环境关系传达情绪，避免人物只摆姿势。场景有可解释的前中后景与空间路径，主要光源、接触关系和尺度连贯。只按用户需要提供角度与数量，不自动扩成整套设定集。

## 信息图、图表与演示画面

先选择信息关系：比较、时间、流程、组成或空间。比较用统一尺度，流程顺序必须有真实因果或步骤，图标和颜色承担一致含义。数据来自用户或已读取资料，单位、范围和来源需要可核对；没有数据不编造统计图。

有精确数值、坐标或大量标签时，图片模型适合概念示意，正式图表应由数据绘图或排版工具制作。当前没有这些工具时提供准确的数据组织与版式说明，不承诺可编辑图表或演示文稿已生成。演示页围绕一条主要结论安排证据，不把长文缩小塞进画面。

## 网页与应用界面视觉

先确定用户正在完成的任务、主操作和信息顺序，再定视觉。区分内容层级与交互状态：普通说明没有链接暗示，按钮名称表达实际动作；表单有标签，空状态给下一步，错误指明如何修正。遵循已有产品和平台规范，不为独特性改变熟悉的操作含义。

设计时考虑窄屏重排、文字放大、键盘焦点、触控区域与减少动态效果。WCAG 2.2 AA 的通常要求是普通文字对比至少 4.5:1、大号文字至少 3:1；大号指至少 18pt，或至少 14pt 且加粗。必要的非文本控件视觉信息通常需 3:1。不要误把所有次要小字都按 3:1 处理；涉及例外时查标准。像素截图只能支持视觉观察，不能证明键盘操作、屏幕阅读器或真实交互通过。
