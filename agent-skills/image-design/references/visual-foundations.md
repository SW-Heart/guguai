# 视觉基础

用于决定画面为什么这样设计。不要把这份检查表显示在作品里，也不要每次把全部规则念给用户。

## 从题材建立方向

先找题材特有的物件、动作、空间、材料或文化语境，再选择表达。例如户外鞋的卖点可以由鞋底与地面接触表现，茶饮的口感可以由汤色、叶片与杯壁质感表现；“高端”本身不是一个画面。写清表达服务哪条已知信息，不把视觉联想当成功效证据。

参考图拆成可独立借鉴的关系：主体占比、视线顺序、留白位置、明暗结构、字体气质、光源方向。用户只借鉴构图时，不连带复制人物、品牌或文案。已有品牌优先沿用其识别特征；GuGu 自身界面风格不自动成为所有客户作品的风格。

## 层级、构图与空间

- 让第一视觉焦点对应作品主要目的：广告可能是产品或利益点，叙事插画可能是人物关系。第二层解释，第三层补充。若处处醒目，先降低次要元素的重量。
- 用共同边线、重复间隔、邻近分组组织内容。位置相近表示关联，间距较大表示分组；不为每一项信息都加边框或卡片。居中适合短而聚焦的内容，多段文字应有稳定阅读边线。
- 区分视觉平衡与几何对称。偏置主体可以由留白、文字或另一侧色块平衡；不要为了“填满”补无关道具。检查人物视线、动作方向和裁切是否把注意力引出关键内容。
- 留白要有用途：分隔、承载标题或呼吸空间。面向小屏缩略图时减少竞争元素并提高主次差异；多画幅按焦点重新排布，不直接拉伸或机械裁切。

## 字体与中文排版

先分标题、正文、辅助信息的职责，再选择字族、字号、字重、行距。通常少量字族就够，同一字族的不同字重也能形成层级；不要强制每个项目配两套特殊字体。

中文标题按语义断行，避免拆散专名、数字与单位；短标题可有表现力，长文不能依赖极细字重、过紧字距或大面积居中。检查中文、英文、数字的基线与视觉大小，缺少中文字形的英文字体不能假装解决中文排版。字体可用性与授权未核对时作为建议，不声称已嵌入或可商用。

图中有准确文字要求时保留用户原文并逐字核对；生图模型不能替代排字工具。密集文字可以规划独立排版层，但在当前工具无法叠加文字时只能交付底图和排版说明，不能宣称完整成品已就绪。

## 色彩、图像与材质

给颜色分配职责：背景、主要文字、次要文字、品牌强调、必要状态。具体 HEX 适合可控的界面或品牌规范；图片生成中的颜色描述是方向，不能保证像素精确。先看明暗可读性，再看色相是否符合题材；避免用浅灰小字和低对比来冒充精致。

照片或写实图统一光源、阴影、透视与尺度；通过合理的高光、粗糙度、反射和接触阴影区分金属、玻璃、织物与皮肤。不要为所有材质都加塑料般的光泽。插画和角色优先保持形状语言、线条、比例与色彩逻辑，允许题材需要的夸张而非一律追求写实。

## 系列作品

明确固定项（标志、字体层级、配色职责、边距、角色身份、光线逻辑）与可变项（主题、动作、图片、标题）。延展时先保持固定项，再根据每张的内容调整构图。视频可沿用这些视觉锚点，但运镜、表演、声音和节奏应使用视频方法，不把视频做成静态海报轮播。
