# 观察与修订

“不专业”需要转成可定位的问题，不要只增加“精美、8K、获奖”等提示词。

## 先看证据

编辑或审阅图片前用 `assets_inspect` 查看真实素材，并读取相关的原始要求与锁定内容。只拿到提示词时只能评估方案；任务成功、文件名和模型自评都不能证明画面正确。图像分辨率不足以辨认文字时明确不确定，不猜测。

按使用场景检查整体与细节。能看到缩略视图时判断第一眼读到什么；能看到实际尺寸时核对文字、边缘、材质和细节。若工具未提供对应视图或测量，不声称已完成缩放、取色、对比度计算或逐像素检查。

## 把症状变成改法

| 观察到的问题 | 优先修订 | 保留什么 |
| --- | --- | --- |
| 主体、标题、贴纸同样抢眼，无法判断主信息 | 明确一个焦点，降低次级元素大小或对比，移除无用装饰 | 已正确的文案和品牌识别 |
| 内容像零散贴上去，边线和间距没有规律 | 统一对齐关系，相关内容靠近，不相关组拉开 | 现有信息与可用图像 |
| 中文断行破坏语义、细字贴在复杂背景上 | 按短语断行，调整字重和文字区背景，必要时拆分后期排版 | 精确原文、必要信息 |
| 画面有很多风格词，却辨不出主题 | 用题材的具体物件、行为或材料组织核心形象 | 用户指定风格与目的 |
| 产品轮廓、人物身份或光照发生漂移 | 重新锚定参考职责，限定修改区域或变量 | 已通过的身份、构图和素材版本 |
| 画面塞满但信息仍不清晰 | 删除重复内容和无功能标记，重新分配空间 | 用户要求的必要信息 |

只在看到对应现象时采用这些改法。偏好粗体或细体、对称或不对称本身不是错误；“极简”不自动比复杂风格更专业。

## 判断是否值得再改

先处理明确违背需求、错误文字/事实、缺失内容、产品或身份错误，再处理影响理解的层级和可读性，最后是可选的风格打磨。每个问题给位置、可见证据、影响与最小修改，不虚构总分或转化率提升。

改前明确此次只动哪些变量和如何确认改好，改后用原要求对照查看，并检查保留项是否退化。满足请求且剩余差异只是偏好时停止，不无限重新生成。实际返工遵守媒体内容授权、报价与预算；一次作品授权不等于无限探索费用。用户只要点评时交付点评，不修改素材。

对用户通常只需说明最关键的少量问题与具体改法；不要输出整份内部检查表。无法核对的文字、品牌精度、印刷或交互要求标明待核对，交付概念稿时如实称为概念稿。
