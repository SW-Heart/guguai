# 从设计方案到可执行画面

用于完整设计交付、参考图编辑和系列出图。视觉判断读本技能的其他专题；这里解决“方向已经有了，交付为何仍无法执行”。

## 先确定这轮交付是什么

| 用户要什么 | 足够的交付 | 不能冒充完成的东西 |
| --- | --- | --- |
| 一个设计方案 | 主视觉、版式关系、准确文案与关键取舍 | 只有风格形容词或模型名单 |
| 可复制的画面描述 | 一段自足正文，附必要参考用途 | 只有内部镜号、素材代号和检查列表 |
| 修改已有图片 | 原图、保留项、修改区域或对象、目标效果 | 凭文件名猜原图，重画所有元素 |
| 一组系列图 | 共同固定项，每张内容差异与对应参考 | 随机风格拼盘，或重复同图只换色 |
| 实际出图 | 真实可读取图片及已核对情况 | 只写方案、仅返回任务成功或空素材编号 |

用户要一个方向就选一个成立的方向，不默认交付三套。缺日期、价格、规格时保留待补信息；文字方案可继续，实际图片不要把“待补日期”当用户认可的正式文案。

## 让输入约束各有落点

在内部将要求对应到画面：必须保留的标志在什么区域，主信息在哪个阅读层级，主要主体占怎样的空间，次要信息如何退后，参考图只控制哪一部分。若两个要求冲突，先检查能否调整版面；必须牺牲品牌、准确文案或产品事实时才请用户选择。

角色、产品和布局参考分开描述。给模型的参考图顺序应与实际传入素材一致；“第一张管产品、第二张管光线”只有确实传了两张图才成立。不要从参考里顺手带入别人的标志、产品功能或活动信息。

## 原创示例：锁定产品的局部改图

请求：“把这张杯子主图改得适合秋季，杯形和杯身文字别改。”

先查看原图，核对哪部分是杯体、杯柄、印字和背景。若确实是平视产品图，可写：

> 保留参考图片中杯子的轮廓、杯柄位置、材质、颜色及杯身全部文字，保留当前拍摄角度和主体比例。仅把背景改成温暖的浅米色桌面与柔和的秋日下午光线，在杯子后侧远处放少量失焦落叶，不遮挡杯身。接触阴影贴合桌面，杯身印字保持清楚，不增加额外文字或标志。

这段描述须随实际图片调整：原图不是桌面图就不能声称“保留当前桌面”。如果工具不支持精确局部控制，如实说明可能需要后期；生成后仍逐项比对杯柄、轮廓和文字，不把提示词里的“保留”当结果证据。

## 原创示例：海报的构图与文案分开

已知文案只有“秋日市集”，需要温暖而热闹的竖版方案。

- 画面：夜色下几处摊灯照亮蒸汽和摊主的手部动作，用近处食物与中景人群形成纵深；上方留可读标题区。
- 文案：主标题逐字为“秋日市集”；时间地点尚未提供，方案预留位置，不虚构事实。
- 排版：标题与活动信息分层，背景最亮处避开文字区；具体字族仅在确认可用后落实。

出图描述只包含本次要呈现的画面与文字，不把“第二层信息”“标题区布局规则”印进海报。中文生成不准确时保留可用底图，交付待排版状态，不宣称成品文字合格。

## 修改闭环

把本次要求转成可观察验收项，例如“杯身文字未变、秋季光线可辨、产品不被遮挡”。看完实际结果后将问题分到正确位置：产品身份错先修参考，阅读顺序不清先修构图，错字先修文字。一次修改围绕失败原因，避免同时改光线、视角、材质和风格而无法判断效果。

局部修改仍可能影响保留项，复核时同时检查改动区和身份/文字等固定项。保留原版和当前可用结果；需要新增收费任务时按新的具体内容预检，沿用平台授权机制。交付说明聚焦作品与未完成项，不给用户展示内部检查流水账。
