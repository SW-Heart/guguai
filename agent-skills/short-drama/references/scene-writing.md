# 场景、对白与局部改稿

用于写完整场景、对白修订与“平、假、套路化”等反馈。先读用户作品再判断，以下示例只解释方法，不能替换用户题材。

## 把场景写到发生变化

先明确进入场景时各方的处境，以及离开时哪件事改变了。重要人物要有所行动；配角只是递信或路过时，不强行为他补人物弧。对话场景重点看双方各自试图得到什么，以及如何回应对方，而不只是轮流说出背景信息。

场景推进可以是：提出请求，被拒绝，换一种办法，对方让步但附带条件。也可以是一段安静的陪伴使关系缓和。选择符合题材的推进方式，不把所有场景都变成威胁和反转。

关键转折前问两件事：人物凭什么改变判断？这个变化是否进入观众能看到或听到的作品？作者脑中成立、只在设定里存在的原因，需要落到当前作品；已有动作已说明原因时不要再加解释对白。

## 对白有对象、有目的

逐句辨别说话人是在求助、掩饰、试探、拒绝、拖延还是修复关系。两人都用同样句式讲大道理时，从权力关系与处境修：谁有资格直接说、谁只能绕着说、谁此刻不愿回答。

不要用口头禅、方言标签或感叹号代替人物声音。用户的风格化台词可以保留；“自然”也不等于全部改成短句和碎句。锁定台词逐字保留，必要调整只发生在动作、停顿或镜头安排。

原创微例：两姐妹在旧居归还钥匙，姐姐希望妹妹多坐一会。

- 平铺解释：“我舍不得你走，希望你再陪我一会。”
- 可表演的另一种写法：妹妹把钥匙放在桌上。姐姐没有去拿，推开身旁的椅子：“水还没开。”妹妹看一眼冷着的水壶，坐下。

后者依靠椅子、水壶和反应传达挽留；若用户要求直白情感，则前者可能更合适。修订的判断依据是这场戏需要怎样的关系，不能把含蓄当作普遍优越。

## 写成可供下一步使用的剧本

沿用用户现有格式。没有格式时，用“场景位置与时间、在场人物、可见动作、角色台词、必要声音”即可。将动作和对白分开；旁白、画外说话、画面文字只在确实需要时标清，不把动作说明误当台词。

写心理状态时给演员行为依据，但不限制到每个眨眼。对影响剧情的动作写完整接触和结果：拿起、递交、接过、放下分别发生在哪里；不要用“交接完成”跳过决定人物关系的瞬间。

## 时间不是字数配额

台词、动作和反应有些同时发生，有些必须前后完成。估算时把不能重叠的部分相加；台词期间能自然发生的动作不重复计时。数字、英文缩写与专名按实际读法理解；情绪和停顿会改变语速。

没有实际朗读或音频证据时只能称“预计”，不宣称已试听。放不下时优先删同义解释、合并重复动作；如果必须删改用户锁定的台词或延长指定片长，明确提出这项取舍，不擅自加速对白来假装合规。精确倒计时出现时逐个检查动作能否在剩余时间内完成。

## 先修决定问题的那一层

| 症状 | 回查 | 最小修订方向 |
| --- | --- | --- |
| 角色突然改变立场 | 前一行动或新信息是否足以触发 | 补足已有情节的反应，或修连接处；不新造重大身世 |
| 两人像在讲设定 | 每句话有没有当前争取的对象 | 让一方回避或要求对方行动，把必要事实留在交锋中 |
| 情节忙但没有推进 | 场末是否仍和开场一样 | 合并重复行动，让一次选择产生实际后果 |
| 反转只剩惊讶 | 前面有没有可回看的依据 | 调整揭示顺序，让既有线索承担作用 |
| 越润色越不像作者 | 是否擅改人物语气、动机或结局 | 回到原稿，只替换用户点名的句子或段落 |

交付改稿时给完整的修改范围，让用户能直接使用；必要时简短说明关键修改。检查保留项和前后因果后停止，不附赠无关番外或新角色。
