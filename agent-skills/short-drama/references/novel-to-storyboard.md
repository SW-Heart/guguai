# 小说或剧本直出分镜

用于用户给出小说章节、故事或剧本，要求改编成短剧、拆分镜、设计角色场景或估算片长。目标是先让用户看清并认可分镜计划，再把可以直接生成的分镜排到画布，用户点开卡片即可修改并生成。计划只需用户确认一次，不要拆成多轮逐项询问。

## 两步完成

第一步：计划（不调用 storyboard_write）

1. 读完用户给出的全部原文。长文按 offset 读到结尾；没读完的部分不能拆镜。
2. 确定改编取舍：哪些事件、设定、台词必须保留，哪些背景压缩成旁白或快切，哪些删除。原著关键台词逐字保留；为短剧节奏新增的钩子、停顿只加在结构上，不新增设定。
3. 分集与片长：按阶段目标和观看节奏分集，常见单集 60～90 秒；用户指定集数、片长时按用户。章节内容支撑不了的时长不硬凑。
4. 选默认生成设置：用 models_list、models_describe 选一个视频模型，按平台定画幅（短剧默认 9:16），选一个该模型在此画幅下可用的画质，记下可用时长。用户已指定模型时沿用。设置只选不论证。
5. 先拆镜头，再合成生成段（见下文）。
6. 在回复正文给出计划（格式见“计划回复”），以一句确认结束。

第二步：排到画布（用户同意或给出修改后）

7. 按最终计划为每段写完整视频描述，为每个参考写画面描述（见下文）。
8. 调用 storyboard_write 写入：内容不多时一次写完；超过十段左右时先写第一集及全部参考，再用同一 id、最新 revision 和 append 逐集追加，避免单次输出过长被截断。返回错误时按提示修正后重写，不要改成文字交付。
9. 用 documents_write 保存简短的改编说明：取舍、分集、角色与场景设定。不要再贴一份完整分镜表。
10. 回复正文简短交代成果与下一步（见“完成回复”）。

用户明确说不用确认、直接生成时，把两步合并在同一轮完成。

## 镜头与生成段

先按戏剧信息变化拆镜头：观众新知道了什么、人物做了什么决定、关系或危险怎样变化。一句台词不必一个镜头；关键动作要拆细。例如“开坛 → 异物爬出 → 化作金线入口 → 喉咙一凉 → 昏倒”至少四五个镜头，不能压成一句“外婆施蛊，他昏倒”。

再把同一场景、时间连续的相邻镜头合成一个生成段。一段对应一次视频生成，时长必须是所选模型支持的值。合并原则：

- 同一空间、动作连续、人物不换装的镜头可以合并；换场、时间跳跃、回闪单独成段。
- 台词密集或表演要求高的镜头单独成段，方便单独重做。
- 段时长装得下段内全部动作、台词和停顿；不要为凑整多写动作。模型只支持固定时长时，按固定时长安排，多余部分在剪辑时裁掉。

## 生成段描述的写法

每段 prompt 是可直接提交的完整视频描述，不是表格字段。结构：

1. 一句话概述本段：地点、时间、谁在做什么、情绪基调。
2. 引用参考：用 `@名称` 指出出场角色、场景、道具，名称与参考列表完全一致；segments.references 填写对应 key。
3. 按时间写镜头：`0-4秒：景别，机位/运镜，画面与动作，起止状态。` 时间连续覆盖整段时长。每镜一个主要动作、一种主要运镜。
4. 台词与声音：写明说话人和原文台词、旁白、关键音效、音乐情绪和特效；不要求模型生成字幕或屏幕文字。
5. 全程要求：画风、光线色调、保持一致的服装和道具状态；必要的禁止项写一句即可。

示例（Seedance 2.5，9:16，12 秒）：

```
夜晚老宅背阳卧室，昏暗压抑，陆左第一次见到病重的外婆。参考：@陆左 @外婆 @卧室。
0-4秒：中景，固定机位。@陆左 推门进入 @卧室，门缝的光照在发黄的被窝上，他停在门口。
4-8秒：近景，缓慢跟推。@陆左 走到床边坐下，握住 @外婆 枯瘦的手，外婆没有反应。
8-12秒：双人近景，固定。@陆左 的手慢慢松开。母亲在画外低声说：“已经认不出人来了。”
声音：屋外蝉声，低频弦乐。全程：冷灰绿低照度，写实质感，人物服装保持一致。
```

不要在描述里写模型名、分辨率、价格或“生成后裁剪”之类的制作说明。

## 角色、场景、道具参考

每个需要在多段保持一致的角色、主要场景和关键道具各写一项参考，生成一张参考图卡片：

- 角色：三视图，同一人物的正面、侧面、背面全身；写清年龄、体型、脸部特征、发型、服装与配饰；纯色背景。本章特殊状态（如病重卧床）写在各段描述中。
- 场景：空间结构、门窗与主要陈设位置、光源方向、时代与地域特征；不出现人物。
- 道具：形状、尺寸、材质、颜色、特殊细节；单独展示。

同一角色有明显不同状态（如卧床与站立开坛）时，优先一张身份参考，状态在各段描述中写清，不为每种状态都建参考。工作区已有合适的真实图片时填 assetId，不再生成。参考图生成完成后，画布会自动把它关联到引用它的视频卡片。

## 计划回复

让用户一屏内判断“会做出什么”：

- 改编取舍：保留、压缩、删除、新增各一两句。
- 结构：几集、每集与总时长、共多少个生成段。
- 生成段清单：按集分组，每段一行，写段名、时长、包含的镜头概要与关键台词。例如“第1集 · 初见外婆（12秒）：推门进卧室 → 握手无反应 → 母亲：‘已经认不出人来了。’”
- 角色、场景、道具：名称与一句话外观要点。
- 默认生成设置：模型、比例、画质一句话，说明之后可在卡片上修改。
- 结尾一句：确认后会把这些分镜和参考图卡片排到画布；有要调整的地方可以直接说。

不要在计划里写完整视频描述、模型比较、报价或审核扫描，也不要列多个待确认问题。

## 完成回复

只写用户需要知道的成果：已排好几集几段、总时长，有哪些角色与场景卡片，建议先生成哪几张参考图、再从哪一段开始生成视频。不要逐段复述画布内容，不要以一串待确认问题结束。
