# 短剧创作

以用户目标和已确认文本为准。先读取已有作品，保留指定剧情、台词、角色、视觉设定和锁定内容；局部修改只动受影响的场次与镜头。不要因为套用一种套路而补造反转、死线、人物或集数。

## 选择入口与交付范围

| 当前请求 | 先取得什么 | 本轮交付 |
| --- | --- | --- |
| 想法或小说改编 | 用户目标、已读原文、必须保留的事实 | 请求范围内的故事或分集方案；要求成稿时继续写完 |
| 写一集或续写 | 当前大纲、前段结尾与锁定内容 | 完整的目标集/场次，不以概要代替剧本 |
| 改对白或某场戏 | 当前原稿、修改目标 | 可直接使用的局部替换，保留无关段落 |
| 角色、场景、分镜 | 当前剧本、已有设定及参考 | 视觉设定或可制作的镜头安排，明确缺失素材 |
| 由剧本制作视频 | 当前剧本、真实素材与制作要求 | 读取 video-production，继续授权范围内的制作 |

只为影响当前结果的缺项提问。用 `documents_read` 或 `workspace_read` 取得当前版本，历史对话里的旧稿不替代它。对用户用“剧本、角色设定、分镜、项目素材”等直观称呼，内部编号、检查规则和工具流程不写成作品内容。

## 按任务读取详细方法

用 `skills_read` 的 `name: short-drama` 读取对应 `resource`。返回 `nextOffset` 时继续读取同一文件直至结束，再执行所选方法；不要每次遍历全部资料。

- 小说改编、分集规划、长材料或续写：[故事开发](references/story-development.md)。
- 写完整场景、对白、时长取舍或局部改稿：[场景与对白](references/scene-writing.md)。
- 剧本转分镜、关键帧、素材准备与连续性：[分镜交接](references/storyboard-handoff.md)。

## 剧作

明确这一段承诺给观众什么体验、人物现在要什么、阻力来自哪里，以及行动如何改变信息、关系、风险或结果。用“行动 → 可见后果 → 新压力”检查因果；转折要有前面建立的事实或人物选择支撑。对白服务于争取、回避、试探和关系变化，能由行为演出的信息不反复解释。场景没有新增信息或情绪变化时合并或删减。结尾可以兑现、留白或留下下一步压力，不强制悬念。

按真实表演、动作和停顿估计时长；不要按字数机械分配镜头。改编已有剧本时区分原文事实、用户允许的改写和新创作内容。

## 场景推进与人物声音

写场景前明确人物的具体目标、阻力、采取的策略和场末变化。策略可以从试探变成交易或威胁，变化须由对方反应触发；不要只增加音量来制造升级。冲突来自不兼容的欲望或信息差，人物要通过选择承担后果。悬念区分观众知道而角色不知道、角色隐瞒而观众猜测、双方一起发现，安排揭示时间，不用旁白提前泄露。

对白先看这句话在做什么：争取、掩饰、逼问、拒绝或修复关系。依据角色经历与此刻权力关系区分用词、句长、回避方式，不靠口头禅区分所有人。读出对白并留出反应、打断和动作时间；信息能通过递物、停顿或回避视线表达时，避免重复解释。局部润色保留用户指定的事实、人物动机和情节结局。

改稿先定位结构、场景或句子哪个层级出了问题。动机不成立先补行动依据，因果断裂先修事件连接；不要用更多形容词掩盖结构问题。短篇不强制固定节拍、反转数或爽点密度。

## 分镜与视觉连续性

每镜说明叙事作用、观众此刻知道什么、画面起点、一个可执行的主要动作、终点、台词/声音和时长。依据戏剧信息变化切镜，不按每句对白平均切。检查人物位置、视线、衣着、道具持有、场景方向和相邻镜头状态；跨时空或有意跳切不强制首尾帧衔接。

角色、地点和关键道具需要复用时，先写稳定视觉锚点并建立实际参考图；已生成的素材要读取结果后再用于后续镜头。生成视频时可按需读取 `video-production` 技能，按当前模型的真实能力设计镜头与提示词。文字剧本或分镜请求直接交付文字，不自动出图或制作视频。

设计人物走位、观看顺序与运镜时，用 `skills_read` 读取 `video-production` 的 `references/camera-and-blocking.md`；安排多镜头覆盖与接点时读取其 `references/sequence-design.md`。写清人物为什么移动、从哪里走到哪里、何时转身，以及摄影机跟随、等候或接近的关系。重要对白和强表演可用固定镜头；运镜有信息任务才增加。

可用 `documents_write` 保存剧本、设定或分镜表；需要可生成节点时用 `project_edit` 写入项目，按最新 revision 操作，引用工具返回的真实 ID。实际媒体制作按授权使用 `media_prepare`、`media_submit`。交稿前检查剧情因果、对白可表演性、镜头覆盖、时长和连续性；生成结果的外观与表演质量须看真实素材，不能仅凭提示词保证。

## 完成与后续修改

点名的范围完整交付、锁定内容保持、人物行动与场末变化成立即完成。没有要求分镜或出图时到此停止。用户要求整集，不以“可继续写”代替后半集；缺少必需资料时准确说明完成范围与缺项。

修改动机、台词或造型时检查受影响的镜头、提示词及素材，标出需要重做的部分并保留其余成果。遇到 revision 冲突先重读、对照最新内容再局部修改，不用旧稿覆盖。已有生成任务先查进度与结果，不把继续创作解释成重新付费生成全部素材。
