# 视频复刻的外部接口需求

目标是让 GuGu Agent 能理解参考、改编、生成、编排、检查和局部修改作品；不以复制 Hypit 的运行时作为交付条件。本清单按创作能力提出需求，不限定供应商。API 文档与测试素材先交接，密钥通过服务端环境变量配置。新增收费能力必须接入现有报价、授权、任务记录和幂等提交机制，不能在 Skill 中直接请求供应商。

## 已有能力与本次工程

已有图像/视频生成路由、Deepgram 语音识别、素材库与内容哈希、原片观察、顺序剪辑、独立音轨混音、普通/逐词字幕、抽帧与音量检查。

新增 `video_edit` / `video_edit_read`：在底片上编排文字、矩形、图片和无声视频，支持移动、缩放、淡入淡出、图层顺序以及目标台词锚点。可组合画中画、分屏、补充镜头、商品揭示和排名卡片；方案与来源随素材持久化，可跨会话读取并只修改受影响内容。使用已有 FFmpeg，不需要新的生成 API。

Agent 自己决定读取哪些技能、准备哪些素材、调用哪个工具。声明式工具限制参数和资源访问，不把用户任务固定成每次必走的流水线。原文资料按问题读取；尚无真实模型端到端效果结论，工具测试不能替代这种评测。

## 1. 独立配音与可复用音色（优先）

用途：目标文案重写、多语言改编、同一人物跨片段音色连续、画外旁白；视频原生语音不合适时可局部替换。

接口要求：

- 文本、语言、参考声音或持久化 voiceId 作为输入；参考声音的长度、格式、采样率限制有明确文档。
- 中文、英文及中英混说可用；能控制基本语速与语气，支持专名/数字读法或发音词典更好。
- 返回可下载音频、实际时长、任务 ID、失败状态、费用/计费单位；音色 ID 能在后续独立请求复用。
- 明确最长文本、并发、超时、轮询/回调、幂等或任务查询办法。提交超时能查询原任务，避免不确定时重复付费。
- 逐词时间戳是加分项而非前提；GuGu 可用已接入的识别接口对最终音轨补时间并复核。

验收：同一角色三段不同情绪中文对白、一段中英混说、同文两种语速；核对词句完整、数字/专名、音色连续性、实际时长、下载与失败重试。指定人物嘴型与新配音同步是另一项能力，普通 TTS 不保证口型同步。

## 2. 视频与声音联合理解（优先）

用途：判断实际表演、人物互动、动作过程、语音与画面关系、音乐与音效；补足抽帧和 ASR 不能看到/听到的部分。

接口要求：

- 输入视频文件或可访问 URL，支持至少常见短片长度；明确最大时长/体积、采样策略及是否真的读取音轨。
- 支持中文提问和多轮或指定区间复看；输出事件时间范围、观察说明、说话人/出镜人的对应与不确定处。
- 能区分台词、环境声、音乐、关键音效；支持询问“这声响与哪个动作相伴”“两个时刻是否是同一位角色”。
- 返回可校验的时间戳、模型版本、用量和任务/请求标识。是否读音频与读画面必须明确，不能只把 ASR 与少量截图摘要包装成完整视频理解。

验收：快切、甩镜、多角色再次入画、画外说话、短促音效、连续音乐跨镜头六类样例；对照人工标注，记录漏检、误认和时间偏差。模型观察仍需保存证据与不确定性，不把回答当作绝对事实。

## 3. 人物跟踪与视频前景分离（需要对应效果时）

用途：头部跟随字幕、人物轮廓叠加、换背景、前后景层次。可以由两个 API 分别提供。

- 跟踪：输入视频，逐帧或明确频率返回带时间戳的人物/脸部框和稳定 trackId；返回坐标系、原始尺寸、置信度、遮挡/丢失标记；不能只给每帧独立检测框。
- 前景分离：输入视频与可选人物选择，输出与原片帧率、时长对齐的蒙版序列/蒙版视频或带 alpha 的视频；明确多人物、头发、手部、遮挡处理及分辨率限制。
- 验收：多人交叉、出画再入画、侧脸、快速移动、头发与手指边缘、半透明物；跟踪 ID 不应频繁互换，时间轴不能漂移。

拿到轨迹后，GuGu 工程可把坐标映射到字幕与图层关键帧；拿到蒙版后可以工程合成。当前简单位移工具不等于已具备自动跟踪或抠像。

## 4. 人声与伴奏/环境声分离（需要保留原片声音时）

输入混合视频/音频，输出人声与其余声轨，保持采样率与长度对齐；若可再拆音乐/环境声需明确输出定义。返回任务状态、下载地址、价格和失败语义。验收背景音乐下对白、混响、多人交叠与短音效，检查漏音、伪影和同步。只提取视频音轨不等于声源分离。

## 5. 口型同步或表演迁移（精确替换原片人物时）

先核对当前视频生成线路是否接受真实视频参考，并能保持动作、镜头与表演；普通参考图模式不能替代它。若不能满足：需要输入目标人物图/视频、源表演视频、可选目标音频，输出持续一致的视频；明确是仅口型、全身动作、面部表情还是整段视频编辑。模型返回与参考时长/帧率的对应规则必须清楚。

验收不同语言句长、遮挡、侧脸、多人切换、非人角色和手部互动，分别报告身份、动作、口型与背景保持能力。

## 6. 音乐与音效生成（按作品需要）

音乐：输入情绪、风格、时长与节奏，返回可独立混音音轨；可循环、无缝延长与变化段落是加分项。
音效：输入具体声源、动作、长度与强弱，返回独立音频；要求不要附带无关音乐或人声。
已有授权音乐或视频原声可用时不要求额外生成。需明确商业使用条件、计费、可下载格式和任务查询。

## 还可继续补的纯工程

复杂关键帧曲线/弹性动画、图层分组、矢量路径、转场、目标词句对音轨的自动定位、可恢复的独立渲染队列、批量版本管理与工程界面。已有图层工具支持常见基础关系，但不等于任意动画组件或完整剪辑软件。按真实参考样例确定具体效果后扩展工具，不把无法实现的效果藏进模型提示词。
