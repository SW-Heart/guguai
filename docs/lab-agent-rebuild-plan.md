# 实验室升级为 Agent：页面、无限画布与爆款视频复刻计划

日期：2026-09-23。状态：实施中。依据当前工作区代码及 Hypit 仓库快照 `78d7436071ba`。实施时以最新代码和实际模型能力复核接口。

首批已落地：Agent 页面与会话画布存储、短剧新建专业编辑入口、复刻 Skill 绑定、Hypit Skill 原文件留存、平台端视频探测、按时间取帧、物理切镜候选、原片混合音轨提取、Deepgram Nova-3 逐词转录、Agent 项目内共享的带时间证据原片观察、音轨/静音技术检查、分段视频拼接、独立音轨混合，以及基于成片转录的普通/逐词字幕烧录。画布可查看台词时间线、播放同步字幕并下载 SRT。模型评估见 `docs/hypit-model-integration-assessment.md`。直接读完整视频的模型按用户决定暂缓；当前仍需复刻目标方案的结构化存储、独立声音生成、声源分离、精细化音量自动调整，以及实际内容听审。当前混音只支持已提供的独立音频素材，不能从视频原声中拆出音乐；技术检查和转录不能证明成片内容正确。

## 1. 已确定的产品方向

1. 左侧导航的“实验室”改为“Agent”，主地址改为 `/agent`；`/lab` 保留兼容跳转。
2. 默认打开对话首页：居中的输入框、附件入口、模型选择、历史对话和“爆款视频复刻”快捷入口。用户不必先创建短剧或复刻项目。
3. 选择“爆款视频复刻”会为本轮对话绑定复刻 Skill。主 Agent 继续负责理解目标、调用平台工具、读取结果、修正方案和交付；Skill 提供专业方法，不另启一套 Agent 运行时。
4. 将短剧“智能导演”的无限画布提取为 Agent 的通用画布。首页以对话为主；产生作品或用户点“打开画布”时进入画布与对话并排视图。画布显示文稿、参考素材、分析、镜头、生成版本、音频、时间线和成片。
5. “短剧创作”保留分步骤的专业编辑界面。新建短剧不再提供无限画布模式；已有智能导演项目及对话必须能继续访问，内容不丢失。
6. 以 Hypit 的完整 Skill 目录为改造基线，固定上游版本并保留来源记录；执行全部改为 GuGu 平台工具。媒体分析与合成部署在平台服务端，生成模型走 GuGu 管理的模型路由。用户不安装 Hypit CLI，不配置 HypiHub 或其他产品账户，也不依赖用户电脑上的媒体工具。
7. 视频复刻的交付标准是可编辑、可局部重做、可播放的完整成片，包含实际需要的画面、口播/配音、音乐/音效、字幕/图形和音画检查。仅生成若干视频片段不算完成。

## 3. 页面与交互

### 3.1 Agent 首页

- 左侧：新建对话、历史对话、最近作品；按当前账号与设备工作区过滤。
- 中央：一句清楚的创作引导、对话输入、图片/视频/音频附件、模型选择；下方是“爆款视频复刻”快捷按钮。没有选 Skill 时仍可正常聊天、写作和使用通用工具。
- 点击“爆款视频复刻”：输入框上方出现可取消的功能标签，提示上传参考视频并描述需要保留、替换的内容；不立即收费或开始生成。首次发送后将 Skill ID 与版本写入本轮任务。
- 运行中：对话展示当前可理解的进展、待确认的方案、费用和结果卡片；可随时补充要求、暂停、继续或局部修改。
- 画布：初始隐藏；有作品时可一键展开。沿用现有缩放、拖动、选择、锁定、引用、生成草稿、版本和附件交互；补音频节点、分析证据节点、时间线节点和成片节点。时间线节点可展开专门的时间线编辑视图，不用自由画布坐标冒充视频时间轴。
- 小屏：对话与画布切换显示，保持输入框和任务状态可见。

### 3.2 短剧创作

- 新项目只进入现有专业编辑步骤，移除“智能导演/无限画布”创建选项及相关首页文案。旧智能导演项目在迁移验收前通过兼容入口访问；正式切换后短剧页不再承载画布。
- 原智能导演项目的剧本、场次、角色、分镜、素材和视频版本通过显式迁移适配专业编辑；原画布、对话和文稿在 Agent 中打开。项目卡片提供清晰的“继续编辑”和“查看 Agent 创作记录”入口。
- 迁移按项目版本执行、可重复运行；先复制并校验新数据，再切换入口。迁移失败时仍可打开原始内容，不能仅修改 `mode` 字段掩盖缺失数据。

## 4. Agent 创作空间与作品契约

新增 `AgentSpace`（与现有设备 `workspace_id` 区分）：`id / ownerScope / revision / canvasState / linkedDomainProjects / createdAt / updatedAt`。新对话首次产生作品时创建创作空间；会话、画布和作品引用同一个空间。画布只存节点 ID、位置、视口和引用；文稿、媒体、分析和生成版本仍由各自的服务保存。

复刻项目至少保留下列版本化事实：

| 对象 | 必要字段与用途 |
| --- | --- |
| `SourceObservation` | 原片 asset ID、内容 hash、时长/帧率/音轨、抽帧与转录处理版本、镜头段、人物/商品/画面事实、证据时间点、置信度和不确定项。只记录原片事实。 |
| `Transcript` | 原语音、说话人、逐词时间戳、人工修正和修正版本。静音、音乐和无法辨认的语音明确标记。 |
| `TargetPlan` | 用户目标、保留项、替换项、台词局部修改、人物/商品对应、生成段与预算；引用原片证据版本，不回写原片事实。 |
| `Composition` | 视频、配音、音乐、音效、字幕、图形各轨；支持秒数与词 ID 两种锚点，记录每段使用的素材版本、裁切、音量和效果参数。 |
| `RepairSpec` | 返工范围、原因、允许改动的字段、锁定项、旧版与新版资产 ID；只重做受影响片段及后续依赖。 |
| `RenderResult` | 成片 asset ID、使用的 Composition 版本、任务/费用、技术检查和实际试听/观看结论。 |

所有写入使用当前 revision，所有付费提交使用现有报价、授权、幂等键和任务归档。源片分析按 `ownerScope + sourceHash + 处理版本` 缓存；换商品时复用原片事实，重算目标方案。

## 6. 需要新增的平台工具与服务

### 6.1 原片理解

1. 若平台有可直接读视频的多模态模型，先用它对原片做全片概览；仅在该模型确实读取音轨时记录声音判断。概览是待核对的分析，不替代带时间证据的细节检查。
2. 媒体 Worker：服务端探测时长、帧率、尺寸、音轨；抽取指定时间点、时间段和原生连续帧；生成带时间码与逐词标签的网格；给出物理画面变化候选。用原片帧核对全片模型的关键判断，对快切、小字和动作转折加密观察；单次调用限制帧数和费用，但允许多轮加密查看。
3. 平台 ASR：有口播且需要准确台词或词级时间时，使用已接入的 Deepgram Nova-3 识别原片或生成视频，保存逐词时间、置信度、说话人和字幕建议，不要求用户提供外部账户。仍需补齐正式的平台计费与可恢复任务；专名、数字及与镜头相关的时间点需要核对。
4. 分析工具：Agent 可读取原片的实际画面、音频、字幕证据；`source_observation_read/write` 保存可校正的时间线。无法辨认的内容留空并标注，不从画面猜台词。

### 6.2 音频生产

1. 优先复用视频模型生成的口播、环境声和音效。若需要独立旁白或固定音色，再为模型目录增加 `audio` 配音操作，并在需要新音色时增加声音设计。音乐、音效生成和声源分离按项目需求另选模型；接入的每种操作需有准确的语言、时长、格式、参考限制和报价。
2. `/api/generations` 与 Agent `media_prepare/media_submit/jobs_wait` 支持音频任务、幂等扣费、进度、失败恢复、归档到文件库和画布音频节点。
3. `audio_trim/clean/align/mix`：按词句边界裁切、音量与淡入淡出、配音/BGM/音效混音、静音和峰值检查。视频模型自带音频时先识别并明确保留、替换或混合，避免重复口播。
4. 目标台词从 `TargetPlan` 编译为唯一音频脚本；用户只改台词时只重做相关语音与受影响的音画同步部分。源片语音和目标语音各存版本。

### 6.3 制作、合成和检查

1. 按目标片需要，先用已有图像生成能力制作并确认人物、场景、商品、主镜头和关键状态图；保存被接受的图片及其参考关系，供多个视频片段复用。已有合适素材或纯文字视频能满足要求时跳过，不要求每镜一张图。
2. 将当前复刻分段生成封装为 `replica_plan / generation_prepare / generation_submit` 等领域工具，复用既有模型路由和报价；按每段职责传入已确认的图像、必要的原片视频/音频参考、准确台词和声音要求，完整记录提示词、素材顺序、源/目标时间范围及任务 ID。
3. 新增平台端 `composition_preview/render`，完成裁切、拼接、转场、配音、音乐、字幕和图形合成，输出文件库中的完整视频。桌面客户端可下载和本地预览，但完成任务不依赖客户端在线或本地 FFmpeg。
4. 字幕与图形先提供可参数化组件；支持词锚点驱动的卡拉 OK 字幕、商品信息、排名/揭示等常见动态元素。再评估隔离的自定义组件执行，覆盖 Hypit 更自由的组件创作能力。
5. `render_inspect` 读取真实成片：时长、画幅、黑帧/静音/截断、片段接缝、最终 ASR 与目标台词、指定时间的画面和音频。Agent 据实际结果决定局部修复，交付时提供成片及可继续编辑的空间。

## 8. 端到端验收场景

1. 从 `/agent` 新建普通对话，讨论、上传素材、生成文稿或图像；对话和画布在刷新后保持一致。
2. 选择“爆款视频复刻”，上传一条有口播、多次快切的参考视频；获得可定位到原片时间的逐词转录、镜头/动作证据和明确的不确定项。
3. 指定替换商品与人物，确认方案和预算；Agent 生成画面、配音、音乐/音效与完整成片，并可在画布中查看所有版本。
4. 修改一处台词或一段动作，仅重做依赖它的语音、片段和合成；其他已完成素材保持原版，费用重新准确报价。
5. 任务中途关闭页面、重启服务或发送新要求后能继续；未完成任务不被当作成功，已完成任务不重复生成。
6. 已有智能导演短剧、专业短剧和实验室复刻项目都能从新入口或短剧列表访问；原剧本、镜头、生成记录和媒体文件不丢失。
