约 7 分钟阅读

这次要完成什么

第一次练习的重点是走完描述、设置、生成、预览和保存这条完整路径，不必一次掌握所有模型。选择一个无需参考素材的简单画面，可以更容易发现自己在哪一步需要帮助。

完成标志是得到能看见、能找到实际文件的图片；一段文字回复、一个等待中的任务或只看见缩略图，都不能替代最后的检查。

  • 目标：生成一张主体清楚、光线自然的橘猫图片。
  • 需要准备：已安装 GuGu AI、能够登录的账户，以及足够支付本次生成费用的积分。
  • 本次不需要参考图片，也不需要提前写剧本。完成后你会得到一张可以预览和在电脑上找到的图片。

第 1 步：打开客户端并登录

官网用于了解功能、查看价格和下载客户端；本次图片创作在客户端完成。登录后先确认账户身份与积分余额，后面再次打开历史作品时也要使用同一账户。

如果下载页面与你的电脑系统不匹配，先换正确安装包。不要为了开始练习，在不支持的设备上反复尝试安装，也不要关闭系统安全设置来绕过所有提示。

  1. 在官网的下载区域选择与你的电脑对应的安装包。Windows 使用 x64 版本；macOS 使用 Apple Silicon 版本。安装完成后打开 GuGu AI。
  2. 在登录页选择「短信登录」或「密码登录」，填写该方式所需的信息，再点击「登录」。验证码和密码只在登录页面输入。
  3. 进入工作台后，找到左侧导航中的「图像生成」。如果导航只显示图标，将鼠标移到图标上查看名称。点击它进入图片创作页面。

第 2 步：填写第一段创作描述

在左侧的「创作描述」中输入下面的示例。这段描述已经包含主体、地点、光线、景别和风格，第一次可以直接使用。

示例中的每句话都有作用：橘猫是主体，窗台是地点，左侧暖光决定照明，中景和完整出现决定构图。先照着生成一张，再改其中一个条件，才容易看出描述怎样影响结果。

例如要换成夜景，就修改时间和光线，保持主体与构图不变。不要同时更换动物、地点、风格和镜头，否则很难判断哪一项带来了变化。

小提示「创作描述」是你希望图片呈现的内容。这里应当写画面，不要只写「帮我做一张好看的图」。

第 3 步：选择设置并开始生成

模型负责生成方式，比例负责画面形状，清晰度或质量负责该模型的输出档位，数量负责本次结果数。它们控制不同内容，第一次选基础设置即可，先检查画面是否成立。

「数量 1」适用于支持单张数量的模型；Midjourney 等按一组多张返回时，使用它自己的有效数量。提交前看本次总价，不根据教程里的一张练习图推断所有模型都按一张收费。

  1. 在「模型」中选择一个当前可用的图像模型。暂时不确定选哪个时，先使用页面已经选中的可用模型。
  2. 在「画面比例」中选择 1:1。本次用正方形方便查看；以后做竖屏封面可选择 9:16，做横版场景可选择 16:9。
  3. 查看模型提供的「质量」或「清晰度」。第一次先使用当前的基础或默认选项，不需要把所有参数都调到最高。
  4. 将「生成数量」设为 1，检查「生成图像」按钮附近显示的积分费用。确认余额足够、描述正确后，点击「生成图像」一次。
小提示模型、画面比例和数量改变后，费用也可能改变。请在最终设置完成后再确认费用。

第 4 步：查看结果并找到文件

先看整体构图，再放大检查主体、边缘与不需要的文字。满意后从作品的文件操作找到实际图片，并按用途保存一个容易辨认的名称；仅截图预览区域不是保存原作品。

如果只想换背景或光线，先保留这张图片作为参考。已经满意的主体有助于下一轮明确哪些内容应该稳定，而不是从零重新描述。

  1. 在右侧「我的作品」中查看这次任务。正在生成时等待状态更新；想找之前的尝试，可以切换到「历史记录」。
  2. 任务完成后点击作品，打开「文件详情」查看大图。检查猫是否完整、光线是否符合要求，以及是否出现不需要的文字。
  3. 在详情中点击「在文件夹中显示」，打开作品所在的电脑文件夹。也可以使用页面顶部的「素材文件夹」查看已保存素材。
  4. 把满意的图片复制到自己管理的项目文件夹中。重新打开该图片，确认它可以正常显示。

第一次结果不理想，怎样继续

把「不好看」拆成能处理的问题：主体太小、画面被裁切、背景太乱、光线不对，或出现多余文字。每次先解决一个最影响用途的问题，并在重新生成前核对费用。

如果结果符合描述，但不是你想象的风格，说明需要补充偏好；任务明确失败则按故障指南检查。效果不满意与生成失败的积分处理不同，不能混为一谈。

  • 构图太近：在描述里补充「中景，完整身体，四周留出空间」。
  • 背景太复杂：补充「窗外虚化，背景简洁，不出现其他动物」。
  • 方向基本正确：修改一个问题后再生成一次，便于比较哪句话起到了作用。
  • 页面出现明确的失败提示：先读原因，核对积分和参数，再按故障处理教程操作。

直接生成与 Agent 的差异

直接生成适合目标已经清楚的单次任务：你自己填写描述、选择模型、检查参数和费用。Agent 更适合还需要拆解、分析素材，或需要串联生成与后期的任务；它可以先查可用方式，再根据对话准备下一步。

使用 Agent 仍然需要检查实际素材、生成确认与作品。它的文字创作可能产生积分消耗，后续图片和视频生成另按对应规则计费。多聊几轮不等于免费，也不保证每轮都会生成一个视频。

短剧工作台与 Agent 合成的差异

短剧创作把多个镜头放在明确的分镜顺序里，适合逐镜写内容、比较版本，然后选中本次要用的镜头。当前工作台合成最终作品后会锁定编辑，合成前应完成版本检查。

Agent 更适合对已有片段提出具体的裁剪和声音要求，例如保留各段的某几秒、放入自己的录音、最后做字幕。你也可以先在短剧里得到成片，再交给 Agent 做后期。两者可以组合，不必在一个入口完成全部工作。

三个常见选择案例

电商白底商品图：先用图像生成，加真实产品参考，检查外观；不需要先创建短剧项目。口播视频加字幕：直接把现成视频交给 Agent，先核对台词；不需要重新生成说话人。

有三幕转折的小故事：先用 Agent 整理剧本与分镜，再在短剧里逐镜生成或由 Agent 制作，最后合成。故事超过单段模型时长时，应该拆镜头，而不是把整部故事塞进一段描述。

约 4 分钟阅读

画幅与清晰度

画幅是宽与高的比例，例如 9:16 是竖屏，16:9 是横屏。清晰度或分辨率是输出尺寸档位，例如 1K、2K 或 720p。竖屏可以有不同输出档位，高清也不意味着一定横屏。

画幅选错，人物或商品可能被裁切；档位太低，放大时细节可能不够。先按用途确定比例和构图，再按实际展示尺寸选择清晰度。

质量、数量与版本

质量是某些模型提供的创作档位，不同模型的同名档位未必一样。数量表示本次要生成多少个结果，增加数量会改变费用。版本则是同一需求多次尝试的不同结果，不一定来自同一次生成。

挑选了最满意的一版，只决定后续使用哪个作品；已经完成的其他生成并不会因此自动不计费。必要时保留小样与正式版本的名称，减少误用旧稿。

参考、首帧与尾帧

参考素材帮助表达外观、动作或风格，首帧与尾帧则是指定视频开始与结束的图片。相同图片放在不同位置，作用可能不同，必须使用模型提供的相应方式。

尾帧也可以来自一个已完成视频的结束画面。将其用于下一段首帧，有助于说明动作起点，但不能保证整段完全一致或无缝连接。

分镜、生成片段与成片

分镜是把故事拆成镜头的制作安排；生成片段是已经能播放的单镜视频；成片是把需要的镜头顺序、声音与文字合并后的实际视频。写出分镜表不等于已经生成每一镜。

目标 30 秒成片可以由多个更短的可用区间组成。生成长度、保留区间与成片长度应分别记录，费用一般按实际生成的长度计算。

原声、配音与字幕

原声是视频里已有的声音，可能混合对白、音乐与环境声。配音是准备好的独立录音或模型支持方式中生成的声音；加入独立录音需要实际音频文件。字幕是根据台词与时间显示的文字，不是声音本身。

关闭原声会同时影响其中的混合声音，不能默认只关闭说话人。字幕应在镜头和声音确认后制作，剪辑或换配音后需要重新核对时间。

下载前确认你的电脑

下载前确认系统与处理器，Windows x64 和 macOS Apple Silicon 使用不同的安装包。系统名称相同但处理器不同，也不应直接使用另一种包；以下载页实际提供的版本为准。

安装客户端不会自动把其他电脑上的作品搬过来。若是更换设备，先整理旧设备中的重要素材与成片，之后分别核对登录账户和本机文件。

  • Windows：查看系统的「关于」信息，确认是适合 x64 安装包的电脑。官网目前提供 Windows x64 版。
  • macOS：点击屏幕左上角的苹果菜单，选择「关于本机」。显示 Apple M 系列芯片的电脑使用 Apple Silicon 版。

先判断「我现在有什么」和「我想得到什么」，再选择模块。下面把各入口、常见页面区域和可直接尝试的创作路线说明清楚。

约 6 分钟阅读

根据目标选择模块

把工作台理解成几条相互配合的创作路线：Agent 帮你理解和处理任务，生成页用于一次明确的图片或视频，短剧创作用于逐镜管理故事，文件库用于找到可复用内容。

例如已有口播只要字幕，应使用后期路线；想从零做一张商品图，先进入图像生成。选择入口的依据是这一步的交付，不是哪个模块看起来更复杂。

  • 只有想法，还没确定画面：进入左侧「Agent」创作助手，通过对话整理方向。官网帮助文档把这个模块称为「创作助手」。
  • 想直接得到图片：进入「图像生成」，填写描述、选择参考图和画面比例。
  • 想直接得到动态片段：进入「视频生成」，设置动作、参考方式、画幅和时长。
  • 想做多个连续镜头：进入「短剧创作」，创建项目，在分镜工作台中逐个制作镜头。
  • 想找已有图片、视频或音频：进入「文件库」，按文件类型筛选或搜索名称。

认识图像和视频页面

左侧输入与参数决定这次创作，右侧作品区域用于查看结果。描述和参数都要检查：写在文字里的「竖屏」或「五秒」，不能替代实际比例和时长选项。

生成后先确认任务是否完成，再进入详情看原作品。旧结果可以作为后续输入，但开始新任务前仍要确认本次真正带入了哪些素材。

  • 左侧创作区：填写「创作描述」、选择模型、添加参考素材和调整参数。
  • 生成按钮：图像页是「生成图像」，视频页是「生成视频」。按钮附近的积分数用于确认本次费用。
  • 右侧「我的作品」：查看生成中的任务和已完成作品。点击已完成作品可以打开详情。
  • 「历史记录」：回看之前的生成尝试，便于对照描述、参数和失败原因。
  • 「素材文件夹」或详情里的「在文件夹中显示」：找到作品在电脑上的文件。

路线一：从一句话做出一张图

这条路线适合头像、封面、场景、插画等单张画面。先确定主体与用途，写一段足够具体的描述；涉及真实商品或稳定角色时，再加入清晰图片作为参考。

不确定风格时先做一个小样，而不是同时生成大量不同内容。满意后保存描述、参考与参数，便于后面知道哪一版可以继续使用。

  1. 打开图像生成，写清主体、环境和画面风格。
  2. 先选一种画面比例、基础清晰度和 1 张生成数量，确认费用后生成。
  3. 看结果，修改一个具体问题，再生成第二版。
  4. 确定满意版本，保存文件；需要动态效果时，继续尝试视频生成。

路线二：已有图片，想让它动起来

已有图片能提供人物、商品或场景的外观，视频描述还要补动作、运镜和终点。先让主体做一个清楚动作，检查参考图是否与最终画幅接近，减少边缘裁切。

直接从图片详情进入视频页可以省去重新查找，但仍需核对参考缩略图。想明确指定开始画面时，使用模型支持的首帧方式，不能把普通参考当成首帧。

  1. 准备一张主体完整、外观明确的图片。
  2. 进入视频生成，选择支持图片参考或首帧的模型。
  3. 添加图片，描述主体动作和镜头移动，选择支持的时长。
  4. 预览结果，检查运动是否自然、主体是否改变，再保存视频。

路线三：做一个短故事

故事制作先决定观众需要看见的事件，再把事件拆成镜头。每镜有明确的主体、动作和用途，后面才方便生成、比较版本和合成；一个模糊的大纲不足以直接制作全部视频。

若想掌控各镜版本，使用短剧工作台；若已有镜头只缺剪辑、旁白或字幕，可以交给 Agent。不要因为是短故事就重新生成所有现成素材。

  1. 先让创作助手帮你把故事写成三组镜头。
  2. 准备一致的人物和场景参考图。
  3. 进入短剧创作并创建项目，逐个建立分镜、添加素材、生成视频。
  4. 确认至少两个可用镜头，按分镜顺序合成并检查成片。
小提示先从两个或三个镜头开始。故事越长，越需要在生成前确认角色、场景、时长和预算。

账户与文件要分别确认

积分余额和积分明细在账户相关入口中查看；素材文件在当前电脑的素材文件夹中查看。更换账户时，请核对当前身份；更换电脑时，请自己保留和转移重要作品文件。

账户积分跟随购买与创作时的登录身份，电脑上的文件则要按当前设备确认。看到余额正常，只能说明账户额度可见；看到项目名称，也不表示每份素材都在新电脑上。

正式交付前找到能播放的实际文件并保存。需要继续修改时，同时保留无字幕成片、源镜头和音频，避免以后只有一个无法拆开编辑的版本。

完整流程：分镜、生成、配音、合成与字幕

这一篇把核心操作连在一起：先确定镜头和声音，再复用或生成素材，接着剪辑、放入已有配音，最后制作字幕并保存成片。可以在 Agent 中按阶段完成。

约 6 分钟阅读

第 1 步：交代目标和现有素材

这一步要把需求从一句「做短片」变成具体交付：给谁看、展示什么、用什么素材、怎样处理声音。已有视频和录音应先告诉助手，要求检查可用内容，再列缺口。

先只做方案可以避免在目标未确认时开始媒体生成，但文字创作本身仍可能产生用量费用。把本阶段目标写清，看到方案后再逐项决定。

第 2 步：确认分镜与时间

确认分镜时同时看信息和时间：每镜有没有必要、动作能否完成、台词能否说完、前后是否能接上。生成长度是模型提供的选项，最终保留长度是剪辑决定的区间，两者不一定相同。

先规划旁白如何覆盖镜头，避免镜头都做好后才发现录音过长。参考人物、道具和画幅也应统一，合成工具不能自动修正外观错误。

  1. 检查每镜的用途、主体、场景、动作、起止状态和声音。
  2. 区分模型要生成的时长与成片要保留的时长。
  3. 确定原视频哪些区间可用，哪些镜头需要补生成。
  4. 核对统一画幅、生成次数、独立音频和字幕计划；费用未知时先核实报价。

第 3 步：只生成缺少的镜头

先补最影响成片的一镜，检查主角、商品或核心动作。方向正确再继续下一镜；方向不对时先定位参考或描述问题，不扩大数量让助手碰运气。

每次新生成都有自己的参数与费用。保留已经成功的镜头，要求只处理缺口，减少费用与不必要的外观变化。

  1. 用 @ 指定需要保持的产品、角色或场景参考。
  2. 要求 Agent 为缺少的一镜准备完整描述、模型参数和费用。
  3. 确认后生成，实际预览，不满意时只改这一镜。
  4. 新镜头成功后保留结果，再检查是否还缺其他内容。
小提示分镜和提示词是方案。要求实际成片时，必须继续完成真实镜头和后期，不以方案作为最终文件。

第 4 步：剪辑并放入配音

旁白比画面长时先调整文稿或镜头安排，不要截断台词。配音需要实际音频，当前不能直接把任意文字变成独立录音。

画面与旁白需要同时安排：指定每份视频保留哪一段，以及录音在新成片什么时候开始。原视频区间是各源片自己的时间，旁白位置则是合成后的视频时间。

如果旁白比画面长，先商量补镜头、调整区间或重新录更短文稿。不要让一句话在结尾突然被切断，也不要默认助手能任意改变说话速度。

第 5 步：最后做字幕

字幕必须对应最后采用的画面和声音。先识别真实台词，校正品牌、人名和数字，再决定普通字幕还是逐词高亮；配音或镜序改动后，重新核对时间。

字幕本身不能修正说错的话。想把「十九元」改成「二十九元」时，需要实际声音与商品事实都正确，而不是只在画面上换一个数字。

  1. 镜头和声音确认后，引用最终成片，请 Agent 识别台词。
  2. 核对品牌、人物、价格、数字和断句，指出具体修改。
  3. 要求根据最终实际语音时间制作普通或逐词字幕。
  4. 改变了镜头或配音时，重新核对字幕时间，不直接沿用旧版。

第 6 步：完整播放并保存

检查应该是完整播放，而不只抽看封面或几秒。镜头接点、最后一句台词、音乐结束、字幕尾句和文件时长都可能在末尾出现问题，交付前逐项核对。

保存成片的同时保留源镜头、独立音频与无字幕版本。以后只改标题或旁白时，能从原素材继续，比处理已经把所有效果烙进画面的成片更方便。

  1. 从头播放最终视频，看镜序、接点、画幅和关键动作。
  2. 听完整声音，确认原声、旁白和音乐没有冲突。
  3. 看字幕是否准确、同步，标题是否遮挡主体。
  4. 用作品的文件操作找到并保存实际成片，同时保留无字幕原片和源素材。

想逐镜手动操作时

也可以先在「短剧创作」中逐个生成、选择分镜版本，并完成「分镜合成」，再把得到的成片交给 Agent 添加已有配音、音乐、标题和字幕。当前短剧工作台合成后会锁定编辑，合成前先确认各镜头。

手动分镜适合你要逐镜写内容、查看多个版本，再决定最终镜序；Agent 后期适合按具体秒数安排剪辑、声音与文字。先选哪条路线取决于你想控制哪一部分。

当前短剧工作台合成后锁定编辑，所以先检查采用版本再合成。需要继续做声音和字幕，可以把最终视频作为 Agent 的现有素材使用。

@ 功能与自动引用：写好 @文件名，一次引用多份素材

GuGu AI 支持自动 @ 引用：在提示词中提前写好 @文件名，把整段提示词放入输入框后，就会自动匹配并引用对应素材，不需要用户手动逐个输入 @、搜索和选择文件。你也可以使用候选列表手动选择。下面重点介绍自动引用的步骤、示例与核对方法。

约 8 分钟阅读

什么时候需要 @

@ 最有用的地方是消除指代歧义：同一项目有多个主角版本、两段视频和一份录音时，明确选择哪一份，比说「刚才那个」可靠。它解决素材指向，不能替代对素材用途的说明。

例如同一张图可以负责人物外观，也可以只提供光线。引用完成后紧接着写职责，模型和助手才更容易理解你希望保持什么。

  • 多张参考图：一张指定主角，一张指定场景，避免模型把两张图的作用混在一起。
  • 视频续拍或修改：指定需要处理的原视频，避免误改其他版本。
  • 声音合成：分别指定配音、背景音乐和需要保留的视频原声。
  • 同一项目的连续镜头：反复使用同一人物参考，让各镜头共享清楚的外观要求。
  • 只有纯文字想法时，不必为了使用 @ 而先添加一张无关图片。

先准备可引用的素材

素材应能实际预览，并且能在当前入口找到。先为关键文件命名，再开始长对话；「主角最终版」「开场采用版」比一串相似文件名更容易判断。

不要把没有上传或没有生成的素材写成已存在。列表里没有时先添加，缺少素材就明确说需要准备，而不是靠一个看似正确的 @ 名称蒙混过去。

  1. 把要用的文件上传到文件库，或在当前项目中添加、生成素材。
  2. 打开预览确认文件正确，并设置好区分的名称，例如「主角蓝外套」「书店暖光」「口播录音」。
  3. 进入要写描述或发送消息的输入框。图像、视频页面有参考选择入口；助手项目中可通过添加附件或画布内容使用素材。
  4. 确认当前账户和项目可以访问这份素材。素材找不到时，先从当前入口添加，不要只编写一个不存在的名称。

重点：整段提示词自动 @，不必逐个选文件

当多个镜头需要反复使用同一人物、场景和道具，或已经在其他地方写好了完整提示词时，可以直接使用自动引用。把每份素材写成 @文件名，并在旁边说明用途，再将整段提示词放入输入框。系统会自动匹配对应的已有素材。

自动引用与手动选择都是使用真实素材的方式。自动引用省去逐个打开候选列表的操作，尤其适合包含多份参考的描述；手动选择适合临时补充素材或不确定名称时使用。

  1. 先准备要使用的素材，确认它们在当前入口可用，并查看实际文件名称。
  2. 在提示词中写好 @文件名，分别交代人物、场景、产品、视频或音频的用途。名称按实际素材填写。
  3. 复制完整提示词并放入输入框，等待自动匹配和引用，不需要逐个手动选择。
  4. 核对输入框中的引用和参考区域，确认匹配的是本次要用的版本。
  5. 继续核对模型、参考方式、数量和费用，再发送或开始生成。
小提示示例文件名需要换成你的实际素材名称。自动引用不会凭空创建文件；未匹配时先检查名称、素材是否已准备好，以及当前入口是否可用。同名素材可先重命名或用候选列表确认。

图像和视频页中的 @

在「创作描述」中放入含 @文件名 的提示词，会自动引用对应的已有素材；也可输入 @ 后从候选列表手动选择。图像生成只使用适用的图片；视频素材类型和数量受当前模型及参考方式限制。添加了多个素材时，分别说清职责。

图像和视频页的引用用于本次生成，不代表文件库里的所有内容都会一起参与。只保留与目标有关的参考，并说明主体、场景和风格分别由谁负责。

视频首尾帧有自己的位置与顺序。用 @ 写出一份图片名称，不能把普通参考自动变成首帧，也不能绕过当前模型对素材类型或数量的限制。

小提示示例的名称需要替换成你实际选择的素材。普通参考与首尾帧不能任意混用；首尾帧仍应放进对应位置，@ 不能绕过模型限制。

Agent 里怎样组合图片、视频与声音

指定素材之后还要指定动作。「参考这份视频」「裁掉这份视频的开头」「提取这份视频的声音」是不同任务。需要后期时明确说用已有素材，避免把参考理解成重新生成。

Agent 能对实际素材提出不同操作，表达方式要连同动作写清。希望剪辑就说「保留第几秒并拼接」；希望分析就说「先拆解不生成」；希望旁白就说明独立录音的开始位置。

这样可以减少把旧视频当作新生成参考的误解。保留成功片段并指明采用版本，后续才容易做局部修改。

引用后怎样修改或删除

引用只是本次任务的选择，移除引用通常不等于删除原文件。换版本时先检查新素材，再替换旧引用；有多个同名文件时先重命名后继续。

列表为空先核对项目与可用文件类型。不要为了修正一次选错而清空文件库，也不要删掉以后可能用来继续剪辑的原片。

  • 选错文件：删除或移除这条引用，再从候选列表重新选正确文件。
  • 只想取消本次参考：移除生成页中的缩略图并检查描述中的引用，不需要删除文件库原素材。
  • 多份同名素材：先重命名，保证名称可区分，再重新引用。
  • 列表为空：检查是否在正确项目、素材是否准备完成，以及当前入口支持的文件类型。
  • 助手引用了旧版本：明确指出要改用哪份新素材，并检查下一次确认。

也可以手动选择：边写边补充素材

支持自动 @ 引用：提前在提示词中写好 @文件名，整段放入输入框后会自动匹配并引用对应素材，不需要逐个打开候选列表。使用教程示例时，只需将示例名称改为自己已有素材的实际名称。

输入框里的标签或名称有助于检查，但最后还要查看实际参考区域与生成确认，尤其在切换模型或模式之后。

  1. 把光标放在需要引用的位置，输入 @。助手对话中可先输入一个空格再输入 @，更容易触发候选列表。
  2. 在素材列表中选中对应项；可继续输入名称的一部分缩小范围。
  3. 点击候选项，确认输入框中出现该素材的引用。部分输入框显示为标签，部分显示为 @名称。
  4. 继续写它在本次任务中的用途，例如「保留外观」「只参考光线」「采用第 2–6 秒」。
  5. 生成前核对参考区域或确认窗口，确保本次实际使用的素材与描述一致。
小提示候选列表已打开时，Enter 可能先选择素材，不是发送消息。先确认引用已经插入，再执行发送。也可以直接放入已写好 @文件名 的完整提示词，自动引用后核对对应素材即可。

图片提示词：主体、构图、风格与修改方法

提示词就是向生成模型说明你想要什么的画面描述。先写清主体、环境、构图和光线，再结合实际参考素材补充风格与限制。这篇提供可直接改写的图片模板。

约 7 分钟阅读

先写一个核心画面

从一句能看见具体画面的句子开始。例如「一位穿深蓝外套的女孩站在雨夜路口，手里拿着透明雨伞」。这比「高级、唯美、有故事感」更容易确定主体和动作。

提示词首先要让人能想象出一个确定画面。主体、位置、姿势、环境和光线比连续写「高级、绝美、震撼」更有信息；风格词可以补充，但不能互相冲突。

如果目标是商品图，把商品外观与构图放在前面；如果是角色参考，把脸型、发型、服装和姿态放在前面。不同用途应该强调不同细节。

  • 主体：人物、动物或商品，写出重要外观。
  • 环境：地点、时间、天气、背景。
  • 构图：远景、中景或近景，主体的位置和需要完整出现的部分。
  • 光线与风格：自然光、侧光、冷暖色调，写实或插画。
  • 限制：不要的文字、额外人物、品牌或背景元素。

可以直接替换的图片模板

使用时把方括号内容换成你的需求，不要原样发送占位词。画面比例在页面参数中选择，描述里重点写主体和构图。

模板只是帮助检查遗漏，不需要每次写成同样长度。先替换主体与环境，再删掉不需要的限制；没有真实参考时，不要为了填满模板编写一个素材名称。

画幅、数量和清晰度仍在参数区域核对。描述里强调完整主体、四周留白能帮助构图，但不能代替比例选择。

图片描述示例

示例把稳定内容与表现方式分开：角色、服装、伞是要保持的细节，雨夜、霓虹和冷暖光是氛围，中景与画面位置是构图。理解这些作用后，才适合替换成自己的主题。

商品或人像需要准确细节时，准备清晰参考。文字描述不是事实证明，也不能保证生成结果中的标志、数字和小字全部正确。

视频描述还要补充什么

图片描述关注一瞬间，视频描述关注从起点到终点的变化。不能只给一个漂亮静帧，再期待模型自动知道什么时候转头、怎样拿起物品或镜头如何移动。

先写一个主要动作，用自然顺序说明前后，声音另行交代。短镜头里事件太多时，先拆成分镜而不是继续堆内容。

  • 主体动作：先做什么，再做什么；每段短镜头先安排一个主要动作。
  • 镜头运动：固定、缓慢推进、轻微跟随等，避免同一段又拉远又快速绕行。
  • 变化节奏：动作缓慢还是迅速，环境是否变化。
  • 声音：只有在当前模型支持时，再说明对白、环境声、音乐或静音要求。不要默认每个模型都支持声音。

多张参考素材怎样写

先分配职责。例如第一张参考人物，第二张参考场景，第三张只参考光线。这样更容易发现哪个要求被误解。

每张参考最好负责一类内容，明确哪些外观不变、哪些氛围可借鉴。人物图和风格图都有不同角色时，应说不采用风格图中的人物，减少融合与误用。

先通过 @ 完成真实引用，再写职责。希望商品保持原样时，不要同时要求夸张变形或让它具备参考图里没有的结构。

小提示如果使用 @ 引用，应选择页面提供的真实素材。写出的素材名称应与实际添加的素材对应。

结果不满意时，一次改一件事

修改前先保留原描述与满意版本，找到一个最明显的偏差。只改背景可以观察背景词的作用，只改构图可以观察景别的作用；一口气重写全部内容会使经验难以积累。

已经正确的主体可以作为后续参考，新任务依然要确认费用。高分辨率不自动修好手部或商品形状，应先处理内容问题。

  • 主体不够突出：补充主体位置、景别和背景简洁程度。
  • 人物外观变化：减少不必要的外观描述，强调需要保留的发型、服装和参考素材。
  • 动作过多或异常：把动作拆短，先生成一个主要动作。
  • 镜头乱动：明确写「固定镜头」或一种缓慢运动方式。
  • 颜色偏离：写出具体主色与光线，不要只说「高级」。
  • 出现多余文字：明确不需要文字，并检查结果。需要精确文案时，后续仍应逐字核对。

请助手帮忙，但保留你的决定

收到改写后再看一遍，确认助手没有擅自加入新的角色、故事或商品特征，再复制到生成页面。

让助手优化时，要求保留必须准确的内容、给完整可复制描述，并解释关键改动。选择新稿的标准是更明确与更可执行，而不是更长或形容词更多。

发现助手新增品牌、卖点、人物或台词时先纠正。只要描述还未满意，就明确暂不提交媒体生成，避免把文字讨论误当成开工授权。

给 Agent 写需求：任务、素材、规格和交付

给 Agent 的提示词是一段任务说明，不必写成复杂格式。说清要做什么、用哪份素材、采用什么规格、这一步要得到什么，通常比堆形容词更有效。

约 5 分钟阅读

一个完整需求的六个部分

一条完整需求应能回答「做什么、用什么、做到什么程度」。目标和素材决定范围，动作决定是写作还是处理文件，规格与交付决定最后要检查什么。

例如「帮我优化视频」可能指重新生成，也可能只指剪掉空等。把操作写清楚，比要求助手自行猜测更容易控制结果和费用。

  • 目标：要给谁看、用在哪里，观众应理解什么。
  • 已有内容：文案、人物图、商品图、原视频或音频；用 @ 指定实际素材。
  • 动作：分析、改写、生成、裁剪、合成、加字幕，说明具体要做哪一种。
  • 规格：画幅、目标时长、输出档位，和必须保留的特点。
  • 声音与文字：原声、配音、音乐、字幕分别要不要，文字应当是什么。
  • 交付与费用：先给方案、先给描述，还是开始制作；新生成的费用需要怎样确认。

只想要方案时

把「先只给方案」写清楚，助手可以先讨论和查询能力。方案满意后，再明确采用哪一个方案并开始制作。

先只做方案时，交付应是你能评审的镜头结构、素材缺口与可用参数。可以要求比较两个方向，但不要把方案阶段写成「全部生成好再让我看看」。

方案确定后，明确采用哪一版，再要求准备下一步。本阶段不提交图片视频，不代表文字处理一定没有积分消耗。

要制作实际作品时

实际作品需要能预览的结果。告诉助手优先复用哪些已经完成的图片或视频，以及哪些内容确实缺少，让它把制作安排与真实文件对应起来。

不要只用一句「就按这个来」承接一个含糊方案。补上画幅、声音、数量和确认方式，尤其在方案中列了多个候选模型时。

小提示分清目标成片时长和各次生成时长。生成后再裁短，费用仍可能按实际生成的长度计算。

要剪辑已有素材时

已有素材剪辑应指定源片区间、顺序与原声处理。录音、背景音乐和标题出现在新成片的时间，与原视频要保留的时间分别说明。

要求「只剪现有素材」有助于防止助手把参考视频重新生成。素材太短或声音长度不够时，先给调整方案，再决定要不要补制作。

要修改一个局部时

说明保留什么和只改什么。不要只说「再高级一点」，可以改成「背景更简洁、标题更小、镜头停顿减少一秒」。

局部修改应能指出具体版本、时间、要改的内容和需要保留的部分。标题已经成为某个外部视频的画面内容时，不能当作一层可编辑文字随便删除，需要先讨论实际可行方式。

如果是助手此前制作的图文编辑版本，可以要求从原底片沿用其他效果，只修改目标内容。这样避免把旧字和新字重复叠在一起。

助手理解错了怎么纠正

纠正时先说明任务类型的偏差，再重新指向正确素材。错误可能来自指代、版本、时长或不支持的方式，只有定位到原因才能决定继续还是换方案。

重新安排生成时核对新增数量与费用，不因为它属于同一个项目就默认旧授权包含所有新任务。明确修改后的交付，方便判断是否已经做完。

  1. 指出具体偏差，例如「我要求只剪已有视频，不要生成新镜头」。
  2. 重申正确素材和版本，必要时重新 @ 引用。
  3. 如果使用的时长或参考方式不可用，让助手提供当前可执行的替代安排。
  4. 采用替代方案前核对新增制作内容和费用，避免把方案变更当作原任务已完成。

图片描述重在一张画面；视频描述还要说明从哪里开始、发生什么、怎样结束和听见什么。先写一个可实现的动作，再安排镜头与声音。

约 7 分钟阅读

按四个阶段写一段镜头

起点、动作和终点构成最基本的时间变化，镜头只是观看这些变化的方式。先让动作自然成立，再增加运镜；主体做复杂动作、镜头又快速绕行时，更难判断哪里出了问题。

同一镜头里优先使用一种主要运镜，不能同时要求固定机位与不断绕主体转动。复杂故事应先拆成镜头，而不是把所有事件压进一个短视频。

  • 起点：主体在哪里、是什么姿势、环境和关键特征。
  • 动作：主体先做什么再做什么，用具体动词。
  • 镜头：景别、视角和一种主要运镜，避免互相冲突。
  • 终点与声音：结束时的状态、要听见的台词或环境声，以及不需要的音乐和字幕。

可替换的视频模板

模板把外观、动作、镜头与声音分开，便于后面只改一部分。真实参考先选好，再将人物或商品的稳定特征写清；不需要的条目可删掉。

参数区决定模型实际可生成的时长。描述中的节奏要与这个长度相容，不能写三句长对白却只给一个极短镜头。

小提示用 @ 引用真实素材，再把方括号替换成自己的内容。时长、画幅和输出档位还应在参数或生成确认中核对。

人物镜头示例

人物示例的重点是连续动作和反应：翻书、发现信封、停顿、抬头，前后必须保持道具和服装。使用角色与场景参考，有助于给每镜一个可核对的外观目标。

检查时看脸、持物手、道具颜色与动作顺序。整体氛围再好，核心动作没发生也不能完成这一镜的叙事作用。

商品镜头示例

不要把未经提供的保温时长、防漏测试或其他卖点写成实际证明。画面能展示动作，不等于证明产品性能。

商品镜头需要让观众看见结构与使用动作，因此写清哪只手进入、打开什么、何时离开，镜头不应遮住关键部位。真实产品参考比抽象的「高级商品」更容易明确目标。

杯盖开启或防漏画面不自动证明性能。只写已有事实，不凭生成结果新增产品承诺；播放后核对产品形状是否改变。

对白与配音怎样说明

声音应该单独交代：对白是谁说、准确文字是什么，旁白来自哪份录音，环境声与音乐要保留还是关闭。可使用的方式取决于当前模型支持，不能靠文字要求创造一个没有开放的功能。

独立录音后期合成与模型生成原声是不同路线。需要严格文稿与可反复替换的旁白时，先准备音频，再按成片时间放入。

  • 对白：写准确文字、说话人、语言和语气，判断所选时长是否足够说完。
  • 画面里的人说话：说明说话动作与台词的对应关系，完成后检查口型。
  • 独立旁白：先写旁白文稿，再准备或引用录音文件；后期合成时指定出现时间。
  • 音乐与音效：说清保留、关闭还是使用已有音频，避免默认添加。
  • 支持声音的模型可以尝试声音描述；纯文本声音要求不能替代一个并未提供的独立音频功能。

使用 Seedance 或 MiniMax 时

在 Agent 中可以选择当前提供的模型创作技能，或直接说明要用哪个模型，让助手按该模型的当前模式、时长和参考限制整理描述。先确认版本，不要把不同模型的全部参数混用。

模型创作方式可以帮助整理描述，但不能把别的版本的参数写进当前任务。让助手先核对参考、画幅、时长与费用，再决定描述里能安排多少事件。

模型建议也要能执行。对话里说支持某种参考，但当前页面没有对应入口时，先查清楚而不是直接添加不兼容素材。

从多镜头描述改成可制作的分镜

一镜只承担一个主要信息，有利于控制人物一致性和局部返工。动作正确但头尾冗长，可以剪掉空等；主体、道具或核心动作错误时，才考虑修改这一镜再生成。

前后镜头之间保留明确接点，例如前镜拿起信封，后镜从手持信封开始。之后合成只负责组合，不能自动改正两镜已经不同的道具。

  1. 一段里事件太多时，拆成几个镜头，各镜只承担一个明确作用。
  2. 前一镜结束与后一镜开始的姿势、道具、方向和光线要能衔接。
  3. 先生成最关键的一镜验证人物与动作，检查后再扩展。
  4. 动作已经正确但开头空等太长时，优先裁掉等待，不需要重新生成整段。

分镜提示词：把故事拆成可生成、可合成的镜头

分镜不只是剧情句子列表。每镜要交代可见动作、人物与场景参考、持续时间、声音，以及怎样接上前后镜头。可以先请 Agent 整理，再逐镜检查。

约 6 分钟阅读

先写故事目标，而不是先凑镜头数

说明观众在结尾要知道或感到什么，然后找出必须出现的动作和信息。例如「女孩发现有人提前写给自己的信」至少要看见进入书店、找到信、意识到异常。没有信息作用的镜头不必为了凑数量加入。

故事目标决定哪些镜头必要。先找观众必须看见的动作与信息，再决定镜头数和节奏；没有作用的镜头即使好看，也可能拖慢叙事并增加生成费用。

转折需要画面证据。例如主角发现异常，至少要有看到线索与反应，不能只在文字里写「她意识到不对」就期待视频表达清楚。

请 Agent 拆分时这样写

拆分时要求每镜具体到能制作，而不只是给「开端、发展、高潮」。明确人物和道具、起点动作、终点状态、镜头和声音，后面才能对应实际参考与生成参数。

如果原故事较长，先给可评审的方案；发现一个镜头承载太多事件时继续拆，不为了凑整齐的镜数而让动作无法在实际时长内完成。

每个镜头写清八件事

这些信息既是生成描述，也是之后检查结果的标准。每镜名字帮助你定位修改，用途解释为什么需要这段，起止状态帮助判断能否接上下一镜。

模型生成长度和最终保留区间应分开写。即使先生成较长片段，最终只用几秒，也仍需要核对原任务完整费用。

  • 镜头名称：例如「发现信封」，方便后面指定修改。
  • 观看目的：这镜让观众知道什么。
  • 主体和场景：用 @ 指定真实参考或明确列出待准备素材。
  • 起点：角色位置、姿势、所持道具。
  • 动作和终点：发生什么，结束时是什么状态。
  • 镜头：景别、方向、运动。
  • 时间：模型实际可生成的长度，以及最后要保留的区间。
  • 声音：对白逐字内容、环境声、配音、音乐和字幕需求。

一个完整分镜示例

示例说明一个镜头从什么姿势开始，关键事件是什么，以及结束时角色怎样持物。只把「发现信封」换成另一个事件还不够，也要改相应道具、动作和声音。

准确对白与画面文字应逐字写清。可选时长仍按当前模型确认，不能让示例中的动作复杂度超过你实际选择的镜头长度。

检查前后衔接

连续性通常出在细节：同一个人物换了外套、信封左右手互换、门的位置变了，都会影响前后镜头的可信度。先用统一参考与明确描述减少这些变化。

镜头已经生成后，把前镜末尾与后镜开头连着播放。发现冲突时优先改有问题的一镜或裁掉重复部分，保留其他成功内容。

  • 人物外貌、服装、持物手和道具颜色是否相同。
  • 视线、运动方向和场景布局是否一致。
  • 前一镜结束的动作，后一镜是否能自然继续。
  • 台词是否完整，是否需要在剪辑中保留反应停顿。
  • 不同镜头的画幅能否放进同一成片，声音是否重复或突然断开。

选择适合的制作方式

短剧工作台适合逐镜掌控内容和版本，Agent 适合先统筹已有素材与制作缺口，并继续安排后期。已有全部可用视频时，直接合成与编辑即可。

无论选择哪种路线，都要把方案、生成片段和最终成片分开验收。最后需要一份能播放、声音完整、文字准确的实际视频。

  1. 想逐个掌控镜头：在「短剧创作」创建项目，按分镜填内容、加素材、生成和选版本，再分镜合成。
  2. 想由助手统筹：把方案交给 Agent，说明先查已有素材，只补缺失镜头，所有新生成先确认。
  3. 已有全部视频：不需要再次生成，直接要求 Agent 指定每段保留区间、顺序、声音和字幕，合成实际成片。
  4. 有一镜失败：保留成功镜头，定位该镜的问题，只修改相应描述和参考。
小提示完成的分镜表是制作方案，完成的多个片段也还不是完整成片。要求交付视频时，需要再合成、播放和保存实际文件。

文字、参考素材与首尾帧：有什么区别，怎样选择

参考方式影响你能控制什么。文字主要表达想象；参考素材帮助说明外观、动作或风格；首尾帧表达开始和结束的状态。选错方式时，增加提示词长度通常解决不了问题。

约 4 分钟阅读

先判断需要控制的是什么

想控制人物长相或商品外观，需要清晰图片；想借鉴运镜或动作，需要当前模型支持的视频参考；想规定起点或终点，要使用相应帧的位置。图片只是加入素材列表，并不自动成为首帧。

参考也有不同职责：人物图负责外貌，场景图负责环境，风格图负责质感。用 @ 选出实际文件后，分别写清用途，不要让每份参考都同时负责所有内容。

几种方式的对比

参考方式控制的内容
方式适用情况如何说明需要注意
纯文字尚无素材，探索一个新画面写主体、环境、动作与镜头同名人物在不同任务中可能长得不同
参考图片商品、角色、场景或风格有明确样子指出必须保留的外观，允许变化的部分不保证逐像素复制；完成后核对细节

一个人物转身的选择过程

如果只想看看穿深蓝外套的女孩如何转身，可以先文字生成；如果已经确认角色脸型与服装，应使用人物参考。想从正面立姿转到一个确定的侧面姿势，就准备两张相近的图片，在支持首尾帧的模式中指定。

原视频已经拍到了正确动作，只是开头等待太长，最合适的是裁掉空等。把同一视频作为生成参考重新做一遍，会产生新的变化，通常也带来新的生成费用。

多份参考怎样避免冲突

风格、主体与动作的职责越明确，越容易判断结果哪里出了问题。参考图里的文字和其他人物也可能影响输出，必要时换成更干净的素材。

更换模型或方式后要重新核对

不同模型允许的文件类型、数量、画幅和时长不同；相同模型的文字方式与图片参考方式也可能有不同限制。切换后以当前页面显示的可选项为准，检查参考缩略图和首尾帧位置。

有些方式互相排斥。提示已有普通参考时，先移除对应素材和描述中的引用，再进入首尾帧。不要把额外图片、音频或视频放进首帧位置以绕过限制。

提示词优化与手动修改：什么时候用，怎样确认

优化的目的是把已有意图写得更清楚，而不是替你换掉故事、素材或台词。本篇说明自己改写、让 Agent 优化，以及短剧分镜里的「AI 优化」分别适合什么情况。

约 4 分钟阅读

三种方式怎样选择

已经知道要改哪一句时，直接在创作描述里修改，最容易控制内容。描述比较混乱、需要解释原因时，可以让 Agent 给出完整改写并说明改动。短剧分镜已有一版内容时，使用「AI 优化」可以在原稿与新稿间比较，再决定是否采用。

不要为了优化而反复更换故事目标。输入越清楚，优化越有针对性；如果原文同时要求固定镜头和绕主体一周，先决定真正需要哪个动作。

提示词调整方式的区别
方式适合情况使用重点
手动修改已明确要改变的主体、动作或词句一次改一个关键条件，保留满意部分
Agent 优化需要整理结构、检查冲突或比较方向要求先只写完整描述，不直接生成
分镜 AI 优化已填写一镜，需要更可执行的描述比较原稿与新稿、手动编辑后确认版本

短剧里的 AI 优化步骤

优化只处理当前分镜描述，确认版本不等于提交视频生成。关闭窗口未采用的优化稿与已经保存的分镜内容应分开理解，回到原分镜看本次实际使用的文字。

  1. 打开尚可编辑的分镜，先填写主体、场景、动作与镜头。
  2. 点击分镜内容旁的「AI 优化」，阅读原始内容、优化稿与改动说明。
  3. 检查人物、台词、道具和已有 @ 引用是否仍正确，必要时直接编辑优化稿。
  4. 想继续调整时点击「再次优化」，填写改进方向或使用当前内容继续优化。
  5. 选定完整可用的一版，点击「确认版本」，回到分镜核对。
  6. 要生成视频时，再核对本镜参数和费用，执行单独的生成操作。

优化方向怎样写才具体

“更高级”很难核对；“背景更简洁、主体完整、一次缓慢推进、台词不改”则可以逐项检查。优化后仍应根据当前视频时长控制事件数量，不能把更多描述当作更多可实现动作。

怎样判断新稿真的更好

先看核心意图是否保留，再看主体与参考职责是否明确，接着检查动作顺序、镜头变化和时长是否相容。对于准确台词、品牌文字或价格，逐字核对，不因为优化稿写得流畅就接受新增事实。

如果新稿出现未提供的人物或素材，先删掉或更正；若它把已有 @ 素材换成另一个版本，也要重新选择实际文件。优化不是补造缺少参考的替代方法。

优化与生成的费用分别看

Agent 的文字改写和短剧 AI 优化可按实际文字用量消耗积分；之后的图片或视频生成另计。没有采用优化稿，不表示已完成的文字处理一定免费。

连续点击再次优化会形成新的文字处理。先读完上一版并写清问题，再决定下一轮，通常比不停要求重新写更容易减少无效修改。

Agent 可以做什么：从创意、生成到字幕成片

Agent 是可以使用你的素材继续创作的助手。它既能写方案，也能处理实际图片、视频和音频。下面按任务列出能做什么、需要什么输入，以及可以直接尝试的说法。

约 8 分钟阅读

入口与最重要的使用方式

点击左侧「Agent」，写需求并添加素材。进入项目后，在对话中继续操作；需要指定文件时，在提示词中写好 @文件名，放入输入框后自动引用；也可手动选择。先告诉助手你要「只做方案」还是「制作实际作品」。

Agent 的优势是能把想法、素材理解、生成和后期连接起来。想讨论创意时说明只给方案；想处理文件时提供实际素材，并明确最终要图片、音频还是可播放视频。

项目越长，越应清楚命名采用版本。指向实际文件并说明用途，比只说「继续刚才那个」更容易保持任务一致。

写作与创意

创意阶段可以比较方向、改写文案和梳理故事，但应由你确认必要事实与品牌内容。要求助手说明为什么采用某个方向，有助于判断方案是否服务于实际用途。

文字写得流畅并不说明产品卖点、人物信息或价格准确。文档和素材里的事实需要核对，不能把创作自由当作虚构关键商业信息的理由。

  • 整理想法：给出不同创意方向、画面构图和内容结构。
  • 写提示词：把模糊需求改成具体的图片或视频描述，说明参考素材如何使用。
  • 剧本与分镜：写人物、场景、动作、对白和镜头安排，修改某一场或某一镜。
  • 角色与图像设计：设计外貌、服装、场景和产品画面，准备可复用的参考。
  • 阅读文档：根据上传的剧本、文案或说明总结、改写，并提取创作所需内容。

生成图片和视频

新生成需要具体描述、真实参考和可用参数。Agent 可以帮你查询和准备这些信息，你仍应核对当前数量、时长、画幅和总价，再确认采用。

已有结果优先复用。只缺一个镜头时明确不要重做成功片段，也不要把模型可用范围之外的时长或参考写成必然能实现。

  • 查询当前可用模型的参考方式、画幅、时长和输出档位，帮你选择适合这次任务的设置。
  • 根据文字或实际参考素材准备图片与视频，进入生成确认后由你核对费用与内容。
  • 复用已确认的人物、场景或物品素材，继续制作其他镜头。
  • 读取已有任务的结果和公开失败原因，提出局部修改建议。
  • 继续已做一部分的项目，先复用成功镜头，再补缺少的部分。
小提示模型支持情况与报价以当前页面和确认结果为准。写出一个效果或秒数，并不等于每个模型都能实现。

看懂已有视频与声音

素材分析适合在改编、续拍或剪辑前了解原片。可以查看特定画面、识别台词与检查声音，但不同问题需要不同观察，不能用「有音轨」证明口型正确。

重要位置自己回放核对。抽看画面与语音识别都可能漏掉细节；分析结果应帮助定位，而不是替代完整播放。

  • 查看视频真实时长、画幅，以及指定时间附近的画面。
  • 识别音频或视频里的台词，标记时间，帮助你整理字幕和改编内容。
  • 检查视频是否有声音、哪些区间静音，提取原有混合音轨。
  • 拆解参考视频的段落、镜头、动作与台词，说明哪些需要重新制作。
  • 评估已有素材能否覆盖目标，减少重复生成。
小提示抽看部分画面不能证明全片每一帧都正确；语音识别也可能写错专名和数字。你仍需播放成片并核对。

剪辑、声音与字幕

后期处理基于真实源文件：剪辑指定保留区间，声音指定独立音频与时间，字幕对应实际台词，图文指定内容与位置。它们可以组合，但最好先确定镜头再确定声音，最后做字幕。

要修改旧版本时说明原素材与保留效果。从底片继续比在已经烧录字幕和标题的视频上重复叠加更容易得到干净结果。

  • 按顺序拼接已有视频，指定每段保留起点和终点。
  • 逐段保留、调低或关闭原声。
  • 加入你提供的独立配音、音乐、环境声或音效，指定开始位置、音量和淡入淡出。
  • 根据最终成片实际台词制作普通字幕或逐词高亮字幕，并修正识别错误。
  • 按秒数或实际台词添加标题、色块、图片、画中画、分屏和简单移动、淡入淡出。
  • 在保留原片的基础上局部调整已有图文效果，输出新版本。

五种可以直接发的需求

这些需求用于展示任务粒度，不必一次把五件事全部交给助手。先选与你当前素材相符的一项，完成后检查实际结果，再追加下一步。

复制前将 @素材名称 改成自己的实际文件名，放入输入框后即可自动引用。引用名称不是通用指令，不能自动替你准备教程中的主角、视频或旁白。

准备素材时需要知道的边界

现有能力边界应该在制作前确认。独立配音或音乐需要你提供文件，混合原声也不能保证分离成人声和背景两份。模型原生声音则按当前支持另行判断。

复杂转场、变速、跟踪和声音克隆不应凭想象承诺。先询问可做方式，若需要替代方案，核对效果与新增费用后再决定。

  • 独立配音、音乐或音效：当前可以合成你提供的音频，还没有通用的文字转配音、音乐或音效生成功能。需要新音频时，先准备文件；模型自带声音能力另按该模型支持情况使用。
  • 混合原声：提取出来仍可能包含对白和音乐，不能保证把两者单独分开。关闭原声会一起关闭这些声音。
  • 复杂后期：不要默认支持任意视频转场、视频变速或声音克隆。先让助手确认当前可做的方式。
  • 字幕成片与图文编辑目前以最长 300 秒的视频为范围；较长内容请先分段。

怎样判断已经做完

要实际作品时，检查是否出现可播放的视频、可预览图片或音频，而不是只有一份分镜表。完成后查看画面、声音、字幕、时长和文件。问题集中在一小段时，说清时间位置，只调整该部分。

实际交付要能被检验：视频完整播放，图片能放大查看，音频能试听，文件能找到。文字说已完成、给出计划或列出分镜，都不能替代这些结果。

发现局部问题时指出版本与时间，要求只处理相关内容。保存源文件与满意结果，后续才能继续修改而不反复从零制作。

用创作助手整理想法

创作助手在客户端左侧标为「Agent」。你可以直接描述任务、补充图片或文档，边聊边完善结果；发送第一条需求后，会进入相应的对话与项目页面。

约 6 分钟阅读

进入助手并开始

开始一段对话时，先写当前阶段的目标，再添加与它相关的素材。要写方案就说只写方案，要交付视频就说明要实际成片；这两个目标决定后续工作的范围。

首次需求不必非常专业，但应有用途与限制。例如面向附近上班族的咖啡店短片，比没有受众的「做一个很棒的广告」更容易判断内容是否合适。

  1. 点击左侧「Agent」，在首页的输入框中写下创作目标。也可以先选一个现成的创作示例，再把其中的主题改成自己的内容。
  2. 明确要得到什么：一段文案、三种构图方案、剧本、分镜，或者一张图片。不要只说「帮我做一下」。
  3. 如果有图片、视频、音频或剧本文件，先点输入框旁的添加文件按钮，选择「从文件库选择」或「从本地上传」。
  4. 检查附件已准备好、需求已写完整，再点击「发送消息」。发送后进入该项目，查看 GuGu 的回复和画布上的相关内容。

给助手四类信息

四类信息是帮助助手减少猜测的最小准备。用途决定内容结构，主体决定画面，限制决定可选方式，交付决定本阶段做完的标志；缺一项都可能让助手多问一轮。

没有偏好也可以明确允许建议，但把固定要求留下。例如风格可建议，真实产品颜色不变，准确台词不改，媒体生成先确认。

  • 用途：例如店铺宣传、商品主图、竖屏短片，说明给谁看。
  • 内容：主角、产品、故事事件，或需要处理的原始文案。
  • 限制：画幅、目标时长、风格、必须保留的特点、不要出现的内容。
  • 这一步的交付：只写方案、只优化描述，还是准备图片或视频。只想讨论时，请直接说明「先给方案，暂不生成」。

收到回复后怎样继续

回复后先评审方向，不要只因为描述丰富就直接开工。看它有没有使用正确素材、有没有补出未提供的人物或事实，以及镜头是否能在当前时长内完成。

继续修改时指出哪一镜或哪一段，并写清保留内容。清楚的局部反馈能减少整份方案反复重写，也更容易控制后续生成数量。

  1. 先检查助手是否理解了用途、风格和要保留的内容。偏离时指出具体问题，例如「我要竖屏，而且镜头里不要出现其他品牌」。
  2. 要求修改时，说明要改哪一部分、保留哪一部分。例如「保留第一组镜头，把第二组改成咖啡拉花特写」。
  3. 需要生成时，再补齐素材与参数。出现生成确认窗口后，先核对数量、积分、画面描述和参考素材，再决定是否点击「生成」。
  4. 看到图片或视频结果后，点击预览检查，继续提出局部修改意见。已有结果不需要全部重做时，明确指定要修改的作品。

暂停、继续与历史对话

暂停适合你需要补充条件或发现当前方向错误时使用，但已提交的媒体任务和正在回复的对话应分别看。打断文字不等于取消所有图片视频任务，也不自动退回已发生的费用。

继续旧项目前先看已完成内容，确认当前任务与采用版本。换成完全不同的主题时新建项目，避免两套角色、素材和创作目标混在一起。

  • 需要暂时打断回复时，使用对话区域提供的「暂停」按钮；暂停后先看已完成的内容，再提出新的要求。
  • 页面提供「继续」时，可让当前任务接着进行。继续之前，先确认当前任务和素材仍然正确。
  • 使用对话区域的「历史」或左侧「对话与项目」找到之前的项目，打开后继续原来的需求。
  • 「新建对话」适合开始新的讨论；换成完全不同的项目时，回到项目列表或助手首页创建新的项目更容易区分。

如果助手一直追问

通常是缺少一个会影响结果的重要条件。先回答用途、尺寸、时长或参考素材问题；如果确实没有偏好，可以明确说「使用你建议的默认方案，但先展示方案让我确认」。

追问通常是在补足会影响结果的条件。可以一次回答用途、画幅、参考与交付，不必每项开一轮；没偏好时说明可用建议，并要求先展示。

如果助手反复询问已经给过的信息，重新用一段短需求总结固定条件。随后核对输出是否真的采用这些条件，而不只看它口头表示理解。

小提示助手给出的品牌、人物或事实信息需要你核实。对话里的「已完成」文字也不能替代作品预览；以实际出现的可查看结果为准。

选择与使用创作技能

技能适合目标明确的任务，例如优化画面描述、写剧本、设计角色或制作视频。查看技能详情后再使用，能更容易得到符合预期的结果。

约 5 分钟阅读

从哪里选择技能

创作技能是帮助组织任务的预设方法，选中后仍要提供自己的主题与素材。查看适用场景和所需输入，比只凭名称判断更可靠；不选技能也可以直接对话。

示例只用于开始，发送前替换占位内容。技能不是一种预付套餐，也不代表选中它就已经生成图片或视频。

  1. 在创作助手首页找到「创作技能」区域，点击感兴趣的技能查看详情。
  2. 阅读它适用的场景、需要提供的内容和可以得到的结果。确认与自己的任务相符。
  3. 点击「使用此技能」，回到输入区，检查已选技能的名称。输入框旁的「选择创作方式」也可用于选择当前可用的技能。
  4. 把示例里的占位内容换成自己的主题，补充素材、时长或画幅，再发送需求。
  5. 如果选错了技能，使用已选创作方式旁的移除按钮，再重新选择；不选技能也可以直接对话。

不同任务怎样选

不同任务的工作重点不同：剧本关注场景与对白，角色设计关注可复用外观，视频创作关注动作和时间，作品优化关注已有内容的问题。先按当前阶段选，再在需求里交代最终输出。

模型相关技能适合已经明确要使用某个当前可用模型的任务。它能辅助写法与规划，但不替代该版本的实际素材限制和参数检查。

  • 描述优化：已有一段文字，但含糊、重复或互相冲突，想整理成清晰的画面描述。
  • 剧本创作：要写完整场景、行动和对白，或修改某一场戏。
  • 角色设计：要确定人物性格、外貌、服装，或者制作不同视角的角色参考。
  • 图像创作：要设计产品图、海报、插画，或根据参考图调整背景和构图。
  • 短剧创作：要把故事写成大纲、分集或镜头计划。
  • 视频创作：要安排动作、镜头、节奏和声音，或制作视频片段。模型相关技能适合说明了具体模型的需求。
  • 作品优化：已有剧本、图片或成片，希望找出问题并得到具体修改建议。
小提示技能名称和可用内容以你当前看到的列表为准。这些说明用于帮你判断用途，不代表每项任务都会自动生成图片或视频。

收到结果后检查主体、光线和构图是否都已写清楚。然后把完整描述复制到「图像生成」，再选择模型、比例和清晰度。

描述优化的结果应是一段完整、可继续使用的描述，同时说明保留了什么、改清了什么。比较原稿与新稿，看核心事实和必要外观是否还在，不能只按文字长度判断。

准备直接生成时，把描述带入对应页面并检查参考与参数。提示词写好 @文件名 后，放入输入框会自动引用匹配的已有素材；没有提及的文件不会全部带入，模型与参数仍需另行核对。

继续修改与生成

同一任务可以沿用已经确认的方式继续修改，但每次明确只改哪一部分。已有角色和镜头能用就保留，避免技能重新发挥时又造出另一套风格。

要求实际生成前核对费用，文字修改和媒体生成可能分别产生消耗。对于重要台词、品牌和道具，优化后仍逐项核对。

  1. 如果结果只给了方向而没有完整文本，可以要求「把第二个方案写成一段完整的画面描述」。
  2. 如果要改写现有内容，先贴出原文，注明必须保留的台词、人物或产品特征。
  3. 需要从方案进入图片或视频生成时，明确告诉助手要采用哪个方案，并核对生成确认窗口。
  4. 如果技能未加载或列表暂时为空，可以先直接在输入框说明需求；若仍需要指定技能，再按页面提示重试。

添加图片、视频、音频与文档

附件让助手看到你已经有的素材。正确的做法是「添加素材 + 说明用途」：告诉助手哪些特征需要保留、哪些内容可以调整。

约 5 分钟阅读

添加电脑上的文件

添加文件是让助手处理具体内容，而不只是讨论你的文字描述。上传前打开一次文件，检查版本、画面和声音；尤其是多个相似片段，先命名再添加。

添加后等素材可用，再发需要读取或处理它的要求。电脑上能播放但项目里没有选中，不代表助手已经知道你指的是哪份文件。

  1. 在创作助手输入框旁点击添加文件按钮，选择「从本地上传」。
  2. 在电脑的文件选择窗口中选中需要的文件。首页允许添加支持的图片、视频、音频和文档；可选类型以窗口提示为准。
  3. 回到输入区检查附件名称和预览，等待文件准备完成。若某个文件显示失败，先移除它，再选择一份有效文件。
  4. 在文字里说明每个附件的用途。例如「第一张是产品外观参考，第二张只参考光线，不要照搬背景」。
  5. 点击「发送消息」，查看助手是否正确理解附件。若附件内容识别不完整，补充关键文字或更清晰的文件。

从文件库使用已有素材

已有素材优先从文件库选择，可以减少再次上传与找错版本。选择之后核对文件名和预览内容，保证是本次采用版；不能只靠名字里的「最终」就跳过检查。

同一账户不同项目或不同设备的文件可见情况需要按当前入口确认。文件库有一条记录，不一定说明当前电脑能立即打开原文件。

  1. 点击添加文件按钮，选择「从文件库选择」。
  2. 在素材选择窗口中找到已有图片、视频或音频，按需要选中。
  3. 点击窗口里的确认按钮，把所选素材加入本次输入。只在窗口中选中还不等于完成添加。
  4. 回到输入区核对素材，再写清要分析、修改还是用于生成。
小提示更换登录账户后，请重新检查附件。当前账户看不到或找不到的文件，需要重新选择。

图片、视频和音频分别怎么说明

图片主要说明外观与风格，视频还能提供动作与节奏，音频用于旁白、音乐或声音分析。分别描述职责，避免把配音录音误当作背景音，或把动作参考误当作要直接拼接的镜头。

@ 选中实际素材后，再写「保留外观」「采用某段」或「从成片几秒开始」。同一份文件可能参与不同任务，操作方式必须明确。

  • 图片：说明参考角色外观、产品形状、构图、配色还是材质。需要保留的特征写具体。
  • 视频：说明参考动作、镜头运动、节奏还是人物形象。需要关注某一段时，写清大致时间位置。
  • 音频：说明参考对白内容、语气、音乐节奏还是音效。要求无配乐或无对白时也要写清楚。
  • 多个素材：给每份素材一个容易识别的称呼，并说明组合关系。素材多不一定更好，先保留真正需要的内容。

上传剧本或其他文档

首页的本地文件选择支持页面列出的文档格式，包括常见的 PDF、Word、纯文本和 Markdown 等。文档内容与普通图片参考不同：请说明要总结、改写还是拆成分镜。

文档用于提供剧本、文案或说明事实。可以先要求提取人物、场景、关键转折和准确文案，再决定镜头；不要把整篇文档默认当作全部要照搬的视频描述。

内容较长时说明关注章节或目标问题，并核对助手引用的内容。文档中的事实不能由创作自由改写成未经确认的商品承诺。

小提示扫描文档、过于复杂的版式或不完整的文件可能影响理解。遇到识别不全时，可复制关键段落到输入框，不要只重复发送同一个附件。

移除与替换附件

替换附件只改变当前任务的输入，不应顺手删除原文件。新旧版本都可能在后续返工时使用，先区分名称，再重新说明采用哪个版本。

如果上次结果用了错误素材，替换后还应检查下一次生成确认或编辑安排。仅在聊天里说换了文件，不能替代实际引用与参考的核对。

  1. 发送前，使用附件卡片上的移除按钮去掉选错的文件。
  2. 换一份素材时重新添加，并检查文字里是否还引用了旧素材的名称。
  3. 已经发送的素材需要换掉时，在下一条消息中明确说明「以这次添加的图片为准，之前那张不再使用」。
小提示附件数量和单个文件大小受到当前入口限制。超过上限时，优先减少重复素材或把任务拆成几次；不要假定对话附件上限等于视频模型的参考上限。

让助手准备一次明确的生成

明确采用哪个方案、生成图片还是视频、生成数量、画幅以及使用的参考素材。若只是想讨论，写「先给方案，暂不生成」，避免目标含糊。

准备生成前先把任务范围说到可核对：是什么媒体、用哪个角色或产品、生成多少、每段多长、画幅怎样。描述与参考应该已经满意，再进入确认阶段。

如果还在比较方向，要求先给方案。不要一边讨论是否采用，一边让助手把所有候选都生成；这会增加费用并让版本难以整理。

阅读生成确认窗口

确认窗口是检查本次真实制作内容的位置。看数量、时长和总费用，再看画面描述与参考是否对应；其中任何一项不对，先取消或调整，再重新确认。

总价不是某个模型的泛泛单价。生成多个结果或使用不同档位会改变总费用，也不要把对话里之前说的预算直接当作这次准确报价。

  1. 查看窗口标题，确认这次要生成的内容类型。
  2. 检查显示的数量和积分费用，确认符合你的预期。
  3. 阅读「画面描述」全文，核对主体、风格、动作和不能出现的内容。
  4. 查看列出的参考素材，确认没有选错或遗漏。
  5. 内容正确时点击「生成」；需要修改时点击「取消」，回到对话说明修改意见，重新准备。
小提示「取消」用于拒绝这一次尚未开始的生成。点击「生成」并提交成功后，不要把关闭窗口当作撤回已提交任务。

确认后怎样看结果

完成后看实际结果，而不是只看助手报告。图片检查外观与细节，视频完整播放画面与声音；原片满意后才继续合成、字幕或其他后期。

多个候选版本应标明采用哪一份。后续修改时重新指向本次作品，避免助手拿旧版继续或重新生成已满意镜头。

  1. 提交后先观察对话和对应任务的提示，不要再发送一次相同的生成请求。
  2. 生成完成后，在当前项目的画布或作品预览中检查图片或播放视频。
  3. 有多个版本时，说明你要保留哪一个，例如「保留第一版构图，只把背景改浅」。
  4. 通过作品提供的文件操作找到电脑文件，保存需要交付的版本。

预算内自动生成怎么用

对话区域的「生成设置」中提供「预算内自动生成」和「本次对话生成预算（积分）」。这是在当前对话中允许助手在预算范围内继续生成的设置。

自动生成适合你已明确任务范围，并愿意在本次对话的预算内让助手提交媒体任务。初次探索可以先用逐次确认，等路线稳定再设置预算。

预算是授权范围，账户余额是实际额度，两者分别看。文字创作可能另有消耗；任务超出当前范围或价格改变时，重新核对，不把一次开关当作对所有后续任务的长期授权。

  1. 第一次使用时先保留逐次确认，走通一次生成与结果检查。
  2. 确实希望助手连续制作时，打开「生成设置」，仔细查看当前开关与预算。
  3. 填写你能接受的本次对话生成预算，并点击「保存设置」。确认额度后再提出连续制作需求。
  4. 如需重新逐次确认，关闭「预算内自动生成」并保存。若页面仍提示需要确认，按当前提示处理。
小提示对话预算不是充值金额，也不等于账户余额。它不能保证一次连续创作就达到满意效果；仍需查看每个结果和账户积分明细。

费用或内容不符合预期时

报价超出预期时先查原因：数量增加、时长变化、档位提高，或参考方式改变。可以减少不必要的结果、选择适用短时长，或只补真正缺少的镜头。

内容不对则先改描述与参考，不要只把预算调大。生成完成后的主观不满意不等于任务失败，新版本仍应按实际费用确认。

  • 数量过多：取消这次确认，明确要求只生成 1 个结果。
  • 费用高于预期：先调整模型、时长、清晰度或数量，再重新确认。
  • 素材不对：说明应该使用哪份附件，并在下一次确认窗口中检查。
  • 自动生成不适合当前任务：关闭相关设置，后续改为逐次检查。
  • 已经提交：查看现有任务和积分明细，先确认状态，再决定后续操作。

在项目画布上查看和继续创作

助手项目把对话和相关作品放在同一个空间。你可以边看画布里的内容，边要求助手修改，也可以使用画布中的图像和视频生成入口。

约 5 分钟阅读

认识项目页面

项目把同一目标的对话、素材和作品放在一起，便于从已完成内容继续。进入后先分清哪些是原始参考、哪些是生成结果，哪些只是描述或方案。

画布看起来有很多卡片，并不代表都已成为实际视频。正式处理时选择能预览的文件或明确的文本内容，并说明它在任务里的用途。

  • 对话区域：描述想法、查看回复、添加素材和继续修改。
  • 画布区域：查看项目相关的文本、参考图片和生成内容。点击具体内容查看可用操作。
  • 项目名称：用于区分不同创作。完成第一次需求后，请检查名称是否容易识别。
  • 「历史」和「新建对话」：查看或开始项目中的讨论。它们与删除项目、删除作品是不同操作。

找到与查看作品

打开作品查看真实内容与版本，不只看缩略图。视频缩略图通常只代表一瞬间，不能证明动作、声音或字幕全片正确；播放才是判断依据。

找不到结果时回到该项目与任务记录检查。不要为了刷新画布就再次提交相同生成，先确认原任务是否仍在处理。

  1. 在左侧「对话与项目」中打开对应项目。
  2. 找到画布上的图片或视频，点击查看；视频需要实际播放，不能只根据封面判断结果。
  3. 如果当前页面以对话为主，可以使用页面提供的「显示画布」切换回画布。
  4. 内容太多时，先确认你要修改的作品名称或所在位置，再在对话里指明对象。

继续修改某一份内容

如果内容打开后提供「编辑内容」或「让 GuGu 修改」，可按按钮提示进行操作。直接编辑文字后记得保存；通过助手生成的新图通常是新的版本，请逐个检查。

继续创作应指向具体作品，并说明修改范围。改颜色、换背景、裁视频和重做动作是不同操作，可能有不同输入要求与费用。

能用的部分先保留。只需要标题或配音时，优先后期；主体或核心动作错误才考虑新生成，避免把一切修改都变成整片重做。

在画布上直接生成

画布上的生成入口便于从已有内容开始，但仍要核对真正使用的描述、参考、模型和参数。出现确认步骤时完整读完，不把点击一个卡片当作所有内容都已正确带入。

先生成一个能验证方向的结果，再扩展数量。复杂任务可以回到对话说明局部目标，而不在多个未完成结果上同时继续。

  1. 使用画布提供的「图像生成」或「视频生成」入口，打开对应的创作输入区。
  2. 填写画面描述，按需要添加参考素材，选择当前可用的模型和参数。
  3. 生成视频时，确认使用文本、参考素材还是首尾帧方式；素材要求以该输入区的提示为准。
  4. 检查生成费用并提交。完成后查看画布中的实际结果，再决定是否继续使用。
小提示不同入口可能提供不同的参数布局。以当前输入区显示的选项为准，不要直接照搬其他模型的素材数量或时长设置。

保持项目清楚易找

文件、项目和版本名应能表示用途与采用情况，例如「产品参考」「开场采用版」「无字幕成片」。名称只是帮助整理，最终仍要检查实际内容。

删除前确认是否还要用它继续编辑。保留源镜头与录音，比仅留一个所有效果已合并的成片更容易以后返工。

  • 一个独立作品主题使用一个项目，更容易对应素材和修改记录。
  • 为阶段性版本设置容易识别的描述或名称，避免只说「最后那个」。
  • 在换项目之前记录下一步要改什么，下次打开后先核对参考素材。
  • 重要结果用「在文件夹中显示」找到文件，并保留到自己的项目目录。

从文字或参考图生成图片

图像生成可以从文字开始，也可以结合参考图调整主体、构图和风格。本篇使用「咖啡杯产品图」说明完整操作：填写描述、添加素材、确认设置、查看作品，再继续修改。

约 7 分钟阅读

进入模块与准备素材

点击左侧「图像生成」。左侧填写描述和设置参数，右侧查看「我的作品」与「历史记录」。纯文字创作不需要添加图片；要保留商品或角色外观时，先准备主体清晰的参考图。

一张图片是否成功，取决于它能否服务于用途。先确定做封面、产品图还是角色参考，选相应画幅与构图；真实外观要求越强，越应该先准备清楚的参考图。

模型列表与参数可能随当前可用情况改变。本次选择之前先检查，而不是按旧教程把某个名字当作永远适用的默认选项。

  • 商品图：尽量使用主体完整、没有严重遮挡的图片。
  • 角色图：选择能看清面部、发型和服装的参考。
  • 风格图：明确只参考配色、光线或画面质感，避免把不需要的人物也带入描述。

只用文字生成

文字生成适合没有现成素材，或想探索一个构图与风格时使用。主体、环境、景别和光线写清，再补少量必要限制；不用把全部可想象的风格都写进一段。

第一次只验证核心画面。满意后再提高尺寸或增加结果数，避免内容方向不对时批量消耗积分。

  1. 在「创作描述」中写清要出现的主体、所处环境、构图和风格。
  2. 选择当前可用的模型，查看它提供的画面比例和质量选项。
  3. 先设为 1 张，确认费用后点击「生成图像」。
  4. 结果完成后打开预览，检查描述中的关键要求是否实现。

添加参考图片并生成

参考图用于说明外观、场景或风格。商品图强调真实结构与颜色，人物图强调脸型与服装，风格图只负责需要借鉴的表现方式；素材职责混乱时更容易融合错误内容。

添加后检查缩略图与数量，选择当前模型支持的图片。要保留外观就明确哪些不变，不要只写「参考这张」而不说希望怎样用。

  1. 在「参考图片」区域点击「添加」，打开「选择参考素材」。
  2. 从已有素材中选中图片；电脑上有新图片时，点击窗口内的「上传素材」并选择文件。
  3. 查看已选择数量和缩略图，选完后点击「使用所选素材」。回到创作页确认参考图已经出现。
  4. 在描述中说明参考图片的用途，例如「保留参考图中杯子的形状、颜色和图案，只更换桌面和背景」。
  5. 检查比例、清晰度、数量及费用，点击「生成图像」。
小提示选错图片时，在参考图缩略图上使用移除按钮，再重新添加。素材窗口里仅勾选图片、随后直接关闭窗口，可能不会把选择应用到本次创作。

怎样在描述里引用图片

输入框支持用 @ 引用参考图片。出现可选素材时，选择对应图片，再把它的作用写清楚。没有需要分别指明的多张图片时，直接写「参考图中的产品」也可以表达基本意图。

@ 是选择实际素材的方式，文字说明是安排素材用途的方式，两者相配合。将教程中的 @名称 换成自己的实际文件名，整段放入输入框后会自动引用，不需要逐个手动选择；随后核对参考区域。

多图任务应逐一分工，例如第一张的人物、第二张的环境。参考中若有其他角色或文字，明确不采用或先换更干净的图片。

小提示示例中的 @产品参考 和 @光线参考 是素材称呼。使用时将名称替换为已有素材的实际文件名，放入输入框即可自动引用；不存在或无法匹配的名称需要先检查。

预览、修改与再次使用

预览先看整体，放大再看商品边缘、标志、手部或需要准确的文字。详情里的继续创作入口能帮助复用，但下一步仍要重新确认描述与素材是否合适。

输出更高尺寸或再做一个版本属于新的制作，不是将旧图免费下载为另一个画面。保存满意版本，并保留它所用的描述，便于后续控制变化。

  1. 任务完成后，在「我的作品」点击图片，打开「文件详情」。
  2. 核对商品边缘、颜色、文字和细节。重要产品信息以真实商品为准，不要只检查整体氛围。
  3. 想沿用描述和参考继续调整时，使用详情中可用的「生成同款」入口，再检查带入的内容并修改。
  4. 想把图片做成动态镜头时，使用「生成视频」入口，进入视频页后补充动作和时长，并确认参考已带入。
  5. 满意后点击「在文件夹中显示」，保存自己需要使用的版本。

常见问题先这样检查

按钮不可用通常是输入、参数、素材准备或模型可用状态需要检查；任务明确失败则看错误与积分记录。结果能完成但画面偏离时，应定位描述或参考问题。

不要用重复提交替代排查。先完成一次检查并记录具体提示，再决定是否改变设置或联系支持。

  • 无法添加参考图：确认素材类型是图片，并查看当前模型的数量限制。
  • 生成按钮不可用：检查创作描述是否为空、素材是否准备完成、模型是否可用。
  • 产品形状改变：使用更清晰的参考图，在描述中强调关键形状与颜色，减少不相关参考。
  • 画面被裁切：调整比例，补充「主体完整出现，四周留白」，重新检查构图。
  • 结果已生成但文件暂不可看：按提示等待文件准备，或查看保存文件的故障处理指南。

画面比例、清晰度、质量与数量怎么选

不同图像模型提供的参数并不完全相同。这篇指南解释每项设置影响什么，以及第一次使用时怎样选择，避免把不必要的参数全部调高。

约 6 分钟阅读

先根据用途选择画面比例

比例决定画面的宽高关系，不等于图片的清晰度。准备把图做成视频时，尽量让图片比例与最终视频画幅接近，减少后续裁切。

比例先由发布位置决定。手机竖屏、横版视频与方形商品展示需要不同构图；主体完整出现、文字留白与动作空间，都应在选择比例时考虑。

后续打算做视频的静帧最好接近目标画幅。把横图强行做竖屏，可能裁掉人物或商品，即使原图清晰也不能避免这个问题。

  • 1:1：正方形，适合产品展示、头像或方形封面。
  • 9:16：竖屏，适合手机短视频的画面与竖版封面。
  • 16:9：横屏，适合横版视频画面、场景和展示页。
  • 3:4、4:3 等：适合其他版面需求。页面有「更多」时，可打开查看当前模型支持的其他比例。

清晰度与质量有什么区别

清晰度关注输出尺寸，质量关注当前模型的处理档位。两者名称可能相似，作用并不完全相同；不能简单把所有选项调到最高来解决内容错误。

先让主体、构图与文字正确，再按展示尺寸提高档位。需要印刷或大屏时更应检查实际文件尺寸与细节，而不只看参数名称。

  • 「清晰度」通常显示为 1K、2K、4K 等，主要帮助你选择输出图片的尺寸档位。
  • 「质量」是模型提供的处理档位，可能显示低、中、高或其他数值。不同模型的档位不能简单一一对应。
  • 先用基础或默认档位验证构图，再在需要更大尺寸时选择更高的清晰度。
  • 清晰度提高不代表主体一定正确，也不能自动修复错误的文字、手部或商品形状。
小提示模型改变后，参数名称、可选值和费用可能同时变化。不要以为一个模型的「高」等于另一个模型的 4K。

生成数量怎样选择

数量适合比较候选，并不保证结果只是同一画面的轻微差别。探索阶段先做少量，更容易知道描述是否有效；方向稳定后增加数量，才有明确的选择标准。

部分模型按一组返回多张，应采用它提供的有效数量与总价。不要把普通单张模型的数量规则套到 Midjourney 四张一组的结果上。

  1. 第一次探索新描述时，把「生成数量」设为 1，先确认模型能理解核心画面。
  2. 描述方向稳定、希望比较不同构图时，再增加数量。
  3. 用数量旁的加减按钮或输入框选择当前允许的数值。
  4. 每次调整数量后，重新查看生成按钮附近的积分费用，再决定是否提交。
小提示增加数量意味着更多结果，也可能增加总费用。数量不是「把一张图重复下载几次」。

模型提供更多参数时

部分模型会提供种子、参考图权重、排除内容、风格化或其他高级选项。第一次不需要全都填写；先确认基本描述、比例和质量，再每次只改一个设置。

高级选项适合已经了解基本效果，想单独控制某项变化时使用。种子、参考影响和风格设置可以辅助探索，但不能保证跨模型的角色完全一致。

每次只改一个设置并记录本次值，结果变化才容易解释。参数不熟悉就先使用页面建议，不要复制另一个模型的一整套数值。

  • 种子：适合在支持该功能的模型里探索可重复的变化；它不能保证不同模型生成完全一致。
  • 参考图权重：用于调整参考影响程度，先按页面默认值尝试。
  • 排除内容：写不希望出现的内容，例如文字、水印或额外物体；它仍不能替代结果检查。
  • 风格相关选项：适合明确追求特定视觉效果时逐项尝试，不要和相互冲突的描述一起使用。

一个适合新手的选择过程

练习分为内容验证和输出规格两阶段：先看咖啡店场景是否符合用途，再决定是否需要更大尺寸。方向不对时先改构图、参考或光线，而不是反复加清晰度。

每个新版本都要再次检查细节与费用。高档位结果也可能产生新的内容变化，不能跳过验收。

切换模型后的检查清单

更换模型会重新影响可选档位、比例、参考限制与数量，旧设置不能直接视为仍有效。切换之后按本次任务检查一遍，再生成。

价格也会变化。比较模型时同时记录总价和实际可用结果，不仅比较页面上哪个名字熟悉或分辨率更高。

  • 参考图片是否仍在允许范围内。
  • 画面比例是否仍然符合用途。
  • 质量或清晰度是否被切换成新的默认选项。
  • 生成数量和显示费用是否符合预期。

实战：商品主图、场景图与产品展示视频

这篇教程以一只保温杯为例，把真实商品参考、主图、场景图和短展示视频连起来。重点是先保留可信外观，再增加环境与动作，而不是用一次复杂生成同时完成所有内容。

约 4 分钟阅读

先准备商品事实与参考

准备一张清楚显示杯身、杯盖和颜色的真实商品图，必要时再补一个结构角度。写出确定可以使用的卖点，不把模型生成的画面当成性能证明；品牌与准确文字应逐项核对。

确定发布用途：方形商品展示可选 1:1，手机竖屏内容可选 9:16，横版展示可选 16:9。先选用途，避免后续改变画幅造成主体被裁掉。

先生成一张干净主图

在图像生成中添加真实参考，选择可用模型与基础档位先做一个小样。放大看边缘、杯盖结构和颜色，满意后再考虑正式尺寸；结构错误时先修改参考与描述，不立刻大量生成。

再做场景版本，区分固定与可变部分

这一步允许变化的是背景与光线，需要保持的是商品。比较结果时，把主图放在一旁核对，而不只看新环境是否好看。如果场景里商品太小，先调整构图。

把可用图片做成动态镜头

视频页先选择支持图片参考的模型，再核对画幅、时长与费用。只安排一个主要动作，播放时检查手部、盖子运动、商品比例和实际声音。需要指定第一帧时使用支持的首帧入口，不把普通参考当成首帧。

需要营销文字时优先后期处理

镜头已经可用，标题或价格需要准确展示时，可以将成片交给 Agent 添加明确文字。提供实际文案、时间与位置，避免遮挡产品；旁白需要真实音频或当前模型已确认的声音能力。

最终完整播放，检查卖点是否与真实商品一致、品牌是否正确、字幕是否同步。只改文字或音乐时保留已确认的画面，不重做商品镜头。

这条路线与短剧路线的区别

商品展示通常先围绕外观与使用动作制作少量镜头，不一定需要剧情和人物弧线。只有要讲清一个故事、比较多个镜头版本或逐镜控制时，再采用短剧分镜工作台。

图片与视频的模型选择也可以不同。先做好参考静帧，再选适合动作与时长的视频模型，比要求一个模型同时满足所有任务更容易检查。

生成你的第一个动态镜头

这篇教程先做一个简单的短镜头：让窗边的橘猫抬头看向镜头。你可以纯文字生成，也可以先准备一张橘猫图片作为参考。

约 7 分钟阅读

入口与准备

点击左侧「视频生成」。视频页的主要设置包括「创作描述」「参考素材」「模型」「画幅」「时长」与模型提供的分辨率。右侧仍通过「我的作品」和「历史记录」查看结果。

先判断要创作新镜头，还是处理已有视频。新动作和新场景适合生成；原片能用只需要剪掉停顿、配音或字幕时，直接使用 Agent 后期通常更容易保留内容。

本次生成最好只安排一个主要动作。确定真实主体参考与画幅后，再决定运镜，避免开始就把完整故事压进一个短片段。

  • 纯文字尝试：准备一段描述，不需要先上传文件。
  • 已有图片：准备清晰的主体图片，选择支持相应图片参考方式的模型。
  • 第一段镜头：安排一个主体和一个简单动作，先不做复杂切镜。

第 1 步：选择模型与参考方式

参考方式决定你能控制什么。普通图片表达外观，首帧规定起点，首尾帧规定起止状态；动作视频与音频只在模型支持时加入，不能当作所有模型通用附件。

先选模型再检查该方式的素材限制。切换时核对参考缩略图与位置，不把旧选择默认当作已经兼容。

  1. 先选择一个当前可用的视频模型，查看参考区域的文字和数量提示。
  2. 只用文字时，不添加不必要的参考素材，按页面允许的方式填写描述。
  3. 已有橘猫图片时，按模型支持的「参考素材」或「首尾帧」方式添加。通用参考方式点击「添加」，选完后点击「使用所选素材」。
  4. 回到视频页面检查缩略图。如果参考区域出现「首帧」「尾帧」两个位置，请把图片放进它应当控制的位置。
小提示不是每个模型都同时支持图片、视频、音频或首尾帧。先读当前页面的支持提示，再准备素材。

第 2 步：写清动作与镜头

纯文字生成时补充橘猫、窗台和背景的外观。使用参考图片时，重点写在参考基础上要发生的动作，不需要把一段短镜头塞入多个不相关事件。

视频描述是一个变化过程：主体从什么姿态开始，做什么，停在哪里，以及镜头如何观看。固定镜头、缓慢推进与跟拍应该根据动作选择，而不是同时要求全部出现。

声音要求也单独交代。有对白时写准确台词并检查是否能说完；不需要音乐或字幕时明确提出，生成后仍需试听确认。

第 3 步：设定画幅、时长和费用

画幅、时长、档位和数量共同影响本次任务。选择当前模型的实际选项，核对总价；在描述中写长时长，不能让不支持的模型自动延长。

第一次先试合适的短镜头，检查动作与外观，再安排更长内容。视频费用按生成长度计算，之后裁短不会将原费用改成只保留几秒的价格。

  1. 选择最终用途对应的「画幅」。竖屏使用 9:16，横屏使用 16:9；以当前模型的实际选项为准。
  2. 在「时长」中选一个当前支持的短时长进行测试。目标时长超过该模型选项时，应拆成多个片段，而不是只在描述里写更长时间。
  3. 选择模型提供的「分辨率」或相应输出档位。先验证动作和构图，再考虑更高档位。
  4. 查看「生成视频」按钮附近的费用，核对余额。确认无误后点击一次「生成视频」。

第 4 步：等完成、播放并检查

播放时从头到尾检查，不只看首帧与封面。关注动作是否完整、人物是否变形、道具是否改变、对白有没有截断，以及尾部有没有多余等待。

结果部分可用时可以剪辑复用；核心动作错误则修改相应描述与参考。先保留满意区间，再决定下一次生成，减少整片反复重做。

  1. 查看右侧任务状态。视频可能比图片等待更久，处理过程中不要重复提交同一任务。
  2. 完成后打开作品，实际播放全片，检查动作、镜头和主体外观。模型支持声音时，也要打开声音听一遍。
  3. 满意时点击「在文件夹中显示」，找到作品文件，并保存到自己的项目目录。
  4. 不满意时修改一个主要问题，例如只把镜头改固定，再生成新版本进行比较。

从图片详情直接进入视频

如果已经在图像生成中得到满意图片，可以打开图片详情，点击「生成视频」。进入视频页后先确认参考图片，再写动作、选画幅与时长并检查费用。图片描述不能完全替代动态镜头描述。

从图片详情进入可以快捷复用该图片，但要再检查当前模型与参考方式。想让已确认图片成为明确开始画面时，使用适用的首帧位置，而不只依赖普通参考。

动作写得与原图姿势相容更容易理解。例如手已经拿着杯子，就描述怎样举起或放下，不重复从桌上拿起另一只杯子。

常见问题

无法生成、任务失败、预览打不开和画面不满意是不同问题。先确定发生在哪一步，记录明确提示，再按对应说明排查；不要把所有问题都当作模型效果差。

等待期间查看已有任务，防止重复提交。文件暂时未能播放时先确认结果和本机文件，不立即重做一个新视频。

  • 视频里主体变形：先缩短动作、减小幅度，使用主体清晰的参考图片。
  • 背景被整体替换：在描述里强调保留环境，避免要求同时换场景。
  • 参考图不能选：查看当前模型和模式支持的类型，必要时更换模型或参考方式。
  • 按钮不可用：检查描述、素材准备情况、时长和模型状态。
  • 任务失败：打开失败详情看原因，核对参数后再尝试；不要只把相同请求反复提交。

参考素材与首尾帧怎么选

参考方式决定你是在「参考一种内容」还是「指定开头与结尾画面」。选错方式时，素材可能无法添加，或结果控制不到你想要的位置。

约 6 分钟阅读

先理解几种参考方式

同一素材能在不同方式中发挥不同作用。图片参考负责外观与氛围，首尾帧负责起止画面，视频参考表达动作或运镜，独立音频则可能涉及声音。

先决定需要控制哪一项，再选择支持该输入的模型与方式。没有对应入口时改用可行方法，而不是在普通列表里添加文件就认为功能已经实现。

  • 文字：主要靠描述创建一个新镜头，适合没有现成画面的探索。
  • 参考图片：表达人物外貌、商品外观、场景或风格；需要在描述中说清参考用途。
  • 参考视频：在模型支持时用于表达动作、镜头或节奏，仍需明确希望参考哪一部分。
  • 参考音频：在模型支持时用于声音相关创作；添加音频不等于每个模型都能按原样复制声音。
  • 首帧：强调视频开始时应出现的画面。
  • 首尾帧：用两张图片表达开始与结束画面，再通过描述说明两者之间如何变化。

使用普通参考素材

选素材后需要写职责，尤其在多人物、多场景任务里。先用 @ 指出实际文件，再说明保持人物服装、采用场景布局，或只借鉴某一段动作。

素材越多并不一定更稳定。优先留下与当前镜头有关且不会相互冲突的参考，生成前再核对本次数量与总价。

  1. 进入视频生成，先选择模型。确认参考区域提示允许哪几种文件以及数量上限。
  2. 在「参考素材」下点击「添加」，从现有文件选择，或使用「上传素材」添加新的文件。
  3. 选中素材后点击「使用所选素材」，回到视频页检查所有缩略图。
  4. 在「创作描述」说明每份素材的用途。多个素材可用输入框提供的 @ 引用进行区分。
  5. 确认画幅、时长和费用，再点击「生成视频」。

使用首帧或首尾帧

首尾帧应来自相近主体与环境，并按开始、结束顺序放好。描述的任务是解释它们之间的变化，而不是把起点与终点分别写成完全不相干的两段故事。

仅需要首帧时检查当前模式是否允许；若页面要求两张则先补齐。不要把音频或视频放进图片位置，也不要用 @ 绕过数量规则。

  1. 选择支持该方式的模型。当参考区域提供切换按钮时，切换到「首尾帧」。
  2. 点击「首帧」，选择镜头开始时的图片；选完使用所选素材，确认它出现在首帧位置。
  3. 需要指定结束画面且当前模型允许时，点击「尾帧」添加结束图片。页面要求两张时，请补齐两张后再生成。
  4. 检查顺序，避免把开始和结束图片放反。只控制开始画面时，也必须确认当前模型是否允许不填尾帧。
  5. 填写中间的动作或过渡，例如「人物从正面缓慢转向侧面，背景保持不变」，再设定时长与费用。

切换方式时需要清理什么

普通参考素材与首尾帧可能互相排斥。若页面提示已有参考内容，先移除普通参考缩略图和描述里的相应 @ 引用，再切换模式。首尾帧只使用图片；视频和音频不要放进首帧或尾帧位置。

切换方式意味着控制目标变化，本次素材也需要重新整理。普通参考与首尾帧互斥时，先清理旧参考及对应引用，再确认新位置。

更换模型会同时改变画幅、时长与档位。切换结束后做一次完整核对，避免旧图还在、参数却已经成为另一套不匹配的选择。

小提示切换模式或更换模型后，重新检查参考素材、画幅、时长和费用。不要假定之前的选择都仍然适用。

怎样准备更容易过渡的两张图片

过渡容易理解的条件是主体、环境和光线稳定，动作变化合理。先用小幅转头、抬手等简单变化测试；大范围换装换场景更适合拆成不同镜头。

完成后连看开始、中间和结束，不能只凭两张指定图片正确就认为中间自然。存在重复或空等时可裁剪，外观错乱时需要处理生成内容。

  • 开始与结束尽量使用同一主体、相近外观和同一个环境。
  • 保证主体清晰、图片比例接近最终画幅。
  • 先尝试小幅变化，如转头、抬手或轻微推进镜头。
  • 人物、服装、地点和构图同时大幅变化时，更容易产生突变；可拆成多个镜头处理。

添加失败时排查

添加失败先看类型和数量，再看文件能否预览及是否准备完成。文件库中的旧记录也要确认当前入口能使用，换账户或设备后尤其如此。

持续失败时提供模型、模式、素材类型与明确提示。先缩小到一份可正常预览的参考验证，避免用大量文件反复提交而掩盖问题。

  1. 确认当前模式支持该类型文件，首尾帧必须是图片。
  2. 确认没有超过参考数量和文件限制，减少重复素材。
  3. 等待新素材准备完成，再提交生成。
  4. 如果仍提示素材不可用，换一份能正常预览的文件重新添加；更换账户或电脑后，也要重新确认文件能找到。

  2. 如果只有文字，确认该模型支持按当前页面的文字方式开始。
  3. 如果要使用图片、视频或音频，查看参考区域对类型和数量的提示。
  4. 如果要控制首尾画面，确认可选择「首尾帧」方式。没有对应选项时，不要强行添加两张图假装是首尾帧。
  5. 选好模型后，再确认画幅、时长与分辨率选项。

画幅与参考图片比例

画幅决定最后能看到多少空间，分辨率决定输出尺寸档位。主体靠边或参考比例差异大时，可能出现裁切，需要提前安排构图与安全边缘。

不同参考方式也可能有不同画幅限制。当前选项不可用时，先判断能否换适用模式或设计另一种构图，不擅自拉伸主体来凑比例。

  • 9:16 用于常见竖屏短视频，16:9 用于横版视频。其他选项是否可用，以当前模型为准。
  • 画幅是宽高关系，分辨率是输出尺寸档位，二者不是同一项设置。
  • 参考图与最终画幅接近时，更容易保留原构图。差异较大时，要提前考虑哪些边缘内容可能被裁切。
  • 主体需要完整出现时，在描述中补充「完整主体，四周留有空间」，并在结果中核对。

时长怎样安排

从页面「时长」选项中选择模型支持的长度。第一次先做一个短片段验证动作；短时长里优先安排一个主要动作。

时长是动作与台词的容器。简单展示用合适短段验证，多个事件则拆成分镜；长时长本身不保证故事表达完整，也可能增加空等。

目标成片与单次生成长度分别记录。后期可以裁掉不需要区间，但本次费用仍按实际生成时长计算，不能按最终只保留几秒来预算。

  • 一个转头或简单展示动作：选择当前可用的短时长试一次。
  • 有几个连续动作：先写清动作顺序，判断它们是否能在所选时长内自然完成。
  • 超过单段支持时长：拆成几个镜头，分别制作，再通过适用的成片功能组合。
  • 描述里的「15 秒」不能替代页面实际选中的时长参数，两者都要核对。

分辨率与费用

模型提供 480p、768p 或其他档位时，可先用基础档位验证画面，再按用途决定是否生成更高档位的新版本。高分辨率不能自动修正错位动作或错误主体。

输出档位与本次报价需要一起看。基础档位适合验证动作，正式发布是否需要更高尺寸取决于用途；内容错误先改内容，而不是仅提高档位。

每次模型、参考类型、时长或数量改变后，再看总价。页面提示价格更新时按新报价确认，不把上一轮价格当作当前任务永久价格。

  1. 选好分辨率，再看生成按钮附近的积分费用。
  2. 修改模型、时长或输出档位后，等待费用显示更新。
  3. 显示费用暂时不可用时，按页面提示处理，先不要假定旧费用仍然有效。
  4. 提交前再核对一次余额、费用、画幅、时长与素材。

声音、对白和字幕

对白、旁白、音乐与字幕不是同一个要求。模型原生声音按支持范围使用，独立旁白通常需要实际录音，精准字幕则适合在最后声音确定后制作。

无论采用哪个路线，都要听真实结果。音轨存在只说明有声音，不证明文字准确、口型自然或音乐不会盖过讲话。

  • 先确认当前模型是否支持你需要的声音能力。支持图片参考不意味着一定支持音频参考。
  • 需要对白时，写出确切的台词、说话人和发生时机；结果完成后听一遍确认。
  • 不需要音乐或字幕时，在描述中明确说明；最终仍需检查是否出现多余声音或文字。
  • 需要精确品牌文字、字幕或对白时，不要省略人工核对。

约 5 分钟阅读

进入与指定参考

分析前说明关注哪里、为了什么。拆解广告结构与检查说话内容是两种问题，可以分步进行；长视频先指定区间，避免要求对每一秒都做同样详细的说明。

使用 @ 选实际文件，并明确先分析不生成。没有素材时只能讨论方法，不能把讨论当作已经查看过原片。

  1. 在 Agent 添加视频，或从文件库选择。
  2. 用 @ 指定原视频，说明关注整片还是某个时间段。
  3. 提出具体问题：动作、镜头切换、台词、时长、产品展示或声音。
  4. 先查看分析结果，不确定的部分回到原视频播放核对。

拆解镜头与结构

画面切换不一定等于叙事段落。让助手解释各镜头承担什么信息，再判断哪些值得借鉴。

镜头拆解要同时记录可见动作与该段作用。开场吸引注意、细节说明产品、结尾表达行动，都是内容组织；画面有切换不一定就承担新的叙事信息。

需要时间准确时回放对应位置。抽看一些画面可能漏掉短动作，重要镜头自己确认再使用分析结论。

识别与核对台词

识别稿用于辅助理解台词与字幕时间，可能听错专名、数字和口音。先给准确品牌或人物名称，再逐句核对；原字幕与实际声音不一致时也要区分。

想修改说话内容，需要处理真实录音或视频，不能只在识别稿里改一个句子就认为原片已改变。

小提示识别可能听错。字幕、真实语音和剧本三者不完全一致时，以你核对的实际内容为准。

查静音、提取音轨

有音轨不代表台词一定正确，也不代表配乐合适。原声提取仍可能同时带有音乐与人声。

查声音与提取音轨是不同动作：前者帮助判断音量和静音区间，后者得到实际音频供试听或再合成。指定原视频的起止区间，完成后听一遍。

提取的仍可能是对白、音乐与环境声混合的一份声音，不能保证自动分成独立人声和背景音乐。

把分析变成下一步

分析应帮助决定复用还是补制作。已有可用动作先裁剪，只有核心内容缺少时才补镜头；台词或字幕问题也应分别处理，不必整片重做。

把采用区间与改编目标记下来，后面合成时明确指向原片。只借鉴结构就不要默认直接复制原品牌、台词与人物。

  • 有可用动作：优先裁剪和复用已有片段。
  • 缺少关键动作：只补缺的镜头。
  • 字幕有错：先纠正实际台词，再生成字幕版。
  • 需要换成自己产品：保留原片结构，重新安排有授权的产品和角色参考。

如何检查分析是否可靠

问助手对应哪一段画面或台词，自己回放那个位置。抽取几个画面不能证明全片动作连续、人物声音或口型正确，交付前仍需完整播放。单次台词识别和音轨提取有区间上限，长视频分段处理。

可靠性来自可核对的证据。问清对应时间与实际画面，再自行播放；对看不清或听不清的部分，允许助手标明不确定，比让它补一个看似完整的结论更有用。

全片交付前仍要完整检查，尤其口型、人物外观与音乐变化。分段分析的长内容也要保证关键区间没有遗漏。

约 4 分钟阅读

准备原片和替换素材

先把原片的结构与自己的素材分开。原片用于借鉴节奏和镜头作用，真实商品图或角色图用于定义新内容；明确哪些直接复用、哪些要重做，避免混用品牌和人物。

如果只想分析原片，先说明暂不制作。看到改编方案后再决定新生成范围与费用。

  1. 添加参考视频，以及自己的产品、人物或场景图片。
  2. 分别命名并用 @ 引用，说明原片负责结构、哪些图片负责外观。
  3. 写清要保留的节奏和要更改的人物、产品、台词、品牌或画幅。
  4. 要求先分析、给改编方案，暂不制作。

可直接尝试的改编需求

需求要说明保留什么和替换什么，例如保留三段节奏，换产品、台词与品牌。这样可以评审结构是否还有效，而不是把原片所有可见内容都照搬。

已有卖点按真实材料使用。替换产品并不自动具备原广告里的全部功能，必须核对准确事实。

确认素材职责与制作缺口

缺口清单把方案与真实文件对应起来：已有哪段可用，缺哪段动作，旁白是否已有录音。若关键素材还没准备好，先补准备，不让助手假定文件存在。

记录预计生成次数与各段用途。批准一个方案不等于随意扩展更多镜头，任务变化时重新核对。

  • 已有视频哪些区间可以直接使用。
  • 哪些人物、场景或产品画面需要重新制作。
  • 台词、旁白和字幕应改成什么准确内容。
  • 是否需要独立配音或音乐，你是否已有对应文件。
  • 计划生成多少段，每段用于哪里，怎样保留为最终成片。

确认后分段制作

先验证产品或角色最关键的一镜，确认外观与动作，再继续其他内容。成功素材保留，失败或偏差只在相关镜头处理，不把每次修改变成全片重做。

最后连着播放，检查是否残留原品牌、原字幕或不需要的人物。只看新封面不足以证明全片已经改完。

  1. 选定方案，检查真实可用的模型、画幅、时长和参考方式。
  2. 先制作最关键的产品或人物镜头，检查外观与动作。
  3. 成功镜头保留，只处理剩余缺口。
  4. 使用现有和新生成的视频，指定区间、声音与字幕，再合成。
  5. 回看成片，检查原品牌、原字幕或不需要的角色是否残留。

想继续改时

继续改编时用镜头名、版本和问题定位，说明保留哪些结果。需要新生成就重新核对描述与费用；已有动作可用只需短一点，则用剪辑。

修改完成再检查接点与声音。单镜正确但节奏、人物或道具接不上，仍需要调整整体安排。

视频续拍：用尾帧和已有素材延续镜头

续拍的目标是接着一个已经存在的动作或画面继续发生。先看原片结束状态，再准备下一段；当前做法可通过提取尾帧、支持的首帧或参考方式，以及后续剪辑完成。

约 4 分钟阅读

先检查原视频末尾

续拍从上一段实际结束状态开始。先看脸、方向、姿势、持物手、道具与光线，再写下一段新动作；只记得故事而忽略画面，容易出现跳变。

原片仍在等待时不要把想象中的结尾当作真实尾帧。采用哪一版必须明确，先播放确认再继续。

  1. 在 Agent 或短剧项目中选择已完成且能播放的视频版本。
  2. 查看最后的动作、姿势、持物手、光线和场景。
  3. 说明下一段要发生什么，哪些特征需要继续保持。
  4. 先让助手确认当前可用模型支持哪种续接参考，不把任意时长当作必然支持。

用尾帧作为下一段首帧

尾帧提供一个明确起点，适合下一段从相同姿态继续。先预览提取图片，再放进支持的首帧或接续参考位置；图片不清或动作处在不自然中间态时，先调整选点。

生成新段后连着播放，裁掉必要的重复停顿。前段已经满意就保留，续拍不应自动重做原片。

  1. 本镜有「提取尾帧」时，提取并查看结束图片；Agent 中也可以说明要查看末尾并准备适用的接续参考。
  2. 选择支持首帧或相应参考方式的模型，将图片放到下一段的正确位置。
  3. 描述从这个姿态开始的新动作，不要把已经做完的动作重复写一遍。
  4. 确认时长、画幅和费用后生成。
  5. 连着播放前后两段，检查动作与外观，再剪掉重复的停顿并合成。

给 Agent 的续拍需求

好的续拍需求应强调已经完成的动作和接下来发生的动作。女孩已拿到信封，下一段就打开它，而不是再次从书里找信封。

同时保持角色外观、服装、场景和画幅。让助手先核对可用参考方式与时长，避免把延续效果写成所有模型必然具备的能力。

为什么不一定完全无缝

无缝衔接需要多个条件同时匹配，首帧只是其中之一。动作方向、服装、道具和光线差异，可能无法仅靠合成掩盖；先定位差异属于生成内容还是剪辑重复。

可以用自然动作节点分段，例如拿起后停顿，再打开。连续快速动作中间硬拆更容易暴露不一致。

  • 首帧提供起始画面，但不能保证全段人物外观和运动完全一致。
  • 前后光线、服装或持物方向差异大，会产生明显跳变。
  • 新段重复旧段结尾动作时，可以裁掉重复部分，不一定要重新生成。
  • 需要连续动作但当前模型不支持长度时，先设计可接续的动作节点再分段。

续拍与视频延长的区别

「再做一段并接上」可以通过上述分段方式完成，不等于所有模型都有原视频直接延长开关。使用某个模型的延长或视频参考能力前，让 Agent 先核对当前支持范围。

再做一段接上，是分段制作与后期组合；原视频直接延长，是某些模型可能提供的特定能力，两者不能仅凭名称混同。

当前入口没有延长方式时，使用支持的帧或参考设计接续方案。新段按实际生成规则计费，旧段裁剪也不会改变原任务费用。

建立项目，从故事走向分镜

短剧创作用于把多个镜头放在一个项目中制作。当前「创建项目」会进入分镜工作台；先用两到三个分镜完成一段短故事，再扩展到更多镜头。

约 6 分钟阅读

先准备这四件事

故事、镜头、参考与规格相互约束。确定想讲的转折，再安排必要镜头；确认角色和道具，才能在各镜中复用；确定画幅与预算，才能决定制作规模。

先用两三镜练习完成一个短事件，比一开始建立很长但无法生成的剧本更容易掌握整个流程。

  • 故事：谁在什么地方，发生什么，最后有什么变化。
  • 镜头：把故事拆成几个可单独生成的片段，每段有清楚的主体和动作。
  • 参考：主角、场景和重要物品的图片，尽量提前确认外观。
  • 规格：最终竖屏还是横屏、希望的总时长，以及可接受的生成费用。

创建并命名项目

项目名要能区分故事与阶段，避免以后误开相似项目。当前入口直接进入分镜工作台，先观察现有布局，再操作已有按钮。

旧项目布局不同可以沿用原入口，不必为了教程另找模式。实际输入区、名称编辑和保存结果都以当前页面为准。

  1. 点击左侧「短剧创作」，进入项目列表。
  2. 点击「创建项目」，打开分镜工作台。当前入口会直接创建项目，不需要寻找一个额外的模式选择步骤。
  3. 点击顶部的项目名称，按页面提供的名称编辑操作改成容易识别的名字，例如「雨夜来信_练习」。
  4. 看到分镜为空时，点击「新建分镜」，开始第一个镜头。

填写第一个分镜

第一镜最好能验证主要角色或关键产品，同时动作足够简单。把人物、环境、动作和镜头写成完整画面，再添加与之对应的参考；一句剧情概括不足以准确生成。

生成前核对该镜模式、画幅、时长和总价。第一镜成功后，后面仍要逐镜确认设置，不能假定全部自动相同。

  1. 为分镜设置容易识别的名称，例如「女孩走到书店门口」。
  2. 在分镜的内容输入区写完整画面：主体、环境、动作和镜头。分镜内容会用于生成本镜视频，不能只有一句剧情概括。
  3. 选择当前镜头的生成方式。只用文字时使用文本方式；需要人物和场景参考时选参考图片；需要指定起止画面时选首尾帧。
  4. 按对应模式加入参考素材，确认没有放错位置。
  5. 选择视频模型、画幅和时长，查看本次积分费用。确认无误后点击本镜的「生成」或页面提供的「生成分镜视频」。

生成后再扩展其他镜头

每次扩展都应接着前一镜的终点，保持服装、持物方向和道具。人物参考沿用同一份，局部变化在描述中说清，减少外观漂移。

一个镜头不满意时保留其他成功结果，只改这一镜。每次重新生成是新版本，应再次检查费用，并明确采用哪一份。

  1. 等待第一个镜头完成，点击视频预览，确认角色、动作和场景都符合要求。
  2. 如果不满意，先调整描述或参考，生成新版本；满意后选择本次要使用的版本。
  3. 点击「新建分镜」，建立第二个镜头。需要人物保持一致时，继续使用同一张角色参考。
  4. 逐个检查每个分镜的画幅、时长和素材。前一个镜头已经完成，不代表新建镜头的全部设置自动正确。
  5. 重复这一过程，先得到两到三个可用镜头，再考虑成片。

合成前必须确认

合成前将镜头按顺序连看，确认采用版本、人物一致性、画幅和动作接点。不同片段都能单独播放，不代表放在一起就自然。

当前最终合成后会锁定编辑，先完成内容修改和版本选择，再确认。字幕、旁白或图文后期可在得到成片后继续安排。

  • 每个要采用的镜头已经完成，并能实际播放。
  • 每个分镜选择了你满意的版本，不是误选第一次生成的结果。
  • 分镜顺序正确，角色、服装、场景和重要道具前后没有明显冲突。
  • 画幅适合放在一起，镜头之间的节奏和动作衔接已检查。
小提示当前分镜工作台生成最终成片后会显示已锁定，后续不能继续添加分镜和编辑。请先完成修改与版本选择，再确认合成。

关闭项目后如何继续

回到短剧项目列表，找到对应名称并打开。继续创作前先查看现有分镜和保存提示，确认打开的是正确项目。想开始完全不同的故事时，创建一个新项目。

重新打开项目时先核对名称与已保存的分镜，确认不是另一个相似故事。项目记录与本机实际视频分别检查，重要成片和源素材另外保留。

删除是清理整个项目的操作，不应拿来处理一镜不满意。先通过版本和内容调整解决，避免丢失以后要复用的参考与记录。

小提示删除项目会影响项目、剧本和分镜记录；不要把删除项目当作清理一个不满意镜头的方法。重要作品文件请另外保留。

整理人物、场景与物品素材

先确定重复出现的角色和环境，再把适用的素材加到具体分镜。素材的作用是帮助你表达一致的外观，并不能替代本镜的动作和镜头描述。

约 5 分钟阅读

先准备一套可辨认的参考

参考库重点是统一外观，而不是堆很多图片。主角准备一张清楚的确认图，场景准备容易辨认的环境，道具准备能看见结构与颜色的图片，先让制作有稳定依据。

风格不同的多份主角参考会让后续目标混乱。需要不同角度时，先核对脸型、服装和配饰仍然一致。

  • 人物：主角的面部、发型、服装和身材特征清晰，优先选主体完整的图片。
  • 场景：地点布局、光线、色调明确；同一故事尽量不要混用差异过大的场景。
  • 物品：故事里重要的信封、杯子或其他道具，准备清晰图片，并在描述里写出关键外观。
  • 一个素材一个清楚用途。命名可以用「主角_深蓝外套」「旧书店_夜景」「信封_米白色」，方便选素材时区分。

先把参考放进文件库

上传后预览，给素材能说明用途的名称，并区分草稿与采用版。文件名称与内容核对好，再放入具体分镜，可以减少后续引用错误。

素材是否在当前项目可用仍按入口确认。不要把文件库的一条旧记录默认当作任何设备都能打开的实际图片。

  1. 点击左侧「文件库」，使用「上传素材」加入电脑上已有的图片。
  2. 点开图片预览，确认主体清晰、方向正确，没有上传错版本。
  3. 用重命名操作改成清楚的名字；没有合适图片时，先去「图像生成」制作参考并检查。
  4. 回到短剧项目，为需要的分镜添加对应素材。
小提示文件库里有一张图片，不代表每个分镜都已经使用它。添加后必须在该分镜的参考区域再次检查。

在分镜中添加人物和场景

同一个人物与场景在连续镜头中反复使用，并说明各自职责。首尾帧需要起止画面，普通参考则需要写外观与环境；位置与模式要一致。

参考中的道具、文字或其他人也可能影响结果。希望只采用主角时明确说明，必要时换更干净的素材。

  1. 选中要制作的分镜，选择支持参考图片的模式和模型。
  2. 在人物、角色或场景的添加入口中，按当前页面提示选择已有文件；支持生成素材的入口也可先制作图片。
  3. 选完素材后，确认参考缩略图出现在当前分镜中。
  4. 如果有多张图片，检查它们的顺序和数量，以及本镜模型的限制。
  5. 在分镜内容中写清「哪个人物在什么场景做什么」，并说明要保留的外观。

物品怎样保持连贯

分镜工作台以当前显示的人物和场景参考入口为准，不一定提供独立的物品栏目。重要道具可以放在相关参考画面中，并在每个镜头的描述里反复说明关键特征。画布项目中有物品内容时，也需要确认它实际用于哪个镜头。

重要道具是叙事线索，颜色、大小、图案和持物手都要稳定。例如信封不能在下一镜变成手机，品牌包装也不应出现另一种标志。

把必须保留的特征写在每镜相关描述里，生成后对照检查。统一参考有帮助，但仍不能免去实际验收。

前后不一致时怎么修

前后不一致先判断是哪一镜偏离，然后改对应描述或参考。已经正确的角色图和成功镜头先保留，不要为修一处细节重新生成整套素材。

如果只是某个版本选错，先换采用版本；如果核心外观本来就错，才补生成。修改后再检查相邻镜头，确认没有引入新的冲突。

  1. 先比较两镜采用的角色和场景参考，确认不是选了不同人物或地点。
  2. 检查描述里的发型、服装、时间、天气和道具有没有冲突。
  3. 只修改偏离的分镜，先用同一份参考重新试一次。
  4. 如果一个镜头需要更稳定的开始画面，可以尝试所选模型支持的首帧方式。
  5. 再次播放前后两镜，看外观和动作是否更接近，再决定采用哪一版。
小提示即使使用同一组素材，不同生成结果也可能有差异。合成前必须逐个看，而不是只核对素材名称。

完善分镜，选择镜头并导出

一个分镜应当描述一个明确的可拍画面。这篇指南说明怎样写镜头、选择生成版本、提取尾帧，以及在当前分镜工作台中合成并找到最终文件。

约 7 分钟阅读

分镜内容怎样写

分镜内容应能让读者想象一段实际动作。主体是谁、在哪、从什么姿势开始、做什么、怎样结束，配合一种主要镜头，才适合对应当前长度制作。

需要准确对白或文字时逐字写清；要沿用角色和道具则引用真实参考。复杂事件太多就拆镜，不靠加长描述解决。

  • 主体与地点：谁在什么环境中，哪些特征要保持。
  • 动作：这一镜具体发生什么，先后关系是什么。
  • 镜头：景别、视角，以及固定还是移动。
  • 时间与衔接：前一镜结束时是什么姿态，下一镜应该从哪里接起。
  • 声音要求：只有在当前模型支持时，说明对白、环境声或音乐。

生成并比较版本

多个版本用于比较，不等于同时都要进入成片。逐个播放并标明本次采用哪一份，核对人物、动作和声音，而不是只选封面最好看的。

重新生成会形成新的费用与结果，旧版也可能仍有可用部分。只修改有问题镜头，其他成功内容保持。

  1. 选中一个分镜，完成描述、参考素材、模型、画幅和时长设置。
  2. 核对本镜费用后点击「生成」。其他分镜还没写好时，先不要同时生成全部镜头。
  3. 完成后点开视频预览，检查动作、角色、道具和声音。
  4. 不满意时改描述或素材，再生成新版本。一个分镜有多个版本时，分别播放比较。
  5. 在版本列表或本镜提供的选择操作中，选定最终要采用的那一版。看到「当前版本」等提示后，再检查画面。

需要接续动作时使用尾帧

本镜提供「提取尾帧」时，可从已经完成的视频中获得结束画面。它可以作为下一镜的首帧参考，帮助你表达接续的姿态和环境。

尾帧帮助续接动作的起点，提取后先看姿态与道具是否自然。下一镜从这个状态继续，不重复已经完成的动作，再按支持方式添加。

尾帧不能保证整段完全一致。前后连放检查外观、方向和光线，重复停顿可裁掉，主体错误则处理相应生成。

  1. 先选中一个能正常播放的完成版本。
  2. 使用「提取尾帧」，完成后在素材中查看提取的图片。
  3. 建立或选中下一镜，选择支持首帧的模型和方式。
  4. 把提取图片设为下一镜的首帧，再写接下来要发生的动作。
  5. 生成后连着播放两镜，确认衔接是否自然。
小提示尾帧参考帮助控制起点，但不能保证动作、光线或镜头完全无缝。最终效果仍需播放检查。

分镜合成的条件

分镜合成需要足够且可播放的已完成镜头，每镜采用一个明确版本。它负责按顺序组合，不能自动把错误动作、缺失台词或冲突人物修好。

镜序与采用版先确定，尤其当前成片完成后锁定编辑。不要因为合成按钮可点击就跳过检查。

  • 当前「分镜合成」需要至少两个已完成、可用的视频。
  • 每个分镜最多选择一个版本参与本次合成。
  • 未完成或文件不可用的镜头不能当作已完成成品参与。
  • 镜头按分镜顺序组合；合成前先把分镜顺序整理正确。
小提示部分旧布局可能显示「一键拼接」及不同的完成条件。以当前按钮和提示为准；本篇下面说明的是当前「分镜合成」操作。

选择本次合成内容

选择窗口用于确认这次真正进入成片的内容。看清每个镜头与版本，漏选可能丢故事信息，误选旧版可能把已修复问题重新带回来。

有问题就先返回调整；确认后再开始合成。需要旁白、音乐或字幕时另行安排，不把分镜合成自动理解成全部后期已完成。

  1. 确认各镜头已完成修改后，点击「分镜合成」。
  2. 在「选择本次分镜合成内容」窗口中，勾选要参与的分镜。
  3. 有多个版本时，为每个分镜选择一个版本，并用「预览」检查内容。
  4. 查看已选视频数量，确认至少两个；不想采用的分镜取消选择。
  5. 还需修改时点击「返回检查」。已经全部确认后，点击「确认并开始合成」。
  6. 等待合成完成，打开最终成片，从头播放到结束检查。
小提示合成成功后，当前工作台会显示成片已生成、后续不可继续添加分镜和编辑。请把确认合成当作最后一步。

找到文件与保留项目

找到实际成片后完整播放，确认最后一个镜头与声音尾部也正常，再保存文件。保留源镜头与项目记录，有助于后面做配音、字幕或重新剪辑。

只保存一个缩略图或只记住项目名称不够。交付对象需要可以正常播放的实际视频。

  1. 打开最终成片预览，使用可用的「在文件夹中显示」或文件操作入口找到电脑文件。
  2. 把最终视频复制到你的交付文件夹，重新播放确认文件完整。
  3. 保留需要的原始素材、采用的镜头文件和描述，便于之后重新制作。
  4. 还需要继续拍新版本时，先保留这些内容，再创建新项目，不要直接删除旧项目。

合成按钮不可用时

按钮不可用先看已完成镜头数量、采用版本、文件是否可用和项目是否已经锁定。等待中的任务还不是合成素材，先看它的真实状态。

不要重复提交生成来试图点亮合成按钮。提供当前提示与哪些镜头可播放，能更快定位缺少条件。

  • 先检查完成镜头数量是否达到当前要求。
  • 确认各分镜已经选中完成版本，而不只是有一条等待中的任务。
  • 确认视频文件能播放；文件未找到时先处理文件问题。
  • 确认当前项目是否已经生成最终成片并锁定。

实战：用三个镜头完成一段短故事

跟着做一个「女孩在旧书店发现来信」的练习。目标是熟悉素材、分镜、版本选择和成片流程，不要求第一次就做出最终商业作品。

约 6 分钟阅读

练习目标与准备

这个练习用进入书店、发现信封和产生疑问三个信息组成完整短事件。每镜只有一个主要作用，既便于学习生成，也便于检查衔接。

先完成三镜可用视频，再考虑更长对白或复杂动画；演练重点是完整制作链路，不是堆效果。

  • 故事：女孩进入书店，在旧书里发现一封信，抬头看向窗外。
  • 镜头：三个，每个只安排一个主要动作；具体时长从当前模型支持的选项中选择。
  • 画幅：统一使用当前模型支持的同一种比例，例如 9:16。
  • 素材：同一位短发、深蓝外套女孩的角色参考；旧书店的暖色内景参考；道具为米白色信封。
小提示不要先承诺一个固定总费用。每镜生成前看当前显示的费用，不满意的重做也需要重新确认。

第 1 步：先做角色和场景参考

主角和书店环境先确认，后面反复使用同一份参考。角色脸型、服装与书店光线应该能逐项核对，道具信封也要有统一描述。

参考不满意先调整参考，不让三镜同时使用三套不同人物。准备正确外观往往比后面反复补救更有效。

  1. 在图像生成中制作或在文件库上传主角参考，检查发型、服装和外观。
  2. 准备书店场景参考，确定木质书架、窗户位置和暖色灯光。
  3. 把素材命名为容易识别的名称，打开预览确认。
  4. 不满意的参考先修改；三镜已经开始后再改变主角外观，会增加返工。

第 2 步：建立项目与第一个镜头

第一镜负责让观众知道人物进入哪里，不必同时翻书、读信和离开。保持动作简单、主体完整与场景明确，更容易验证角色和环境。

生成后检查门的位置、服装与进入方向。满意后保存该版本，第二镜在同一环境里接着开始。

  1. 进入短剧创作，点击「创建项目」，名称改为「旧书店来信_练习」。
  2. 点击「新建分镜」，名称写为「进入书店」。
  3. 选择支持图片参考的模式与模型，添加主角和场景参考。
  4. 复制下面的分镜描述，统一画幅，选择适用时长，确认费用后生成。
  5. 完成后播放，只有主角和环境基本符合要求，才继续第二镜。

第 3 步：制作第二个镜头

第二镜负责呈现线索，需要观众确实看见书与信封。手部与道具是重点，所以镜头从中景到特写应服务于这个动作，不增加无关运镜。

生成后检查信封从哪里出现、大小颜色是否稳定。问题只在这一镜时，不重做已经成功的开场。

  1. 新建分镜，名称写为「发现信封」，继续使用同一组角色和书店参考。
  2. 填写下面的内容，检查画幅与第一镜相同，再设置本镜时长和费用。
  3. 生成并播放。特别检查信封是不是从书中出现，是否变成其他物体。
  4. 结果不正确时，只修改这一镜；满意后选中要采用的版本。

第 4 步：制作第三个镜头

第三镜负责人物反应，不需要用长文字解释情绪。抬头、停顿与视线能帮助表现疑问，动作起点仍要接着手持信封的状态。

检查道具是否还在正确手里、角色是否还是同一人，结尾是否留出自然停顿。多余空等可在合成时裁剪。

  1. 新建分镜，名称写为「抬头看向窗外」，确认采用相同角色外观与场景风格。
  2. 填写下面的内容，再核对画幅、时长和费用。
  3. 生成后连着播放第二、第三镜，检查手中的信封和人物外观是否一致。
  4. 有偏差时先修改第三镜，确认满意版本后再继续。

第 5 步：检查后合成

按故事顺序连看，确认进入、线索与反应都清楚，再采用满意版本合成。镜头长度不必完全相同，信息充分且节奏自然更重要。

完成后检查实际成片，字幕或旁白需要时再按最终声音安排。当前工作台锁定后不要期待直接继续改分镜，先在确认前处理。

  1. 确认三镜都能播放，每镜选择一个满意版本。
  2. 按「进入书店、发现信封、抬头看向窗外」的顺序检查故事。
  3. 检查服装、信封和光线，没有明显突变后，点击「分镜合成」。
  4. 勾选三镜，在合成窗口逐个预览版本，确认后开始合成。
  5. 成片完成后从头播放，找到电脑文件，保存练习结果。
小提示当前工作台合成成片后会锁定编辑。还有镜头需要重做时，先返回检查，不要急着确认合成。

  • 逐镜确认费用、预览结果、选择版本。
  • 在合成前检查顺序和连贯性，并保存最终文件。

入口与素材准备

合成已有素材的第一步是确认所有源视频可播放，采用哪个版本，以及希望怎样使用。文件准备好后再要求剪辑，不让助手根据一个名称猜内容或补造区间。

需要纯后期时明确不生成新镜头。只有发现真实缺口且你确认方案后，才补制作。

  1. 进入 Agent 的一个项目，添加所有要用的视频，或从当前文件库选择已有镜头。
  2. 为每段视频设置不同名称，例如「开场」「产品特写」「结尾」，先逐段预览。
  3. 通过 @ 选中需要的素材，说明只剪已有素材还是允许补拍缺失镜头。
  4. 确定成片画幅、顺序、每段保留范围和声音处理。

指定每段保留哪里

保留区间使用各段原视频的时间。上例保留 3 秒、5 秒和 3 秒，总长为 11 秒。源文件太短时先调整安排，不要让助手凑一个不存在的时间范围。

每段保留时间从该源视频的开头计算，不从整片计算。将 A 的 1–4 秒放在第一段，后面的独立旁白开始位置则从新成片开头计时，两套时间不要混用。

区间要在源片实际长度内，镜头动作和台词不能被切断。先核对总长度，再安排声音与字幕。

让助手挑选区间

不知道具体秒数时可以描述可见动作，让助手先分析并建议区间。建议应说明选点理由与预计时长，关键动作自己回放确认。

「删掉空等」不等于自动缩短所有停顿。反应镜头、呼吸和一句话结束的自然停留，可能是内容需要，应按用途判断。

小提示没有告诉助手具体秒数时，可以先让它查看素材再建议，但仍需确认关键动作和台词是否完整。

声音与画幅要明确

合成时同时决定画面与声音：是否允许裁切、逐段原声保留多少、录音从哪里开始、音乐何时结束。画幅不一致尤其要防止关键主体被裁掉。

声音长度不够或太长时先调整安排，不能默认变速。字幕最好在最终剪辑与混音确认后制作，避免整份时间重新对齐。

  • 保留原声：使用每段视频已有的声音。
  • 关闭原声：该段对白、背景音乐和环境声都可能一起消失。
  • 添加旁白或音乐：提供独立音频，指定在新成片从哪一秒开始。
  • 画幅不同：说明允许裁切还是希望完整展示，不要默认拉伸主体。
  • 字幕：需要时明确提出；最好镜头和声音确定后再制作。

成片完成后检查

完整播放成片，检查每个接点、原声变化、最后一帧和最后一句。单段都能播放，只能证明素材存在，不能证明组合后的顺序和节奏正确。

满意后保存实际文件，同时保留各源片。想局部修改时从源素材继续，不必依赖已经合在一起且无法拆分的旧版本。

  1. 打开输出视频，从头播放到结束。
  2. 检查镜头顺序、接点、人物和道具连贯性，确认没有重复片段或多余停顿。
  3. 打开声音检查是否断句、重复起乐或音量突变。
  4. 有问题时指定成片时间位置，要求只改相关区间。
  5. 用作品提供的文件操作找到电脑文件，保存原片和采用的成片。

与短剧里的分镜合成有什么区别

短剧工作台通过按钮选择各分镜的已完成版本，按分镜顺序合成。Agent 则通过对话指定已有片段的裁剪区间、顺序和独立音轨，适合进一步剪辑、配音和字幕。

短剧分镜合成适合按工作台的镜序与采用版本制作，Agent 合成适合指定具体区间、声音和后续编辑。两条路线可以配合，先做好镜头再处理旁白和字幕。

当前短剧最终合成后锁定编辑，先确认镜头。Agent 也不会因为你说「合成分镜」就自动拥有尚未生成的片段，必须是实际可用素材。

字幕：识别台词、核对文字、生成普通或逐词字幕

字幕通常在镜头顺序和声音确定之后制作。Agent 先识别最终视频里的实际语音，给你核对，再把普通字幕或逐词高亮字幕加入成片。

约 5 分钟阅读

准备正确的成片

字幕的基础是正确的最后版本。先确认镜序、声音和旁白已经满意，再识别台词；旧版中多一段或少一句，都会使后面时间不同。

原片有字幕时也要说明是否保留。已经烙在画面里的旧字不是可直接删除的文本，应尽量从无字幕底片继续制作。

  1. 先完成视频剪辑、配音和音乐安排，选定要交付的版本。
  2. 打开播放，确认语音真实存在且清楚。
  3. 将这份最终有声视频添加到 Agent，用 @ 引用，不要误选旧版或一段原素材。
  4. 说明语言以及需要普通字幕还是逐词高亮。
小提示没有语音时不能依靠语音识别凭空做出台词。静音视频想加文字说明，可以用标题文字功能，或先准备旁白。

先识别台词，暂不制作字幕

语音识别可能把品牌、姓名、数字、方言或重叠人声听错。读文本的同时试听对应位置，先完成纠错。

识别稿帮助核对真实台词与出现时间，先修专名、数字和断句。听不清的地方回放或提供准确说法，不让助手用剧情猜一句看似合理的话。

字幕不能替代改音频。原声确实说错数字或商品名时，先决定如何处理声音，再生成准确且一致的文字。

确认后制作普通字幕

普通字幕适合阅读完整句子，尤其信息多、需要清楚表达的内容。确认稿采用后再生成字幕视频，检查出现结束时间与画面遮挡。

字体和样式只能在当前支持范围内调整，不应默认任意外部字幕模板都可使用。先满足可读性与准确性，再考虑表现形式。

  1. 指出错误文字与对应时间或准确台词，不要只说「错了几个字」。
  2. 明确采用普通字幕，保留已确认的声音和镜头。
  3. 等待新成片出现，播放检查文字、断句、出现时间及是否遮挡主体。
  4. 保存无字幕原片和字幕版，方便继续修正。

逐词高亮字幕是什么

逐词字幕会随着实际说话进度逐词突出显示，适合口播或节奏明确的内容。它依据实际识别的词句时间，不是按剧本平均分配秒数。

逐词高亮突出随说话变化的词，适合希望强调节奏的短口播。它更依赖准确语音时间，识别遗漏或断句错误会影响观看感受。

如果内容很密、说话快或需要长句阅读，普通字幕可能更容易看清。用同一短段检查两种形式，再选择适合观众的样式。

后面改了配音或剪辑怎么办

剪掉开场或更换旁白后，后面字幕可能整体偏移。要针对最终视频重新识别或核对，不直接把旧文字时间表套上去。

保留无字幕底片和确认稿，便于返工。新版本生成后再次检查最后一句和数字，不能只确认开头同步。

  1. 先完成新版本镜头和声音。
  2. 对新成片重新识别台词与时间，不沿用旧片全部字幕时间。
  3. 核对改变的区间、重复句子和数字。
  4. 从没有旧字幕的原片重新制作，避免新旧两层字幕叠在一起。

当前字幕的交付方式与范围

当前字幕制作交付的是已经把字幕放进画面的新视频，不能默认同时提供可编辑字幕工程或独立字幕文件。较长视频需按当前范围分段处理。

完成后保留有字幕与无字幕两版。需要改变文字时从合适底片重做，避免多层旧字幕叠在一起。

  • 当前字幕制作输出文字已加入画面的新视频；不要默认它同时交付可下载的 SRT 文件或任意样式编辑器。
  • 语音识别按可处理区间进行，字幕成片目前最长 300 秒，较长视频先分段。
  • 需要改字幕颜色、位置或其他复杂样式时，先确认当前可做的范围。
  • 字幕完成后仍应人工核对专名、数字、断句、同步和遮挡。

先确认你要哪种配音

先区分文稿、独立录音与模型生成声音。Agent 可以帮你写旁白，也可以把已有录音放入视频；一段文字还不是可以混音的实际声音。

  • 已有旁白录音：直接添加音频，并说明放到成片哪个时间段。
  • 已有视频里的一段声音：可以先提取原有音轨，再用于后续合成。

  • 想让生成视频中的人物说话：属于所选视频模型的声音能力，写准确台词并确认支持，完成后核对口型和声音。

准备旁白文稿和音频

文稿应服务于镜头时长与受众，准确卖点先确认，再删掉重复形容词。自己录音后听完整内容，检查静音开头、背景噪声和是否截断。

录音比画面长时先改文稿或镜头安排，不急着交给合成。旁白准确、可用，后面字幕识别也更容易核对。

  1. 先写完整文稿，注明语言、说话人、语气和预计使用场景。可请 Agent 修改文稿，暂不生成视频。
  2. 录制或准备独立音频，避免明显噪声和过长空白。
  3. 在 Agent 添加文件，或先上传到文件库，命名为容易识别的「旁白录音」。
  4. 播放确认台词、语速和时长，再选择目标视频。

把旁白放到成片中

旁白出现的位置从新成片开始计时。说明从几秒开始、采用完整内容还是某段，以及原视频声音保留多少；不要只说「放进去」而不交代时间。

对白、环境声与音乐可能在原片中混合，关闭原声就会一起消失。需要保留其中一部分时，先确认有没有独立音频可用。

  1. 用 @ 引用视频与旁白，告诉助手谁负责画面、谁负责声音。
  2. 指定旁白在成片开始的时间，说明使用整段还是录音中的一段。
  3. 明确视频原声保留、调低还是关闭。
  4. 核对时长安排，再要求制作实际成片。
  5. 完成后听全片，检查开头、结尾、响度和是否被截断。

替换配音又想保留背景声

如果原视频的对白、音乐和环境声混在同一条声音中，关闭原声会一起关闭它们。只想换对白但保留背景时，优先准备单独的环境声或音乐。让 Agent 先检查哪些声音素材真正可用，不要以为提取原声就已经得到干净人声。

更换旁白又保留背景，是因为需要把两类声音独立安排。原视频已经把它们混在一起时，不能保证直接剥离说话人；先试听原声并决定实际可行方法。

可以提供独立环境声或音乐重新混音。不要把提取原片声音误当作已经分离人声与背景。

配音太长或太短时

音频长度影响结尾和节奏。太长时不截断句子，先考虑用备用镜头、延长可用停留或重录；太短时也不必无意义重复同一句。

当前不应默认提供任意变速。调整方式先说清并确认，最后完整听一遍，尤其结尾是否自然。

  • 太长：先精简文稿、重新录制，或调整镜头保留长度；不要默认直接变速。
  • 太短：说明允许停顿、保留环境声还是缩短画面。
  • 出现位置错了：指定新成片时间，不要拿原片时间作为旁白起点。
  • 想做字幕：先完成配音和混音，再识别最终成片的台词。

录好后回到原项目选中音频，按实际文件继续。文字与声音是两个阶段，费用和完成标志也要分别看。

裁剪时如何指明时间

A 使用 3 秒，B 使用 5 秒，合起来是 8 秒。B 在原文件从第 2 秒取，但在新成片从第 3 秒开始。配音、文字等后期操作应使用新成片的时间。

裁剪时间应落在实际源片范围内，并说明采用哪个版本。起止点如果切在动作中间或句子中间，片段可能单独好看却无法自然接上。

先看原片再写秒数，必要时让助手提出区间方案。引用另一个旧版本时，同样的时间可能对应完全不同内容。

不知道秒数也可以说明动作

用动作描述区间适合不知道秒数的情况，但需要先查看与确认。说明保留完整推门、放下杯子或一句话，而不是笼统要求「加快节奏」。

开头等待与剧情反应停顿不同，后者可能有作用。选区间时结合故事目标，不把所有静止画面都删掉。

  • 用动作描述帮助助手定位，再核对时间。
  • 有对白时先检查台词，不要为了凑时长切掉句子。
  • 重要信息需要停留，不能把所有停顿都当作无用片段。

调整已有成片

修改已有成片要重新考虑镜序与音频位置。裁掉一段后，后面的音乐、标题和字幕时间可能变化，应明确哪些效果保留、哪些需要重新安排。

有源镜头时优先基于源片继续，保留上一版做比较。直接处理烙了所有效果的旧视频，可能无法干净修改其中一项。

  1. 指定当前要改的成片和它的源片段，保留原始素材。
  2. 说明新的顺序或采用版本。例如「第三段改为第二段，其他不变」。
  3. 要求重新计算成片时长和声音位置。
  4. 剪辑改变后，重新核对受影响字幕与标题的时间。
  5. 播放新版本，比较变化点及相邻镜头。

哪些问题适合剪，哪些需要补拍

画面已经正确但头尾空等、镜序不对或时长冗长，适合剪辑；人物外观、核心动作或商品结构错误，通常需要补相应内容。

先判断问题类型再动手，避免为了删一秒空等重新生成整段，也避免指望裁剪能修复画面本身的形变。

  • 动作前空等、结尾停太久：先裁剪。
  • 顺序错误、重复片段：调整排列或删除重复采用段。
  • 标题挡脸：修改文字位置或时间，不用重新生成原视频。
  • 音乐过响：调整独立音轨或原声音量，不用重新生成画面。
  • 关键动作没有出现、角色严重改变：可能需要调整参考与描述，重做这一镜。

局部修改的说法

局部修改说明具体镜头、保留内容与目标变化。越能精确定位，越容易避免助手重做成功部分，也更容易核对新增任务费用。

修改后连看相邻镜头，检查动作和声音接点。目标不只是那一秒消失，而是整段仍然自然。

不确定是否支持的效果先问清楚

当前常规拼接是按区间顺序合成，不要把「淡入一个文字」理解成已支持任意视频转场或变速。需要特殊效果时，先让 Agent 说明当前可执行的做法，确认后再制作。

转场、变速和跟踪有各自支持范围，不应默认与裁剪一样普遍可用。先询问当前可做方式，再决定采用什么效果。

若可用替代方案会改变内容或需要新生成，先确认效果与费用。不要因为名称听起来像常规后期就跳过能力检查。

背景音乐、音效与原声怎么合成

声音安排要说明「使用哪份音频、从哪里开始、响到什么程度、怎样结束」。配音、音乐、音效和原声可以各有作用，但都需要实际可用的素材。

约 5 分钟阅读

先分清几类声音

原声可能是一份混合声音，独立旁白、音乐和音效则可以分别安排。先知道手里的音频是什么，再决定保留、关闭或添加，避免意外消掉对白。

给音频明确名称与职责，例如「旁白采用版」「低音量背景音乐」「关门音效」。只说有三份音频，不能说明它们什么时候该出现。

  • 原声：视频自带的声音，可能同时包含对白、音乐和环境声。
  • 配音或旁白：独立录音，通常需要保证可听清。
  • 背景音乐：可以跨越多个镜头连续播放。
  • 音效：门响、杯盖开合等短声音，安排在动作对应位置。
  • 环境声：雨声、店内氛围等建立空间的声音。

为声音提供明确安排

声音安排需要起点、长度、相对音量与淡入淡出，尤其旁白与音乐同时播放时。可以先让助手核对长度，保证重要话语完整且清楚。

新增音效也要贴近实际动作位置。从新成片计时，不继续使用某个被裁掉开头的旧视频秒数。

使用已有音频

使用已有录音或音乐时先试听，确认是正确版本与可使用内容。文件名写着背景音乐，不代表没有突然大声或结尾截断，仍需检查。

当前没有通用独立音乐或音效生成功能。需要新声音先准备实际文件，或明确核对所选模型的原生声音能力。

  1. 上传配音、音乐和音效，先试听各文件。
  2. 为每份音频命名，用 @ 分别引用。
  3. 指定音频自身需要使用的区间，以及在新成片从哪一秒开始。
  4. 说明每段视频原声怎样处理，再说明独立音频的音量与淡入淡出。
  5. 完成后实际听全片，检查台词被盖住、声音突变、接缝和结尾截断。

声音随镜头位置变化

调换镜头或裁短片段后，原有的音效和旁白位置也可能需要改变。请让 Agent 使用新成片时间重排音频。两镜原声各带一段音乐时，直接拼接可能出现重复起乐，必要时改用独立连续音乐。

镜序变化会带来声音位置变化。一个源片的关门在原第六秒，裁剪后可能落在成片更早的位置；独立音效应按最终接点调整。

混音前先确定采用区间，混音后再字幕。这样避免后面重复对齐声音和文字。

从视频提取声音

提取音轨适合试听或复用原片的一段声音，但通常会一起带出人声、音乐与环境声。指定原片起止区间，提取后先听，不直接当作独立背景。

要分开替换时，先确认是否有各声音的源文件。关闭混合音轨可能关闭所有内容，应在确认前说明。

小提示提取是取出原有混合音轨，不会自动去掉背景音乐，也不会把不同说话人分成独立文件。

声音问题这样描述

问题用能定位的时间与现象描述，例如哪段音乐盖住哪句话、哪处突然静音或音效晚于动作。这样更容易只调整相应部分。

新片完整试听，检查开头、接点与结尾。只看音量数字或音轨存在不足以判断听感与台词正确。

  • 旁白被盖住：「调低独立背景音乐，保留旁白清楚可听」。
  • 出现双重人声：「检查是否原声和旁白一起播放，按我的要求关闭对应片段原声」。
  • 视频没声音：「先检查最终文件有无音轨、哪些区间静音，再确认音轨安排」。
  • 音效提前或延迟：「定位成片第几秒的动作，把对应音效移到那里」。
  • 音频不足：「说明真实缺少多少秒，先给我选择，不要编造已经补齐」。

约 6 分钟阅读

准备底片与叠加内容

底片是你要保留的实际视频，叠加内容是标题、图片或另一段视频。先说明出现区间和位置，再核对素材与声音来源，避免把待生成画面当成已有贴图。

底片里原有的文字与后来添加的可编辑标题不同。想改已有字时先判断来源，不能默认任何视频里的字都能直接删掉。

  1. 添加要编辑的视频，并用 @ 明确指定这份底片。
  2. 添加需要贴入的图片或小视频，确认它们能正常预览。
  3. 写准确标题或数据，不要让视频生成模型猜测品牌文字。
  4. 说明出现时间、位置、大小、遮挡限制，以及需要淡入、淡出还是简单移动。

添加固定标题

时间以当前成片为准。如果标题只是说明文字，不必通过语音识别生成对白字幕。

固定标题适合准确文案、品牌、日期或结尾提示。给完整文字、起止时间和大致位置，留出边缘并避开人物脸与商品。

完成后检查换行、字数与遮挡，尤其竖屏。标题越长越容易覆盖关键画面，应先简化文案而不是只缩小到看不清。

根据实际台词出现文字

按台词出现文字，要先识别真实语音，再确认对应位置。重复词或短句出现多次时，说明第几次或在哪一段，避免效果出现在错误位置。

台词来自最终底片，剪辑改动后时间可能变。确认对应区间再制作，完成后看文字与话语是否一致。

小提示重复出现的台词要说明第几次。当前视频里没有这句话时，改用明确秒数或修正目标，不要假定剧本里的句子已经被说出。

图片、画中画与分屏

贴图负责静态信息，画中画负责同时展示另一段画面，分屏则用于对比。都要说明大小、位置、区间与是否允许裁切，优先保留关键主体。

叠加视频不自动带入它的声音。需要其音频时另行安排，避免听见两个同时说话的人或意外消音。

  • 完整显示：保留图片或小视频全部内容，可能有空边。
  • 填满指定区域：允许裁切部分边缘时要明确说明，避免裁掉关键主体。
  • 分屏：指明各画面放左、右或上下，说明哪份声音被使用。
  • 叠加视频不会自动带入它的声音；需要其声音时，还要独立安排。

简单动画怎样说

目前支持这类简单位置移动、缩放和淡入淡出。不要默认任意复杂转场、跟踪或三维动画都可执行。

简单移动、缩放和淡入淡出可以帮助信息出现，但不是任意复杂转场或跟踪动画。用具体起点、终点和时间说明比「做炫酷效果」更容易实现。

效果应服务于可读性，不把商品或标题移出画面。先用一个短区间检查，再扩展到整片。

修改已有标题而不叠字

修改之前由助手制作的图文版本，指明哪一项变化，并要求保留其他效果、从原底片继续。这样不会把旧字与新字叠两层。

外部视频中的文字已经是画面部分时，先讨论实际处理方法，不承诺直接编辑文字。源片和编辑版本都应保留。

  1. 指定之前由 Agent 制作的编辑版本，说明只改哪个文字或画面元素。
  2. 要求保留其他效果，并从原底片重新制作。
  3. 如果原文字已经在外部视频中成为画面的一部分，先说明它不能当作可编辑标题直接删掉。
  4. 播放新片检查出现区间、遮挡和是否仍有旧字。
小提示当前图文编辑以最多 300 秒的视频和 24 个画面元素为范围。内容较多时先简化或分段。

双画面分屏示例

需要对比两份视频时，说明两边的素材、出现区间、画幅和声音来源。先确认视频能覆盖所需时长；分屏的声音也需要单独指定。

双画面用于前后、左右或不同产品对比，选择的两份内容需要能覆盖所需时长。画幅和布局要让双方主体可看清，而不是把画面拉伸凑满。

声音来源单独明确，通常保留一个主要来源更容易理解。完成后核对两边动作、文字与时间是否真的可比。

实战：给现有口播视频加字幕、配图与背景音乐

已经录好的口播通常不需要重新生成说话人。可以先检查原片和台词，再加入对应的配图、标题与较轻的背景音乐，最后做字幕。本篇按实际制作顺序说明怎样得到一个可检查的新版成片。

约 4 分钟阅读

先确认原片和台词

准备能够正常播放的口播视频，听清原声，并确认哪一版是最终内容。把需要出现的产品图、卡片文字和背景音乐一并准备好，名称尽量能区分用途。

有错误台词或太长停顿时先处理，再做字幕与配图。把字幕做完后反复剪辑，会改变后面所有文字出现的时间。

第一步：识别并核对实际内容

校正识别稿时以实际声音为准，不凭想写的文案新增一句视频里没有说的话。想改变话语内容，应先准备新的录音或调整原片，而不是只让字幕写成另一句。

第二步：确定需要保留的区间

原片只是开头准备时间过长，可以裁掉准备部分；中间有停顿时要听清句子是否完整，再提出保留区间。裁剪后的时间应成为后期安排的基础，不继续使用旧视频的秒数。

声音与画面来自同一口播时，保留原声更容易保持自然。不要关闭原声后才发现对白也消失；如果要新旁白，需要提供实际音频并先核对长度。

第三步：加入图片或说明卡片

根据一句实际台词指定出现位置时，说明第几次说到它，避免多个相同词造成歧义。准确文字使用标题或卡片编辑，比让生成模型重新画字幕更方便核对。

第四步：处理音乐，再最后做字幕

音乐太响时具体指出哪一段盖过了对白，让助手基于原片和原音频重新安排，不改已确认镜头。字幕最终根据混音后的实际声音与剪辑时间制作；想做逐词字幕也应先把台词核对完整。

最后的播放检查

  1. 从头听完一句一句的对白，确保没有被裁断或音乐盖住。
  2. 核对品牌、价格、人名与数字，字幕与实际声音一致。
  3. 检查配图出现的时机和位置，人物脸与关键内容不被遮挡。
  4. 确认新片可正常播放，并保留无字幕版本及原始口播。
  5. 需要下一轮修改时指明本次版本与具体时间，不把多个旧稿混在一起。

如何选择模型：先看任务，再看参考、规格与费用

没有一个模型适合所有任务。选择时先检查它是否支持你的输入与所需输出，再比较实际效果、费用与重做成本。本篇给出可操作的选择顺序，而不是一份永久有效的模型排名。

约 5 分钟阅读

先过四个必要条件

第一是任务类型：图片模型不会自动变成视频模型。第二是素材类型：你需要人物图片、视频动作参考或音频参考，模型必须支持相应方式。第三是规格：画幅、时长和清晰度必须能在当前页面选择。第四是费用：本次实际生成的总价要在你能接受的范围内。

不满足必要条件时，先换方式、换模型或拆分任务。不要仅凭模型名字熟悉，忽略「该方式不支持这个画幅」或「当前时长不可用」的提示。

怎样做一次有意义的小样对比

比较每秒单价之外，还要考虑最终能保留几秒。一个便宜但需要连续重做的镜头，可能比一次就能用的镜头总费用更高。模型是否更适合你的任务，需要用实际素材验证。

  1. 选一份代表真实需求的参考素材，写同一核心目标和必须保留的细节。
  2. 在候选模型里分别选择可实现的相近画幅与时长，记录当次参数与报价。
  3. 先生成一个结果或一组结果，不立即批量重做。
  4. 用同一标准检查主体、动作、声音、可用区间和修改难度。
  5. 以满足需求的可用结果为准，决定是否提高档位或扩大数量。

模型不可用时怎样继续

先确认是不是当前参考方式、输出档位或画幅不可用，而不是整个模型都不能使用。可以降低不必要的档位、改用当前支持的画幅，或把长镜头拆成短镜头。

替换模型后再核对人物与风格。已经成功的片段先保留，只补缺少的一镜；换模型不应该自动触发全项目重做。

先分清四种计费方式

图片生成通常按次，视频通常按生成时长。部分图片模型一次生成返回一组多张，价格不能按每张重复乘；文本创作则按实际处理与生成的文字用量计算，不能拿视频每秒价格估算。

官网「价格与积分」帮助查看当前单价；客户端生成按钮或 Agent 确认窗口显示本次费用。将单价与本次参数对应，再确认总价，是最可靠的使用方式。

计费单位与总价的关系
类型怎样计算要特别核对
普通图片生成当前单次价格 × 实际生成次数清晰度档位与生成数量
Midjourney 图片按一次一组四张计算；两组按两次计算四张结果不应再重复乘四
视频生成当前每秒价格 × 生成时长 × 生成数量时长按生成长度，不按剪辑后长度

图片费用：先看档位，再看数量

同一个图片模型的 1K、2K、4K 等档位可能不同价。选择高档位后再生成，是一份新的生成任务；不能把它当作免费下载原图的更清晰版本。普通多图任务则按本次数量增加总费用。

Midjourney 当前使用一组四张的生成规则。界面显示四张时，要按一组理解；选两组共八张则按两组计算。判断一张图的成本时，可以用总价除以实际结果数比较，但支付前仍以这次显示的总价为准。

视频费用：按生成长度，不按最终保留长度

假设本次显示单价为 1.5 积分/秒，生成一个 10 秒视频，则预计为 15 积分，即按当前换算展示为 1.5 元。若生成两个同规格结果，总额是 30 积分。这里的数字只演示计算，不是所有模型的固定报价。

把 10 秒结果裁成 4 秒，不会将原任务改成只生成过 4 秒。相反，已经有一个可用的视频，继续剪掉空等，不需要为那个镜头再做一次生成。选择合适长度和复用素材，通常比生成后大量丢弃更容易控制费用。

为什么同一模型的报价会改变

清晰度、参考方式、素材类型、画幅、时长和当前价格变化，都可能影响本次可用选项与报价。尤其在添加视频或音频参考后，不要默认仍采用未添加参考时的价格。

价格列表是帮助比较的入口，不是给所有参数组合永久锁价。页面提示价格已更新或暂不可用时，刷新并检查本次费用，再确认生成；不要重复点击或按旧截图付款。

小样与正式版本的区别

小样优先验证主体、构图和动作，可以从适用的基础档位开始。方向错了就先改描述或参考，不要立刻把数量翻倍；只有内容已经成立，才考虑高尺寸或更多候选版本。

高档位的新生成仍可能有内容变化，应再次检查。已经有正确主体、只需要加标题或字幕时，优先后期编辑，不要把增加几个文字当作重新生成全片的理由。

自动生成预算与账户余额分别看

账户余额是可用积分；Agent 的本次对话生成预算是你允许助手在这一对话中自动提交媒体生成的范围。设置预算不等于充值，也不等于保证所有任务都能在这个金额内完成。

自动生成预算不应被理解成全部文字创作与后期的统一价格承诺。开始时仍明确「只补缺少镜头」「保留成功结果」，遇到报价、任务内容或参数变化时，重新核对需要的费用。

失败与效果不满意分别处理

任务明确失败，查看对应退回积分记录；正常完成但不符合审美或某个细节不理想，先定位需要修改的地方。两种情况不能都按「没达到想象，所以不算生成」理解。

等待期间看已有任务，不重复提交。一个镜头有问题时，说明时间位置、保持什么和改什么；重做全部镜头容易同时增加成本和破坏已有一致性。

  4. 如果显示失败，阅读提示，检查类型、大小和文件完整性，再选择一份可用文件重试。
小提示上传完成后素材可用于后续选择。上传到文件库不等于已经把它加进某个图片、视频或分镜任务。

筛选和搜索

搜索先用有辨识度的名称片段，例如角色或镜头名，而不只搜很常见的「视频」。结果多时配合类型筛选，并加载后续内容。

没找到时核对账户、项目与当前设备，不因一轮搜索为空就断定素材已删除。旧版或另一项目的文件可能需要从对应位置确认。

  1. 先按素材类型筛选，例如点击「图片」。
  2. 在「搜索文件名」输入名称里的一部分，例如「主角」或「书店」。
  3. 没有结果时先清空关键词，再切回「全部」，判断是名称不匹配还是筛选错了类型。
  4. 有更多文件时使用「加载更多」。还找不到时确认当前账户、电脑和素材目录是否正确。

预览与重命名

名称中加入项目、内容和版本，比「最终版」更容易查找。仅改文件名称不会把画面内容变成另一张图。

预览是判断文件内容的依据，重命名是提高后续引用准确性的工具。将采用版与草稿分开，后面 @ 或添加参考时更容易选对。

改名不会把内容变成另一版本。需要替换文件就添加正确文件并重新引用，别仅把旧名改成新名来掩盖内容差异。

  1. 点击文件卡片的预览入口，打开「文件详情」。
  2. 核对媒体内容和文件信息；视频或音频请实际播放。
  3. 从文件卡片的「重命名」操作，或详情里的名称编辑按钮，修改名称。
  4. 输入新名称，按页面的保存操作确认；看到「文件名已保存」等结果后，重新搜索检查。

把素材用于下一次创作

复用素材可以省去不必要的再次生成，但不同入口有不同输入规则。先选择，再检查参考区域与用途，尤其普通参考与首尾帧的位置不要混用。

Agent 处理已有视频时明确操作类型。文件被选中只说明它可参与任务，还需要说分析、裁剪、合成还是作为新生成参考。

  1. 进入图像或视频生成，在参考素材区域点击「添加」。
  2. 在「选择参考素材」里选中文件库已有的素材，点击「使用所选素材」。
  3. 回到创作页面确认素材缩略图，补充它的用途，再设置参数和生成。
  4. 助手输入区可用「从文件库选择」添加对话附件；短剧分镜则从对应的人物或场景入口加入。
小提示文件详情有制作图片或视频的快捷入口时，也可以使用。进入目标页面后仍需确认参考、描述和参数。

找到文件与删除素材

在文件夹中显示用于找到本机实际文件，不等于云端备份或跨设备自动迁移。重要作品另存清楚的目录，保留源片与录音。

删除前确认是否有项目、字幕或后期需要继续用它。移除一次引用可以解决本次误选，不必删除文件库原素材。

  • 需要电脑文件时，点击卡片或详情里的「在文件夹中显示」，然后在文件夹中复制、备份或使用该文件。
  • 需要查看整个素材目录时，点击「素材文件夹」。
  • 删除前确认素材是否用于其他镜头，并保留重要原始文件。阅读删除确认，不要把它当作只移除一次参考选择。
  • 仅想把素材从某次生成中拿掉，使用生成页面缩略图上的移除按钮，不需要删除文件库里的素材。

文件存在记录但打不开

先看预览是否提示「文件已移除」「视频文件未找到」或正在准备。若只是未完成，按提示等待或重试；若实际文件已移动或删除，重新选择或上传仍然保留的原文件。记录存在不能替代一份可打开的文件。

无法打开先区分记录存在、源文件存在与播放器支持。检查同设备上的实际路径与预览，保留具体提示，避免为了打不开一个旧文件就重做全部项目。

如果原文件在另一台电脑，按备份或迁移方式找回实际素材。账户余额正常不能证明原电脑文件已经搬到当前设备。

约 5 分钟阅读

短信登录怎么操作

短信登录确认当前手机账户，填写时先检查号码是否正确，再按页面提示获取验证码。验证码有时效与用途，收到后只在登录页填写，不发给他人。

验证码未收到时先看号码与提示，避免连续重复请求。换设备登录或再次充值时，应使用原来的同一个账户。

  1. 打开客户端登录页，选择「短信登录」。
  2. 填写页面要求的手机号，核对号码没有输错。
  3. 点击「获取验证码」，收到短信后在验证码框中填写，再点击「登录」。
  4. 页面有倒计时或错误提示时，按提示等待或重试。不要短时间反复请求验证码。
小提示收不到验证码时，先核对手机号、短信拦截和当前提示。仍然无法收到，可把时间与错误提示提供给客服；不要把验证码发给他人。

密码登录怎么操作

密码登录适用于已设置密码的账户。输入对应账户与密码，不把短信验证码当密码；遇到错误时核对身份与大小写，再按页面可用方式处理。

如果没有设置过密码，先使用支持的登录方式进入后设置。不要通过新建另一个账户来解决旧账户密码问题，否则余额和作品不会自动跟过去。

  1. 选择「密码登录」。
  2. 在「账号或昵称」中填写可用的账号、已设置昵称或手机号。
  3. 填写密码，再点击「登录」。
  4. 提示失败时检查输入方式、大小写和是否登录错账户。如果仍能使用短信登录，可先通过短信方式进入账户。

设置昵称与密码

昵称帮助显示与辨认，密码用于登录，两者作用不同。保存后查看反馈，后面切换设备时仍要使用原账户身份；昵称相同并不能证明是同一个账户。

设置强度合适的密码并自行保管，不在合作咨询或问题反馈中发送。账户设置不会自动更改支付记录或把积分转给别人。

  1. 进入工作台后，点击左侧底部的账户入口，打开账户菜单。
  2. 点击「账号设置」，查看手机号，确认正在修改正确的账户。
  3. 在「账号昵称」中填写以后容易记住的昵称。页面说明昵称可作为密码登录时的账号。
  4. 需要设置密码时，填写「设置密码」与「确认密码」，两次内容保持一致。
  5. 点击「保存设置」，等待成功反馈。后续密码登录时，使用刚确认的昵称或页面支持的账户信息。
小提示密码长度、昵称是否可用等要求以表单提示为准。没有成功保存时，不要把刚输入的内容当作已经生效。

确认登录身份与切换账户

切换前确认当前重要内容已保存，并记住购买时的账户。退出后再登录另一个账户，看到的余额和项目可能不同，这是先需要核对的身份问题。

多台设备或多个账户交替使用时尤其容易混淆。买错账户不要继续重复付款，先保留订单信息核对。

  1. 在账户菜单查看当前名称、手机号或账户信息。
  2. 购买积分前再次检查客户端中的当前账户，确认是你要使用的账户。
  3. 要切换账户时先记录未发送的描述、保存重要文件，再选择「退出登录」。
  4. 重新登录后查看项目与积分是否属于目标账户，重新选择本次需要的附件。

哪些内容要分别核对

余额相同或昵称相近，不能证明一定是同一账户。遇到记录或余额不一致时，先核对身份与订单，再反馈问题。

账户余额、项目记录与本机文件是不同检查项。某一项能看见，不代表其他两项一定完整；换电脑时尤其要保留原素材与成片。

找不到作品先查账户与项目，再查当前设备的实际文件。重新登录能确认身份，但不能自动恢复被删除的本机文件。

  • 余额与积分明细：核对当前账户。
  • 项目和对话：核对当前账户以及打开的项目名称。
  • 素材文件：核对当前电脑的素材文件夹及文件是否仍然存在。
  • 购买积分：在客户端核对当前账户和支付金额。

找不到登录或保存结果

保存设置失败时先阅读表单错误，按提示修正。忘记密码且能接收短信时，先尝试短信登录，再按账号设置允许的操作处理。两种方式都无法使用时，请通过可用的支持渠道反馈登录时间和错误提示，不要发送完整密码或验证码。

登录问题先记录发生在哪一步与完整提示，文件问题则提供对应项目和预览情况。准确的信息能帮助区分身份、网络与本地素材的问题。

不要以提供密码或验证码作为排查方式。仅提供必要账户辨识信息、时间与错误截图，并保留隐私内容。

什么是积分：余额、购买、消耗与退回

积分是 GuGu AI 中用于支付创作服务的额度。当前购买换算为 1 元 = 10 积分；积分数量决定能否支付本次任务，但不代表固定能生成几张图或几秒视频。理解它与余额、预算、充值订单的关系，可以避免多数费用误解。

约 4 分钟阅读

积分与人民币怎样换算

当前 1 积分按 0.1 元展示，购买 100 积分需要 10 元。模型价格既可以用积分理解，也可以按这个比例换算成金额，但这只是购买与费用展示关系，不表示积分可以随时兑换现金。

不同模型、输出档位、参考方式和任务数量会改变实际消耗。询问「100 积分能做多少视频」时，必须先知道单价、每段时长、生成数量，以及是否还需要文字创作。

哪些操作可能消耗积分

图片生成、视频生成、Agent 的文字创作，以及部分 AI 优化功能可能按各自规则消耗积分。生成内容通常在提交前可核对本次费用；文字创作则根据实际用量形成记录。

浏览文档、查看文件或阅读现成结果，与提交新的创作任务不是同一件事。点击「生成同款」、重新生成或要求再做一个新版本时，应重新确认是否会产生新的费用。

为什么余额可能有小数

视频按秒、文字按用量结算时，积分可能出现小数。侧栏为了节省空间可能显示简短数字，详细金额应打开「积分详情」查看；不能把显示位数不同直接理解成积分消失。

一段时间内既有充值、创作消耗，又有失败退回时，余额是这些记录的合计结果。核对时按任务与时间逐条看，比只比较两个余额截图更容易找出原因。

积分跟随哪个账户

充值到账对应购买时登录的账户。不同设备的客户端需要登录同一个账户，才能查看这笔充值；切换账户不会把余额或作品自动转给另一个账户。

同账户的积分与电脑上的实际文件也要分别确认。余额存在，不代表换一台电脑就一定能打开原电脑上的素材。项目的重要源文件与成片仍应自行妥善保留。

购买与退回的基本原则

建议先以小额购买完成一次真实创作，再根据已确认的模型报价补充额度。普通充值按当前页面价格一次性购买，不应自行假设订阅权益、赠送比例、跨账户转移或额外折扣。

正常情况下，充值成功后不支持退款。任务明确失败时可能退回对应生成积分，这是创作费用的退回，不是把充值款退回微信或支付宝。具体异常需要按订单或任务记录核对。

常见问题

  • 积分不足：先核对当前任务总价，降低不必要的数量或补充所需额度。
  • 买了积分却看不到：确认支付成功和登录账户，刷新支付状态与余额。
  • 生成失败后余额未恢复：等待任务与退回记录更新，保留信息联系人工核对。
  • 不打算继续使用：不要将余额视为可提现金额；充值前按实际需求购买。

了解积分、费用与购买

积分用于支付创作费用。先看本次生成的费用，再选择是否购买；付款完成后确认积分已经到账，之后再开始生成。

约 6 分钟阅读

先看账户余额与本次费用

官网「价格与积分」页显示当前可展示的模型价格。不同模型可能按次、时长或其他方式计算，实际以这次生成前显示的费用为准。

余额表示可用额度，费用表示本次具体任务消耗，两者分别确认。图片、视频和文字创作有不同计费方式，不能以一笔充值金额直接推断能做多少作品。

当前 1 元 = 10 积分是购买换算。最终消耗取决于模型、参数和数量；价格变化后以本次显示的总价为准。

  1. 在客户端左侧底部的积分入口查看余额。
  2. 选择要用的模块、模型、参考方式、画幅、时长、清晰度或生成数量。
  3. 等费用显示更新，查看「生成图像」「生成视频」或生成确认窗口中的积分数。
  4. 余额足够且内容正确时再开始生成；不足时先购买需要的积分。
小提示对话中的文字回复与图片、视频生成不是同一个动作。不要假定取消一段对话会取消已经提交的生成。

在客户端购买积分

客户端充值要先确认账户与支付方式，再看应付金额和到账积分。微信自定义金额按当前整数范围使用，支付宝按有效积分包选择。

正常情况下充值成功后不支持退款，建议按实际近期需求购买。支付页面打开不等于已付款，完成支付后回到入口确认状态。

  1. 点击积分相关入口中的「购买积分」，打开购买窗口。
  2. 确认当前账户和余额，再选择页面提供的积分档位或微信支付金额。
  3. 使用自定义金额时，在对应输入框中填写页面允许的数值，检查换算后的积分和「应付金额」。
  4. 确认支付方式，点击「立即购买」。
  5. 微信支付窗口出现后，用微信扫一扫扫描二维码，核对支付金额再付款。
  6. 付款后点击「我已完成支付」或等待页面确认；回到积分窗口查看余额是否增加。
小提示支付方式、金额限制和二维码有效期以当前窗口为准。二维码已失效时，先确认原订单是否付款成功，再按页面提示重新处理。

在官网查看模型价格

进入官网「价格与积分」查看当前模型价格与积分费用。账户登录、余额查询与积分购买请在 GuGu AI 客户端中完成。

官网用于查看当前模型价格，账户登录、余额查询和购买积分在客户端完成。查看单价后，回客户端选择本次参数，再核对生成总价。

单价列表与本次生成总价不同，添加参考或更改参数后重新核对。充值成功也不意味着模型可用性与费用永远不变。

查看积分消耗和获取记录

消耗记录帮助对应具体创作，获取记录帮助核对充值与退回。按时间、类型与模型看，可以区分文字创作、媒体生成和失败返还。

不要只比较两张余额截图，期间可能有多笔任务。侧栏简短显示与详情精度不同，也应以具体记录为准。

  1. 打开积分入口中的「积分详情」。
  2. 「消耗」页查看时间、类型、使用模型、积分数和状态，核对是哪一次创作。
  3. 「获取」页查看购买、赠送或退回等对应记录，结合时间判断是否到账。
  4. 如果显示金额与自己的记忆不一致，先检查是否连续生成了多个版本、增加了数量或切换了时长。

已经付款但没到账

先确认真实支付与购买账户，再刷新状态。支付成功未到账和未支付订单需要不同处理，重复付款往往会增加新的订单问题。

仍有异常时提供订单号、时间、金额与账户，按记录核对；不提供密码或验证码，也不自行假定已获得退款批准。

  1. 先在支付应用中确认订单是否实际支付成功，而不是只打开过付款页面。
  2. 核对客户端是否登录了购买时的账户。
  3. 回到支付页面刷新状态，等待结果反馈。
  4. 若仍未到账，记录订单号、支付时间、金额、账户和错误提示，通过可用的支持入口反馈。
  5. 问题确认前不要为同一笔支付重复付款。

怎样减少不必要的重复消耗

减少费用的关键是先验证方向、复用成功素材、只改有问题镜头。数量多、时长长和高档位都会影响总价，等待期间不要重复提交。

  • 第一次先生成 1 张图片或一个短镜头。
  • 参数改变后重新确认费用，尤其是数量、视频时长和输出档位。

  • 正常完成但效果不满意时，先确定要改哪一点，再生成新版本。

退款策略与异常处理：充值退款和积分退回的区别

正常情况下，GuGu AI 充值成功后不支持退款。请在付款前确认账户、金额和使用需求。本篇同时说明生成失败时的积分退回、已完成作品不满意，以及重复支付或到账异常应如何处理。

约 4 分钟阅读

正常充值的退款策略

充值购买的是当前账户中的创作额度。正常情况下，充值成功后不支持退款，包括暂时不打算继续使用、购买多于近期需求或普通创作效果没有达到个人预期等情形。建议先小额体验，确认适合自己的用途后再补充积分。

普通余额不提供随时提现或兑换现金的承诺。不要把“1 元 = 10 积分”的价格换算，理解成任何时候都能按相同比例把积分换回人民币。

任务失败退回的是积分

图片或视频任务最终明确失败时，系统按任务结果处理对应生成积分的退回。查看「积分详情」和原任务，核对是否已有返还记录；页面暂时打不开文件或任务仍在等待，不一定等于任务最终失败。

积分退回进入原账户，不是充值付款原路退回微信或支付宝。它也不自动退回同一项目中其他已经完成的图片、视频或文字创作费用。每项任务应分别按实际记录核对。

异常订单怎样申请核对

异常反馈的目的是查清订单或任务事实，并不意味着发出请求就已经获得退款批准。具体处理应以核实结果与双方沟通为准。

  1. 在支付应用中确认实际支付结果，保留平台订单号或交易记录。
  2. 核对充值时与当前登录的账户是否相同。
  3. 记录金额、支付方式、支付时间和页面显示的情况。
  4. 生成费用异常则另附任务名称、参数、时间和积分记录。
  5. 将信息交给人工核对，按核实结果继续处理；未确认前不要重复付款。

等待、失败与积分问题怎么处理

遇到问题时，先确定是哪一个阶段：按钮不能点、任务还在生成、明确失败，还是结果已有但文件打不开。下面给出对应的检查顺序。

约 6 分钟阅读

生成按钮不能点击

按钮不可用先看输入与页面提示，常见原因是描述、参数、素材准备或模型状态还不符合条件。逐项完成检查，比不断换模型更容易定位。

参考类型和数量限制与当前模式有关。素材能上传成功，也不代表该模型在该方式下能使用它。

  1. 检查「创作描述」或分镜内容是否已填写，不要只有空格。
  2. 确认模型当前可用，画幅、时长和质量都在可选范围内。
  3. 查看参考素材是否准备完成，是否超过数量限制，是否放进了正确的参考位置。
  4. 需要首帧或尾帧时，按当前模式提示补齐；不支持的文件先移除。
  5. 检查费用和余额显示；页面有明确提示时先处理该提示。
小提示首尾帧与普通参考可能不能混用。切换时既要看缩略图，也要检查描述中是否还保留旧的 @ 引用。

任务还在等待或生成

等待与生成期间先查看已提交任务，不重复点击。视频较长或当前服务繁忙时可能需要等待，以真实状态为准，不能凭几分钟没有结果就认定失败。

想改变需求可以先暂停讨论，但已提交媒体任务分别检查。不要把关闭客户端当作全部任务已经取消。

  1. 在「我的作品」或「历史记录」找到这一次任务，核对时间、内容和状态。
  2. 没有失败提示时，先等待已有任务更新。视频通常比图片更复杂，页面没有提供固定完成时间时不要按一个绝对分钟数判断失败。
  3. 网络中断后先恢复连接，再查看已有任务，确认是否已经完成。
  4. 不要反复点击生成或让助手重复提交相同内容；新提交可能形成新的任务。
  5. 长时间没有变化且无法确认结果时，记录任务时间、模块和现有提示，再反馈问题。

页面明确显示生成失败

任务最终明确失败时记录错误和参数，并查看对应积分退回记录。自动尝试仍在进行时，以最终结果为准，先等待状态明确。

修改输入后再次生成会形成新任务。旧任务失败的积分退回，只对应原任务，不代表之后所有尝试免费。

  1. 点击失败任务或其详情入口，阅读原因与建议。
  2. 如果提示内容或参数问题，调整具体描述、参考方式、文件类型或时长。
  3. 如果提示素材不可用，先在文件库预览原文件，再重新添加一份能正常打开的素材。
  4. 如果提示网络或服务暂时不可用，恢复网络或稍后查看，先不要连续重复提交。
  5. 到「积分详情」核对该任务的消耗状态和获取记录。需要查询费用时，保留任务信息。
  6. 确认原因已处理后，再尝试生成一次。
小提示任务失败后的费用处理，以实际任务状态和积分记录为准。正常完成但效果不满意，不等于任务失败；修改后重新生成前仍要确认费用。

结果完成了，但图片或视频打不开

完成记录存在但打不开文件，应按实际作品与本机可用情况检查。确认源文件、下载或准备提示，再试预览，不能直接把这类问题当作生成质量失败。

关键是找到真实可播放结果。账户里有记录或一个缩略图，只说明记录可见，不一定说明当前设备文件完整。

  1. 查看是否还在准备文件，按当前提示等待或使用提供的重试操作。
  2. 点击「在文件夹中显示」，检查文件是否存在。
  3. 如果显示文件已移除，确认是否在电脑上移动、删除或清理过对应文件。
  4. 能找到原文件时，重新选择或上传；没有文件副本时，保留任务信息并反馈。
  5. 视频能找到但播放失败时，记录该文件和播放提示，不要先删除唯一副本。

积分与订单问题

付款成功但未到账，先核对支付记录和登录账户，再刷新支付状态。生成费用有疑问时，查看积分明细的时间、模型、数额和状态，与任务对应起来。请提供订单或任务信息，不要只说「积分不对」。

费用异常先区分充值、文字消耗、媒体消耗与失败退回。支付成功没到账核对订单，生成扣费则核对具体任务与数量时长，不把不同问题合成一个余额问题。

正常充值不支持退款；已完成但效果不满意先定位修改方案。异常记录按事实联系人工核对，保留时间与准确提示。

诊断信息用于帮助定位客户端问题，可以按当前页面提供的日志入口操作。同时写清复现步骤、发生时间与影响范围，日志不能替代问题说明。

不要把密码、验证码或无关私密文件附进去。若用户可见错误里有明确提示，原样记录并说明已经尝试过哪些检查。

  1. 打开账户菜单，找到「上传诊断日志」。
  2. 在「问题描述」中写明操作步骤、发生时间、模块与错误提示。
  3. 点击「上传日志」，等待结果提示；需要查找日志文件时，可以使用「打开日志文件夹」。
  4. 页面提供「联系客服」时，也可以按该入口联系，并说明已提交的问题。
  5. 涉及支付时附上订单号与金额；涉及生成时附上任务时间和作品信息。

  3. 需要查看更多素材时，使用工作台或文件库顶部的「素材文件夹」。
  4. 把满意作品复制到自己管理的文件夹，例如「项目名 / 交付」。
  5. 从新位置重新打开作品，确认文件完整、内容与预览一致。
小提示「在文件夹中显示」是帮你定位已保存的文件，不是让你选择一个新的下载目录。只有当前页面确实提供下载或另存操作时，才按该操作选择位置。

短剧成片如何保存

短剧成片与各分镜视频都值得保留：成片用于交付，源镜头用于继续剪辑与修改。字幕、音乐和旁白另有源文件时也一并整理。

当前工作台合成后锁定编辑，确认镜头前先做好修改。之后可将实际成片用于 Agent 后期，但不能指望只剩成片还能随意还原每一镜原稿。

  1. 确认已经合成出最终成片，打开成片预览并播放检查。
  2. 使用成片提供的文件操作找到它的电脑位置。
  3. 把成片和需要保留的分镜视频复制到你的项目目录。
  4. 再保留角色、场景参考和重要描述，方便以后重新制作。
小提示关闭项目或看到一条完成消息，不等于已经做了备份。重要交付请确认你手里确实有能打开的文件。

找不到文件时按顺序检查

按正确账户、项目、采用版本和本机实际文件顺序检查。任务还在等待时没有最终文件，文件刚准备时先按提示等待，不通过重复生成来寻找原作。

另一台电脑的素材需要从实际备份或原设备找回。登录同账户能看见余额，不保证本机已拥有所有源素材。

  1. 先用作品里的「在文件夹中显示」定位，不要只依靠记忆猜下载目录。
  2. 再看「素材文件夹」中是否有对应文件，搜索时使用具体名称或创建时间。
  3. 如果自己移动或重命名过文件，检查新的目录和系统回收站。
  4. 换过电脑、账户或素材目录时，检查当前环境，必要时从原电脑复制自己保存的文件。
  5. 仍找不到且页面提示文件已移除时，重新提供原始素材或按问题反馈指南提交信息。

换电脑与备份

备份要包含真实文件，而不只是项目名称或任务截图。最好保留源镜头、独立音频、无字幕成片与最终稿，方便以后替换文字或声音。

更换设备前先试打开备份，确认图片视频与音频都完整，再在新设备重新核对可用情况。

  • 换设备前，复制重要原始素材、生成结果和最终成片。
  • 新电脑安装客户端并登录账户后，还要检查素材文件是否已经在新电脑上；看到项目记录不等于本地已有文件。
  • 项目正在使用的参考不要随意移动或删除。需要整理时先做一份备份。
  • 不要把某个任务记录或一张预览缩略图当作唯一的保存方式。

创作前的使用须知

这份清单帮助你在开始前确认素材、参数和费用，在完成后检查结果，并保存好后续需要使用的文件。

约 6 分钟阅读

开始前：把目标写清楚

创作目标决定后面全部选择，先说用途、受众、需要的文件与必须准确的内容。只有纯文字想法时先讨论方案，已有素材时先复用，别为了使用全部功能把任务复杂化。

目标不明确时，请助手提出路线并说明各阶段交付；确认后才开始媒体生成，过程中仍查看文字创作费用与任务范围。

  • 明确用途：商品主图、竖屏短片、角色设定或故事片段。
  • 明确这一次只要方案，还是要直接生成作品。
  • 确定画幅、预计时长、关键主体以及必须保留的特征。
  • 准备清晰、完整、能正常预览的参考素材。
  • 新模型或新描述先做一个结果，不急着连续制作。

素材使用与隐私

只使用有权使用的图片、视频、音频和文稿。真实人物与品牌内容涉及外观和信息准确性，先确认权限与事实，不凭模型输出当作授权或证明。

反馈问题时只提供必要信息，私密文档、密码与验证码不应作为通用素材上传。公开发布前也检查画面与声音是否包含无关私人内容。

  • 使用自己拥有或已获得相应授权的图片、视频、音频和文字。涉及真实人物、品牌或他人作品时，先确认你可以怎样使用。
  • 不要把账户密码、验证码、完整支付敏感信息放进创作描述、附件或问题截图。
  • 文件含个人信息时，只提供本次任务需要的部分。
  • 商用、发布或对外交付前，根据自己的使用场景核对素材授权与内容要求。

生成前：确认这一单会做什么

生成确认是核对本次实际制作的步骤。除了报价，还看素材、数量、时长、画幅和完整描述，任何一项不对都先调整。

充值额度和本次预算分别理解；正常充值不支持退款。读完价格规则再购买，避免把个人审美期望理解成必然免费重做的承诺。

  • 当前账户正确，余额足够。
  • 模型可用，参考方式与素材类型匹配。
  • 画幅、时长、质量或清晰度、生成数量都符合本次目标。
  • 参考素材没有选错，也没有重复添加不需要的文件。
  • 费用已更新，并在你能接受的范围内。
  • 使用助手时，已看清生成确认；开启预算内自动生成时，已保存合适的预算设置。

等待期间：先看已有任务

生成有一定等待时间，具体速度因模型和任务而异。网络恢复后先查现有任务，不要直接再提交同一份内容。遇到明确失败时，阅读原因、核对费用记录并处理问题后再试。

任务还在处理时，先看已有结果与状态，不连续点击创建新任务。想改变方向可以说明下一步暂停，但已经提交的媒体任务单独检查。

不要把关闭页面、退出对话或重新登录当作自动取消。记录已经提交的任务，后续再核对实际结果与积分记录。

生成后：检查真实作品

真实作品要用播放和预览验收：主体、道具、声音、文字与时长都正确，才能完成用途。助手的完成文字、一个封面或只抽看几帧都不够。

数字、品牌和准确台词需要人工核对。模型生成的画面不能自行证明产品性能，重要事实按你的真实材料确认。

  • 人物、商品外观和重要道具是否正确。
  • 画面边缘、手部、文字和品牌信息是否有明显错误。
  • 视频动作是否自然、前后镜头是否连贯。
  • 声音、对白、字幕是否正确，有没有多余音乐或文字。
  • 描述中的事实信息是否需要再核实。
小提示AI 结果具有不确定性。同一描述可能产生不同版本，高质量档位也不能替代检查。看过实际文件，再决定是否对外使用。

合成与交付前

交付前完整播放最终版本，检查声音结尾、字幕尾句和镜头接点。保留源片与无字幕成片，将采用版清楚命名，便于后续局部修改。

需要修改一项时先基于源文件继续。已经烧录进画面的标题字幕，不应默认像文字稿一样可以直接删除。

  1. 逐个确认要采用的镜头版本和顺序。
  2. 短剧项目还有需要修改的内容时，先返回检查，再确认合成。当前分镜工作台成片生成后会锁定编辑。
  3. 完整播放最终作品，检查画面、声音和开头结尾。
  4. 找到电脑文件并保存到交付目录，再留一份重要参考和原始内容。
