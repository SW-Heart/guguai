# Caption font

`NotoSansCJKsc-Regular.otf` is the Noto Sans CJK SC Regular font from
https://github.com/notofonts/noto-cjk/tree/main/Sans/OTF/SimplifiedChinese.

It is distributed under the SIL Open Font License 1.1. The accompanying
license text is `OFL.txt`. The font is bundled so server-rendered Chinese
captions do not depend on fonts installed on the host.
