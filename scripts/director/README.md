# 智能导演工作台

智能导演项目直接打开「无限画布 / 可收起的导演对话」工作台。原专业编辑入口保留。

画布使用参考项目同版本的 `@8btc/whiteboard` CanvasApi，复用平移、缩放、节点选区与拖动。参考项目依赖的 React 对话组件和 Shell Agent 运行时没有迁入；GuGu 使用现有 LLM、积分结算、生成任务和本地媒体服务。

## 状态与操作

`project.resources`、`project.shots`、生成任务及资产是作品事实；`directorWorkspace` 仅保存布局、视口、锁定、对话和操作计划。画布节点 HTML 始终从项目数据重建，不存任意 HTML。

`POST /api/drama/projects/:id/agent-plan` 返回校验过的结构化计划，不直接改写作品。前端共享操作执行器将计划写入当前项目，沿用 revision 合并机制。计划生成按现有 LLM 用量结算；生成使用现有收费 API。请求体和幂等键先保存，再提交素材生成；暂停后恢复沿用任务 ID，已成功步骤不重复执行。

- 辅助：提出方案，用户确认后执行。
- 导演（默认）：自动执行设计与编辑，在素材生成等步骤前确认。
- 全自动：逐阶段读取作品现状、重新规划，完成生成与本地拼接。每次连续推进最多 8 轮；可重试的失败最多自动重试一次。
- 委托导演：同一工作台接管剩余制作；导演模式仍保留阶段确认点。

锁定在计划验证及执行前检查。用户可以直接导入素材到画布；选中节点后通过快捷工具条锁定、交给导演或展开编辑。编辑面板可修改 Prompt 和镜头时长，选择已完成版本，设置首尾帧及参考图。重新生成成功后选用新版本，旧版本保留。

## 验收边界

当前自动质检是分镜生产结构及资源引用的检查，不是视觉模型评分。尚不支持对人物外观一致性、表演和剪辑质量进行视觉评分，也不能宣称自动挑出了视觉效果最佳的版本；目前选择的是成功生成的新版本。跨镜头外观一致性依靠资源引用、首尾帧和用户检查。

执行器运行在当前客户端；退出工作台会暂停推进，外部已提交任务仍可完成。重新打开可确认继续。它不是关闭客户端后仍持续工作的后台自动驾驶服务。

真实模型生成与整片输出需要使用已配置的模型，并按实际调用消耗积分。自动测试使用隔离数据及模拟模型，不会调用收费生成。

## 验证

运行 `npm run check` 与 `npm test`。HTTP smoke 覆盖智能导演空项目、自治模式和画布/对话保存。`director-workspace.test.mjs` 覆盖锁定、非法操作、局部编辑保护和任务标识恢复；服务测试覆盖计划验证及结算错误边界。
